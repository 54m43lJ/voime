1. WHAT & WHY

↑

1.1 IDEAL：要解决的问题

Linux 桌面的键盘、输入焦点与文本提交由 Fcitx5 持有。Voime 需要在不接管键盘、不注册输入法条目的 前提下，把语音识别结果写进当前输入框。fcitx-addon 作为 Fcitx5 后台 addon 运行： 匹配热键、记录语音段目标、显示 Partial、提交 Final；音频与识别全部在 voimed。

1.2 GOAL：什么算成功

  • addon 随 Fcitx5 后台加载，不注册输入法条目；Shift / Super+Space 不会切到 Voime。
  • 配置一个 Mode、一个 Hotkey 与一个 Final Model；PTT 按住、Toggle 切换、Continuous 忽略热键。
  • 热键由 Fcitx 捕获；普通按键完全照常输入。
  • Partial 显示在 Fcitx 输入面板；Final 提交到语音段开始时聚焦的输入框。
  • 目标失焦时不误提交；daemon 断线时放行热键，不影响普通输入。

1.3 非目标

  • 不实现音频、VAD、ASR、标点或会话状态；这些属于 voimed。
  • 不实现 TUI、托盘或自绘候选窗口；临时窗口由 Fcitx UI 渲染。
  • 不使用客户端 preedit；只写 Fcitx InputPanel。
  • 不抓键盘、不转发按键、不注入其他窗口。
  • 不保证桌面空白处、锁屏、未使用 Fcitx 的应用中的热键。

2. 用户交互

↑

场景行为契约
安装 addon安装 voime.so 与 addon 描述文件，重启 Fcitx；在 Addons 页面可见，不加入输入法组。BUILD §2
配置在 fcitx5-configtool 或 ~/.config/fcitx5/conf/voime.conf 设置 Mode / Hotkey / Model；Model 只选择 Final。USER §4.1
PTT按住热键开始，松开结束；静音可自动结束。USER §3.1
Toggle按一下开始，再按一下结束；目标失焦自动结束；无语音时保持空白窗口。USER §3.1
ContinuousVAD 自动分段，热键不参与。USER §3.2
临时文本说话期间在 Fcitx 输入面板显示 Partial；Final 前清空。USER §3.3
最终提交提交到语音段开始时的目标输入框；失焦不提交。USER §4.2
普通输入除热键外的按键全部由 Fcitx 正常处理。USER §2
daemon 不可用放行热键、清空临时文本、定时重连。USER §4.4
