1. WHAT & WHY

↑

1.1 IDEAL：要解决的问题

Linux 桌面的键盘、输入焦点与文本提交由 Fcitx5 持有。Voime 需要在不接管键盘、不注册输入法条目的 前提下，把语音识别结果写进当前输入框。fcitx-addon 是核心安装写入 Fcitx5 系统 addon 目录的后台 addon：匹配热键、记录语音段目标、显示 Partial、提交 Final；音频与识别全部在 voimed。addon 不加载模型、不做识别，也不感知 Final 后端或 GPU backend。

1.2 GOAL：什么算成功

  • addon 由核心安装以 sudo 写入系统 addon 目录，随 Fcitx5 后台加载；不注册输入法条目，也不加入输入法组；Shift / Super+Space 不会切到 Voime。
  • 安装后出现在 fcitx5-configtool 的 Addons 页面；用户不需要把 Voime 加入任何输入法组。
  • 只配置一个 Mode 与一个 Hotkey；PTT 按住、Toggle 切换、Continuous 忽略热键。
  • 热键由 Fcitx 捕获；普通按键完全照常输入。
  • Partial 显示在 Fcitx 输入面板；进入 Finalizing 后保留最后一条 Partial 且不再刷新，Final 到达后提交到语音段开始时聚焦的输入框。
  • 目标失焦时不误提交；daemon 断线时放行热键，不影响普通输入。
  • 安装入口允许跳过 addon；拒绝提权或 addon 安装失败时核心安装失败并提示 --no-addon，不静默降级到用户目录。

1.3 非目标

  • 不实现音频、VAD、Preview、CPU Final 或 GPU Final；识别属于 voime-core / GPU worker，Final 调度属于 voimed。
  • 不做识别；Partial / Final 文本均由 daemon 产生，addon 只负责显示与提交。
  • 不加载模型，不链接 ONNX Runtime / llama.cpp，不感知 Final 后端（cpu / firered / qwen3）或 GPU backend。
  • 不实现 TUI、托盘或自绘候选窗口；临时窗口由 Fcitx UI 渲染。
  • 不使用客户端 preedit；只写 Fcitx InputPanel。
  • 不抓普通按键、不转发按键、不注入其他窗口。
  • 不保证桌面空白处、锁屏、未使用 Fcitx 的应用中的热键。
  • 不负责协议消息定义；协议见 voime-ipc USER。
  • 不实现传输协议；OS 传输见 voime-transport USER。
  • 产品级术语与端到端契约见 根 USER；Fcitx 外部 API 见 PROVIDER。
  • 安装入口与 --no-addon 的选项语义由 根 README §2 定义，本组件不重复。
  • 本组件仅支持 Linux；Windows 前端见 windows README。

2. 用户交互

↑

场景行为契约
安装 addon运行核心安装脚本；只有 addon 步骤申请 sudo，把 voime.so 与 voime.conf 写入 Fcitx5 系统 addon 目录。重启 Fcitx 后出现在 Addons 页面，不加入输入法组；系统路径见 PROVIDER §4.3。根 README §2
跳过 addon--no-addon 跳过 addon 安装，不申请 addon 提权；核心其他部分仍按用户级安装。用户自行完成系统 addon 安装后才出现热键与临时窗口。根 README §2
安装失败拒绝提权或 addon 安装失败时核心安装失败并提示 --no-addon；不写入用户目录，也不设置 FCITX_ADDON_DIRS。PROVIDER §2
配置在 fcitx5-configtool 或 ~/.config/fcitx5/conf/voime.conf 设置 Mode / Hotkey。USER §4.1
PTT按住热键开始，松开结束；静音可自动结束。USER §3.1
Toggle按一下开始，再按一下结束；目标失焦自动结束；无语音时保持空白窗口。USER §3.1
ContinuousVAD 自动分段，热键不参与。USER §3.2
临时文本说话期间在 Fcitx 输入面板显示 Partial；语音段结束、进入 Finalizing 后保留最后一条 Partial 且不再刷新，Final 到达后清空并提交。USER §3.3
最终提交Final 到达后提交到语音段开始时的目标输入框；失焦不提交。Toggle 会话在自动分段的 Final 后保留空白窗口。USER §4.2
普通输入除热键外的按键全部由 Fcitx 正常处理。USER §2
daemon 不可用放行热键、清空临时文本、定时重连。USER §4.4
