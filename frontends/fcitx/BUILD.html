1. 环境

↑

项目要求
平台Linux + Fcitx5；Windows 不构建本组件。
编译器C++20、CMake。
Fcitx5≥ 5.1.23 开发头文件；Arch：fcitx5；Debian / Ubuntu：libfcitx5core-dev 等，按发行版为准。
JSON仓库内 third_party/nlohmann/json.hpp（MIT），不需要额外安装。

2. 构建与安装

↑

cmake -S frontends/fcitx -B build/fcitx -DCMAKE_INSTALL_PREFIX=/usr
cmake --build build/fcitx
sudo cmake --install build/fcitx
产物说明
build/fcitx/voime.soFcitx5 addon；安装到 $PREFIX/lib/fcitx5/。
share/fcitx5/addon/voime.confaddon 描述文件；OnDemand=False，可配置。
图标assets/icons/voime.svg 安装到 Fcitx 图标目录。
inputmethod 条目不安装；Voime 不出现在输入法列表。
  • CMake 设置 PREFIX ""，产物是 voime.so（不是 libvoime.so），与 Library=voime 对应。
  • 构建根为 frontends/fcitx/；文件树保持相对结构。
  • 根构建编排见 根 BUILD §2。

3. 配置与加载

↑

# 重启 Fcitx
fcitx5 -r

# 确认 Addons 页面加载了 Voime；不需要加入输入法组
fcitx5-configtool
配置路径
addon 描述$PREFIX/share/fcitx5/addon/voime.conf
用户配置~/.config/fcitx5/conf/voime.conf（或 XDG_CONFIG_HOME）
旧配置迁移无后缀的 ~/.config/fcitx5/conf/voime 在启动时迁移到 voime.conf，然后删除旧文件。
  • 修改 Mode / Hotkey 后重新加载 addon 配置或重启 Fcitx。
  • 如果 Addons 页面没有 Voime，检查描述文件前缀、voime.so 的 ABI 与依赖。

4. 测试

↑

cmake --build build/fcitx
ctest --test-dir build/fcitx --output-on-failure
测试覆盖
tests/addon_test.cppMode / 热键字符串 / IPC 枚举 / target 空引用；不测试模型配置。
手工验收Addons 页面加载、不出现在输入法组、Mode 三态、热键冲突、临时窗口、Final 提交、目标失焦、daemon 重启重连、默认 CPU Final、GPU 目录安装后自动选择 / 回退。
frontend 覆盖原生 Wayland、XWayland / XIM、支持 text-input 的终端；不支持输入法协议的窗口不承诺。

5. 升级 / 卸载

↑

操作步骤
升级 Fcitx重新编译并安装 voime.so；重启 Fcitx；确认 addon ABI 与输入法组中没有 Voime。
升级 addon停止 daemon（可选）；重新构建 / 安装；重启 Fcitx；daemon 重启后 addon 自动重连。
卸载删除 addon 描述文件、voime.so 与图标；重启 Fcitx；用户配置按需保留或删除。
清理旧条目如果存在 share/fcitx5/inputmethod/voime.conf，删除并从输入法组移除 Voime。
