2. CONVENTIONS

↑

约定内容
线程所有 Fcitx API 调用、socket 事件与定时器都在 Fcitx 事件循环线程内；IpcClient 不做后台线程。
事件监听按键使用 watchEvent<InputContextKeyEvent>(PreInputMethod)；焦点失焦使用 watchEvent<InputContextFocusOut>(PreInputMethod)。
热键消费命中热键后调用 filterAndAccept()；未命中立即返回，不影响 Fcitx 普通路由。
PTT 状态holdActive_ 表示按住；松开按记录的 keycode 匹配；auto-repeat 消费后忽略。
Toggle 状态toggleActive_ 表示会话有效；toggleCode_ 防止同一次按键的 press / release 重复切换。
目标TargetRef 保存 TrackableObjectReference<InputContext> 与 segment_id；提交前检查 focused()。
重连2 s 定时器每次重新 setNextInterval 与 setOneShot；只重连不阻塞事件循环。
socket非阻塞 Unix socket；读写缓冲在 IpcClient 内，断线时先关闭 fd 再禁用事件源。
配置readAsIni / safeSaveAsIni 不会自动补 .conf；路径必须写全。
  • 仓库级线程 / 进程边界见 根 CORE §2；用户可见行为见 USER §2。

enum class TriggerSource { Hold, Toggle, Tui, Cli, Continuous };

struct IpcConfig {
    Mode mode = Mode::Ptt;
    std::string hotkey;

enum class ServerMessageType {
    Snapshot, SegmentStarted, State, Partial, Final,
    HistoryCleared, Status, Error, Bye, Unknown,
};

struct ServerMessage {
    ServerMessageType type = ServerMessageType::Unknown;
    std::optional<uint64_t> segmentId;
    std::string text;
    bool recording = false;
    bool finalizing = false;
    TriggerSource source = TriggerSource::Hold;
    std::optional<Mode> mode;
    std::optional<std::string> hotkey;
    std::string errorCode;
    std::string errorMessage;
};

std::string defaultSocketPath();
const char *triggerSourceName(TriggerSource source);
std::optional<TriggerSource> parseTriggerSource(const std::string &name);

class IpcClient {
public:
    explicit IpcClient(fcitx::Instance *instance);
    ~IpcClient();

    void setConfig(const IpcConfig &config);
    bool connect(const std::string &socket);
    void disconnect();
    void configure(Mode mode, const std::string &hotkey);
    void start(uint64_t segmentId, TriggerSource source);
    void stop(uint64_t segmentId, TriggerSource source);
    void toggle(uint64_t segmentId, TriggerSource source);
    bool connected() const;
    void onReadable();

    std::function<void(const ServerMessage &)> onMessage;
    std::function<void()> onDisconnected;

private:
    void sendJson(const std::string &json);
    void flush();
    void readAvailable();
    void handleLine(const std::string &line);
    void updateEvents();
    void fail();

    int fd_ = -1;
    std::unique_ptr<fcitx::EventSourceIO> ioEvent_;
    std::string socketPath_;
    std::string inBuffer_;
    std::string outBuffer_;
    IpcConfig config_;
    bool connectedOnce_ = false;
};

5. Call stack tree

↑

5.1 addon 启动

fcitx5
├── 加载 share/fcitx5/addon/voime.conf（OnDemand=False）
└── VoimeAddon::VoimeAddon(instance)
    ├── VoimeAddon::reloadConfig()
    │   ├── migrateLegacyConfig()
    │   ├── fcitx::readAsIni(config_, "conf/voime.conf")
    │   └── IpcClient::setConfig(currentConfig())
    ├── IpcClient::connect(defaultSocketPath())
    │   └── sendJson(Hello { role: fcitx, version, config })
    ├── Instance::watchEvent<InputContextKeyEvent>(PreInputMethod, handleKey)
    ├── Instance::watchEvent<InputContextFocusOut>(PreInputMethod, focus lambda)
    └── EventLoop::addTimeEvent(2 s, reconnect timer)
        └── connectDaemon()

5.2 PTT 热键

fcitx5::InputContextKeyEvent
└── VoimeAddon::handleKey(event)
    ├── 判断 mode == Continuous → 返回
    ├── 判断 !client_.connected() → 返回
    ├── KeyEvent::checkKeyList(hotkey, MatchAllNormalizedKeys)
    └── VoimeAddon::handlePtt(event, matches)
        ├── 判断 event.isRelease() && holdActive_ && code == holdCode_
        │   ├── holdActive_ = false
        │   ├── finalizing_ = recording_
        │   ├── IpcClient::stop(segmentId, Hold)
        │   └── KeyEvent::filterAndAccept()
        ├── 判断 !matches → 返回
        ├── KeyEvent::filterAndAccept()
        ├── 判断 holdActive_ || starting_ || recording_ || finalizing_ → 返回
        ├── VoimeAddon::bindTarget(event.inputContext())
        ├── holdActive_ = true; starting_ = true
        └── IpcClient::start(segmentId, Hold)

5.3 Toggle 热键

VoimeAddon::handleToggle(event, matches)
├── 判断 release && toggleCode_ 匹配
│   ├── toggleCode_ = 0
│   └── KeyEvent::filterAndAccept()
├── 判断 !matches → 返回
├── KeyEvent::filterAndAccept()
├── 判断 !toggleActive_ && !starting_ && !recording_ && !finalizing_
│   ├── VoimeAddon::bindTarget(event.inputContext())
│   ├── toggleActive_ = true; starting_ = true
│   ├── VoimeAddon::refreshTogglePreview()
│   └── IpcClient::start(segmentId, Toggle)
└── 判断 toggleActive_
    └── VoimeAddon::stopToggle()
        ├── toggleActive_ = false
        ├── clearPreview()
        ├── IpcClient::stop(0, Toggle)
        └── 判断 !finalizing_ → target_.ref.unwatch() + segmentId_.reset()

5.4 IPC 消息

IpcClient::onReadable()
└── IpcClient::handleLine(line)
    └── VoimeAddon::onIpcMessage(message)
        ├── SegmentStarted
        │   ├── segmentId_ = message.segmentId
        │   ├── target_.segment_id = *message.segmentId
        │   ├── 判断 source 非 Hold / Toggle → 绑定 mostRecentInputContext()
        │   ├── 判断 toggleActive_ && Toggle && !target_.focused() → 跟随当前焦点
        │   └── 判断 toggleActive_ → refreshTogglePreview()
        ├── State
        │   ├── recording_ = message.recording
        │   ├── finalizing_ = message.finalizing
        │   ├── 判断 recording_ → starting_ = false
        │   ├── 判断 !recording_ → 清空 / 空白 / 清理
        │   └── 判断 Idle && !toggleActive_ → unwatch + reset
        ├── Partial
        │   ├── 判断 segmentId 不匹配 → 忽略
        │   ├── 判断 target_.focused() → Preview::show
        │   └── 否则 clearPreview()
        └── Final
            ├── 判断 segmentId 不匹配 → 忽略
            ├── Preview::clear(target)
            ├── 判断 focused && text 非空 → InputContext::commitString(text)
            └── 判断 toggleActive_ → refreshTogglePreview() / 清理

5.5 失焦、断线与错误

fcitx5::InputContextFocusOut
└── focusWatcher_ lambda
    ├── 判断 target_.get() != event.inputContext() → 返回
    ├── 判断 toggleActive_ → VoimeAddon::stopToggle()
    └── 否则 Preview::clear(target_.get())

IpcClient::fail() / EOF
└── VoimeAddon::onDaemonDisconnected()
    ├── clearPreview()
    ├── target_.ref.unwatch()
    ├── segmentId_.reset()
    ├── holdActive_ / starting_ / toggleActive_ = false
    └── 热键恢复为普通按键

VoimeAddon::onIpcMessage(Error)
├── 判断 role_conflict / version_mismatch / invalid_message
│   └── IpcClient::disconnect() → 2 s 后重连
├── 判断 inference && toggleActive_
│   └── 重置状态 + refreshTogglePreview()
└── 判断 !recording_
    └── 清理 Toggle / PTT / target / preview
