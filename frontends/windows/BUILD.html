BUILD — frontends/windows

根：README USER CORE PROVIDER BUILD ｜ 本组件：README USER CORE PROVIDER ｜ 评估：WINDOWS

状态：目标 P3（Rust 托盘）与可选 P4（TSF）。以下命令在组件落地后生效； 当前仓库尚未包含 frontends/windows/Cargo.toml 与 tsf/。

本模块尚未实现；以下命令是目标构建流程。

1. 环境

↑

项目要求
系统Windows 10 / 11 x64；普通用户桌面会话。
RustMSVC 工具链；独立 workspace。
Windows SDKWin32 / UIA / TSF 头文件与库；TSF 需要 C++20 与 CMake。
共享 cratevoime-ipc、voime-transport 通过 path dependency 复用。
模型 / daemon由根 workspace 构建 voimed.exe / voime.exe；前端不加载模型。

2. 构建

↑

# Windows 前端（P3）
cd frontends/windows
cargo build --release

# 共享 crate + daemon / CLI（在仓库根）
cargo build --release -p voimed -p voime

# 可选 TSF（P4）
cmake -S frontends/windows/tsf -B build/tsf-x64 -A x64
cmake -S frontends/windows/tsf -B build/tsf-x86 -A Win32
cmake --build build/tsf-x64 --config Release
cmake --build build/tsf-x86 --config Release
产物说明
voime-tray.exe托盘 / 热键 / 目标 / 浮层 / SendInput。
voimed.exe / voime.exe由根 workspace 构建；前端通过命名管道连接。
onnxruntime.dll随 daemon 发布；前端不链接。
TSF DLL（可选）x86 / x64 两份；COM 注册后由目标应用加载。
  • frontends/windows 使用独立 Cargo.lock，避免 Windows-only 依赖污染 Linux 根构建。
  • Linux 上可跑 cargo check --target x86_64-pc-windows-msvc 做快速反馈，但不能替代 Windows 链接 / COM / TSF 验证。

3. 安装与启动

↑

# 每用户安装（目标流程）
voime-setup.exe

# 登录启动：当前用户 Startup / 计划任务
# 托盘拉起 daemon：voimed.exe --model-dir %LOCALAPPDATA%\voime\models
项目契约
安装每用户安装；不要求管理员，除非启用 TSF 注册。
登录启动当前用户登录后启动托盘；托盘负责拉起 daemon。
模型%LOCALAPPDATA%\voime\models；由根模型安装流程生成。
TSF 注册可选阶段；COM / TSF profile 注册通常需要管理员，按用户启用。
卸载停止托盘与 daemon；删除二进制、登录启动项、TSF 注册与按需保留的模型目录。
  • 不要把 daemon 装成 Session 0 服务：无法可靠访问交互用户麦克风，也破坏隐私边界。
  • 模型下载与 daemon 安装见根 BUILD §3。

4. 测试

↑

# Windows 前端
cd frontends/windows
cargo test
cargo clippy --all-targets
cargo fmt --check

# 共享 crate（仓库根）
cargo test -p voime-ipc -p voime-transport

# TSF（可选）
cmake --build build/tsf-x64 --config Release
ctest --test-dir build/tsf-x64 -C Release --output-on-failure
类别用例
系统Windows 10 22H2、Windows 11 23H2 / 24H2（x64）；中英文系统；100% / 150% / 200% DPI；多显示器。
应用Notepad、Word、Outlook、Chrome、Edge、Firefox、VS Code、Windows Terminal、PowerShell、WPF / WinForms、UWP Notepad、管理员控制台、RDP 客户端。
目标前台窗口稳定、窗口内切换焦点、目标关闭、提权窗口、锁屏。
输入中文 / 英文 / emoji / 长文本；IME 开启状态；SendInput 失败。
传输命名管道 ACL、拒绝远程、daemon 重启、慢读。
TSF（可选）Notepad 单应用提交、多应用、x86 / x64、注册 / 升级、组合 / 预览。

5. 发布

↑

产物说明
voimed.exe、voime.exe、voime-tray.exedaemon、CLI / TUI、托盘前端。
onnxruntime.dll与 daemon 一起分发。
安装器 / 登录启动项每用户安装；托盘拉起 daemon。
