BUILD — frontends/windows

状态：P3（Rust 托盘）已实现；P4（TSF）为可选阶段，当前分支未包含 tsf/。 以下命令在 Windows MSVC 工具链下执行。

1. 环境

↑

项目要求
系统Windows 10 / 11 x64；普通用户桌面会话。
RustMSVC 工具链；独立 workspace。
Windows SDKWin32 / UIA / TSF 头文件与库；TSF 需要 C++20 与 CMake。
共享 cratevoime-ipc、voime-transport、voime-log 通过 path dependency 复用。
设置窗口eframe / egui（glow / OpenGL）；随二进制分发，不依赖 WebView2、Node 或前端构建工具。
模型 / daemon由根 workspace 构建 voimed.exe / voime.exe；前端不加载模型。

2. 构建

↑

# Windows 前端（P3）
cd frontends/windows
cargo build --release

# 共享 crate + daemon / CLI（在仓库根）
cargo build --release -p voimed -p voime

# 可选 TSF（P4，当前分支未包含 tsf/）
# cmake -S frontends/windows/tsf -B build/tsf-x64 -A x64
# cmake -S frontends/windows/tsf -B build/tsf-x86 -A Win32
# cmake --build build/tsf-x64 --config Release
# cmake --build build/tsf-x86 --config Release
产物说明
voime-tray.exe托盘 / 热键 / 目标 / 浮层 / SendInput / egui 设置窗口；GUI 子系统构建，启动不显示控制台。
voimed.exe / voime.exe由根 workspace 构建；前端通过命名管道连接。
onnxruntime当前 ort 预编译包在 Windows 静态链接；如切换为动态链接，随 daemon 分发 onnxruntime.dll。前端不链接。
TSF DLL（可选）x86 / x64 两份；COM 注册后由目标应用加载。
  • frontends/windows 使用独立 Cargo.lock，避免 Windows-only 依赖污染 Linux 根构建。
  • 本目录被根 Cargo.toml exclude，VSCode 打开仓库根时 rust-analyzer 默认不加载本 workspace。可在本地 .vscode/settings.json（不入库）配置："rust-analyzer.linkedProjects": ["Cargo.toml", "frontends/windows/Cargo.toml"]。
  • Linux 上可跑 cargo check --target x86_64-pc-windows-msvc 做快速反馈，但不能替代 Windows 链接 / COM / TSF 验证。

3. 安装与启动

↑

# 每用户安装：构建、复制二进制、登录启动、安装模型
powershell -ExecutionPolicy Bypass -File packaging\windows\install.ps1

# 跳过构建 / 模型 / 登录启动
powershell -ExecutionPolicy Bypass -File packaging\windows\install.ps1 -NoBuild -NoModels -NoStartup

# 单独安装模型
powershell -ExecutionPolicy Bypass -File scripts\install_models.ps1 -ModelDir "$env:LOCALAPPDATA\voime\models"

# 卸载（可选删除设置与模型）
powershell -ExecutionPolicy Bypass -File packaging\windows\uninstall.ps1 -RemoveSettings -RemoveModels
项目契约
安装每用户安装到 %LOCALAPPDATA%\Programs\Voime；不要求管理员，除非启用 TSF 注册。
登录启动写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run；登录后启动托盘；托盘以子进程托管 daemon，退出托盘即停止。
模型%LOCALAPPDATA%\voime\models；由 scripts/install_models.ps1 生成。
日志启动托盘前设 VOIME_LOG=1（或目录路径）；托盘、设置窗口与 daemon 分别写 %LOCALAPPDATA%\voime\logs\voime-tray.log / voime-settings.log / voimed.log。
TSF 注册可选 P4；COM / TSF profile 注册通常需要管理员，按用户启用。
卸载停止托盘与 daemon；删除安装目录与登录启动项；-RemoveSettings / -RemoveModels 按需删除配置与模型。
  • 不要把 daemon 装成 Session 0 服务：无法可靠访问交互用户麦克风，也破坏隐私边界。
  • 模型下载与 daemon 安装见根 BUILD §3 / §4。

4. 测试

↑

# Windows 前端
cd frontends/windows
cargo test
cargo clippy --all-targets
cargo fmt --check

# 共享 crate（仓库根）
cargo test -p voime-ipc -p voime-transport -p voime-log

# TSF（可选 P4，当前分支未包含）
# cmake --build build/tsf-x64 --config Release
# ctest --test-dir build/tsf-x64 -C Release --output-on-failure
类别用例
系统Windows 10 22H2、Windows 11 23H2 / 24H2（x64）；中英文系统；100% / 150% / 200% DPI；多显示器。
应用Notepad、Word、Outlook、Chrome、Edge、Firefox、VS Code、Windows Terminal、PowerShell、WPF / WinForms、UWP Notepad、管理员控制台、RDP 客户端。
目标前台窗口稳定、窗口内切换焦点、目标关闭、提权窗口、锁屏。
输入中文 / 英文 / emoji / 长文本；IME 开启状态；SendInput 失败。
传输命名管道 ACL、拒绝远程、daemon 重启、慢读、协议 3。
模型选择设置窗口 Final 下拉、CPU / GPU 标识、不可用原因、待重启、重启失败保留旧选择；模型选择不写 config.json。
TSF（可选）Notepad 单应用提交、多应用、x86 / x64、注册 / 升级、组合 / 预览。

5. 发布

↑

产物说明
voimed.exe、voime.exe、voime-tray.exedaemon、CLI / TUI、托盘前端。
onnxruntime静态链接进 voimed.exe；动态链接构建时改为随包分发 onnxruntime.dll。
安装器 / 登录启动项每用户安装；托盘以子进程托管 daemon。
可选 TSF DLLx86 / x64 + 注册脚本；版本化，升级需重启应用。
模型下载 / 校验与 Linux 共用 manifest.json 与 SHA-256。
  • 发布前检查：托盘单实例、热键注册、目标失焦不误提交、提权窗口不注入、命名管道 ACL、无按键 / 音频 / 文本落盘。
  • 正式发布前需评估代码签名与隐私说明；安全软件可能对全局热键、麦克风与注入行为敏感。
