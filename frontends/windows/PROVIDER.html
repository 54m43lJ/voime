1. TERMS

↑

术语定义
HWNDWin32 窗口句柄；前台窗口由 GetForegroundWindow 取得。
UIAUI Automation；用于读取焦点元素与 RuntimeId。
RuntimeIdUIA 焦点元素的稳定标识；同一窗口内切换控件时变化。
SendInputWin32 合成输入 API；使用 KEYEVENTF_UNICODE 注入 UTF-16 单元。
RegisterHotKey注册系统范围热键；只提供按下，不提供 PTT 所需的 key-up。
GetAsyncKeyState轮询主键状态；PTT 松开检测使用此方式，同时用于读取录制时的实时修饰键。
UIPI用户界面特权隔离；阻止普通完整性进程向高完整性窗口注入。
DACL命名管道的访问控制列表；只授予当前用户。
TSFText Services Framework；Windows 输入法框架。
ITfContextTSF 的目标文档上下文；提交必须通过编辑会话。
ITfRangeTSF 文档范围；SetText 写入选区或组合范围。
edit sessionITfContext::RequestEditSession 调度的读写会话。
keyboard TIP / speech TIPTSF 文本服务类别；keyboard TIP 需成为当前输入法，speech TIP 的并行能力待验证。
CLSID / InprocServer32COM 类标识与进程内 DLL 注册表项。

2. CONVENTIONS

↑

约定内容
进程模型每用户桌面进程；不使用 Session 0 Windows 服务采集音频或注入文本。
热键全局热键用 RegisterHotKey；PTT 的 key-up 用 GetAsyncKeyState 轮询；录制使用设置窗口的 winit 键盘事件，不安装低级钩子，不记录其他按键。
目标前台窗口 + UIA 焦点元素；提交前复核 HWND 与 RuntimeId。
编码UTF-8 内部字符串转 UTF-16；emoji 代理对不拆分；长文本分批。
UIPI不尝试绕过；提权窗口默认不支持。
安全命名管道当前用户 DACL、拒绝远程客户端；不记录按键、音频或文本。
TSFDLL 是进程内 COM 组件；提交必须走 edit session；失败不注入其他窗口。
升级TSF DLL 版本化；运行中应用可能继续使用旧 DLL，需要重启应用或注销。
本地性所有 provider 调用在本机完成；运行期不联网。

3. DIAGRAMS

↑

3.1 命名管道与 daemon

  • 端点、DACL 与拒绝远程客户端由 voime-transport PROVIDER 定义。
  • 前端只处理字节流上的 JSON lines；消息语义见 voime-ipc USER。

3.2 目标绑定与 SendInput

  • 目标绑定使用前台 HWND + UIA RuntimeId；提交前复核。
  • SendInput 只注入目标；失败不重试其他窗口。

3.3 TSF 编辑会话

  • TSF 提交发生在目标应用进程内，使用该应用的 ITfContext。
  • 编辑会话可能失败；失败时保留 daemon 历史，不跨窗口注入。

4. INTERFACES

↑

4.1 Win32 / UIA 调用

调用 / 类型用途
RegisterHotKey / UnregisterHotKeyPTT / Toggle 全局热键注册；设置窗口打开时注销，关闭后重注册。
设置窗口键盘事件（winit）热键录制；只在窗口聚焦时读取，Esc 取消，窗口失焦停止。
GetAsyncKeyStatePTT 主键松开检测；录制时读取实时修饰键。
GetForegroundWindow / GetGUIThreadInfo取得前台窗口与焦点 HWND。
CoInitializeEx（STA）托盘与设置进程各自在主线程以 STA 初始化 COM；UIA 调用的前提。
UIA GetFocusedElement / RuntimeId取得焦点控件并复核目标；GetRuntimeId 返回 SAFEARRAY，按 LBound / UBound 读取后 SafeArrayUnaccessData，最后 SafeArrayDestroy；UIA 不可用时退化为只绑定 HWND。
winit 事件循环每个进程只允许创建一个事件循环；设置窗口因此运行在独立进程（voime-tray.exe --settings）。
SendInput + KEYEVENTF_UNICODE注入 UTF-16 文本。
CreateWindowExW + WS_EX_NOACTIVATE / WS_EX_TOOLWINDOW / WS_EX_TRANSPARENT创建无激活、置顶、点击穿透的浮层。
DPI / monitor API浮层定位与缩放。
Shell 通知区域 API托盘图标与菜单。

接口 / 机制作用
ITfTextInputProcessor / ITfTextInputProcessorEx文本服务生命周期；取得 ITfThreadMgr。
ITfThreadMgrEventSink跟踪焦点上下文与文档变化。

ITfUIElementSink / candidate UI可选候选 / 预览窗口；实现成本高。
ITfInputProcessorProfileMgr注册 / 激活语言 profile。
COM 注册 + InprocServer32CLSID、线程模型、DLL 路径；通常需要管理员权限，且需 x86 / x64 两份。

4.3 命名管道

项目契约
端点\\.\pipe\voime-<session>-<user>。
权限当前用户 DACL；拒绝远程客户端；不使用 Global\ 跨会话。
读写字节流；一行一个 JSON；最大 1 MiB；PROTOCOL_VERSION=4。
关闭关闭句柄并唤醒阻塞读；按重连策略重连。
GPU 边界前端不感知 GPU Final 选择，只消费 Final 文本；不链接 ONNX Runtime、DirectML 或 CUDA。

4.4 错误与边界

情况触发条件处理
热键注册失败组合被系统或其他应用占用、系统保留或缺少修饰键。设置窗口内提示；要求重新录制或清除 Hotkey；不静默吞键。
UIA 焦点不可用应用不暴露 UIA 或焦点元素为空。只绑定前台 HWND；提交前尽力复核。
UIPI 拒绝目标窗口完整性级别更高。不注入；保留历史；提示用户。
SendInput 部分失败目标拒绝或以 Unicode 处理异常。停止后续输入；不重复注入；记录错误码。
TSF 编辑会话失败只读、选区变化、上下文销毁。不提交；保留历史；不跨窗口重试。
管道断开daemon 退出或权限变化。隐藏浮层；放行热键；定时重连。
