2. CONVENTIONS

↑

约定内容
独立构建根frontends/windows 使用独立 Cargo workspace 与独立 Cargo.lock；不进入根 cargo test --workspace。
平台只构建 Windows 目标；Linux CI 不构建本 crate。
无模型不链接 ONNX Runtime，不加载模型，不做 VAD / CTC / 分段。
事件循环主线程拥有托盘与消息循环；IPC reader 线程把消息送入有界通道；热键 / 目标 / 浮层更新回到主线程。设置窗口在独立线程运行 egui 事件循环，保存结果通过通道回到主线程。
目标所有权目标窗口 / 焦点元素属于前端私有类型；协议只传 segment_id 与事件。
单实例每用户一个前端进程；重复启动激活已有托盘。
提交边界SendInput 只在目标复核通过后调用；失败不重试其他窗口。
日志只记录错误码、端点、热键注册与目标变化；不记录按键内容或识别文本。
TSFDLL 不加载模型；只通过命名管道连接 daemon；编辑会话失败不注入其他窗口。
  • 仓库级依赖方向见 根 CORE §2；平台 API 与安全约束见 PROVIDER。

pub struct Hotkey { /* modifiers + virtual key */ }

4.10 settings.rs 文件树

pub enum SettingsAction {
    Save {
        config: Config,
        ack: Sender<Result<(), String>>,
    },
    StartDaemon,
    StopDaemon,
}

pub fn run_process(config: Config, status: FrontendStatus,
                   focus_hotkey: bool) -> anyhow::Result<()>;
pub fn show_error(error: &anyhow::Error);
pub fn show_text(title: &str, text: &str);

fn run_window(config: Config, status: FrontendStatus,
              sender: Sender<SettingsAction>,
              focus_hotkey: bool) -> anyhow::Result<()>;
  • --settings 启动独立设置进程，run_process 在该进程主线程运行唯一的 egui 事件循环；保存、daemon 启停由动作线程执行，保存结果经 ack 返回窗口。
  • 保存前由动作线程用消息窗口校验热键可用性；注册冲突回显在窗口内。
  • 托盘打开设置前注销全局热键；设置子进程退出后托盘重新加载配置并恢复热键。

5.1 启动与连接

Windows 登录启动 / 用户双击
└── frontends_windows::main()
    ├── voime_log::init("voime-settings" | "voime-tray")

    ├── config::load()

        ├── Tray::create(&mut frontend)
        ├── frontend.attach_window(tray.hwnd())
        ├── Overlay::create()
        ├── frontend.try_connect()
        │   ├── IpcClient::connect(&Endpoint::NamedPipe(name))
        │   ├── IpcClient::send(Hello { role: Frontend, config })
        │   ├── IpcClient::snapshot()
        │   ├── frontend.sync_hotkey()
        │   └── frontend.on_message(snapshot)
        ├── frontend.start_daemon()（连接失败时）
        └── Windows 消息循环

5.2 热键到提交

热键事件
└── frontend::on_hotkey()
    ├── 判断 Mode == Ptt / Toggle
    ├── target::capture()
    ├── IpcClient::send(Start { segment_id, source })
    ├── IpcClient::send(Stop { ... })（松开或再次按下）
    └── 消息循环分发 ServerMessage

frontend::on_message(Partial)
└── Overlay::show(text, &target)

frontend::on_message(Final)
├── 判断 message.segment_id == target.segment_id
├── 判断 target::focused(&target) → 否则 on_target_lost()
├── 判断 Toggle 会话 active → Overlay::show_empty(&target)
├── 其他模式 → Overlay::hide()
└── commit::commit(&target, &text)

5.3 Continuous 与目标失效

frontend::on_message(SegmentStarted)
├── 判断 source == Continuous / Toggle 续段
├── 判断 Toggle 续段且原 target 失焦 → on_target_lost()
├── target::capture()
└── 判断 target::focused → 绑定；否则 on_target_lost()

frontend::on_focus_change()
├── 判断 !target::focused → Overlay::hide()
├── 判断 Mode == Toggle && (toggle_active || recording)
│   └── IpcClient::send(Stop { segment_id, Toggle })
└── 放弃当前段提交

5.4 断线与重连

IpcClient reader thread
└── read_message() 返回 EOF / 错误
    └── frontend::on_disconnect()
        ├── Overlay::hide()
        ├── target.clear()
        ├── 热键放行
        └── 定时重连
            ├── IpcClient::connect()
            └── IpcClient::snapshot()

5.6 设置窗口与 daemon 启停

└── frontend.open_settings(focus_hotkey)

    ├── hotkey::unregister()
    └── Command::new(current_exe, --settings --status=... --focus-hotkey)

设置进程
└── main(--settings)
    └── settings::run_process(config, status, focus_hotkey)
        ├── settings::run_window → eframe::run_native(Voime 设置)

            └── 判断 StopDaemon → control::stop_daemon()

frontend.tick()
└── poll_settings()
    └── 判断 settings_child 已退出 → config::load() → apply_settings()
        └── sync_hotkey()
