1. WHAT & WHY

↑

1.1 IDEAL：要解决的问题

Windows 没有 Fcitx 等价的后台 addon 模型：键盘、焦点与文本提交分散在 Win32、UI Automation 与 TSF 中。Voime 需要一个独立前端，在不复制识别链路的前提下，把热键、目标输入位置、 临时浮层与最终文本注入接到 voimed。托盘前端随核心安装一起安装，提供后台听写： 普通桌面进程 + 全局热键 + SendInput；TSF 是可选扩展，用于需要系统输入法身份的场景。 GPU 推理模块独立安装，只增加 Final 识别路径，不是前端的一部分。

1.2 GOAL：什么算成功

  • 只装核心即可在 Windows 使用托盘听写：热键、预览与提交不依赖 GPU 模块；GPU 模块不是前端前提。
  • 用户按热键说话，浮层显示 Partial，Final 注入语音段开始时聚焦的输入位置。
  • 目标失焦、提权窗口、注入失败时不误提交；最终文本保留在 daemon 历史 / TUI。
  • 前端不加载模型、不做 VAD / Preview / Final；只消费 IPC 消息。
  • 命名管道只允许当前用户；不记录按键、音频或识别文本到磁盘。
  • Windows 目标、预览、提交语义与 Linux 等价；Final 后端不进入前端。
  • 安装、登录启动、托盘、卸载形成闭环；不把 daemon 装成 Session 0 服务。
  • 核心安装入口是 scripts/install-core.ps1；GPU 模块由独立 scripts/install-gpu.ps1 安装。

1.3 非目标

  • 不加载模型；不做 VAD / Preview / Final 或任何识别。
  • 不感知 Final 后端；不读取 final.backend，不选择 CPU / GPU，不因后端变化改变热键、浮层或提交。
  • 不管理 GPU worker；worker 由 voimed 拉起、重启与回收，前端不接触 worker 进程。
  • TSF 作为可选扩展，且不承诺与 keyboard TIP 并行。
  • 不承诺覆盖提权窗口、游戏 / Raw Input、锁屏 / 安全桌面、所有 UWP / 终端。
  • 不做跨平台 UI 抽象；Linux 前端与 Windows 前端各自实现。
  • 不使用 loopback TCP；默认传输是命名管道。
  • 不在前端内保存模型或识别历史。
  • 不负责协议消息定义；协议见 voime-ipc USER。
  • 不负责本机端点实现；传输见 voime-transport USER。
  • 不负责模型安装；核心 / GPU 模型分别由核心 / GPU 安装脚本写入 %LOCALAPPDATA%\voime\models。
  • 产品级术语与端到端契约见 根 USER；Windows API 细节见 PROVIDER。

2. 用户交互

↑

场景行为契约
安装核心 / 启动运行 scripts/install-core.ps1：每用户安装托盘与 daemon 到 %LOCALAPPDATA%\Programs\Voime，核心模型写入 %LOCALAPPDATA%\voime\models；登录启动写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run；托盘以子进程托管 daemon，退出托盘即停止。根 README §2 · USER §4.6
安装 GPU 模块运行独立脚本 scripts/install-gpu.ps1：安装 GPU worker、对应 runtime 与 GPU 模型；GPU 模块不是前端的一部分，前端不参与安装。后端选择见 根 USER §2 / §4.4。根 USER §4.4
配置托盘右键菜单或设置窗口设置 Mode / 浮层 / 登录启动；热键在设置窗口直接按键录制，默认组合避开系统保留键。Final 后端不是前端配置项。USER §4.1
daemon 生命周期登录启动托盘，托盘以子进程托管 daemon（唯一所有者）；托盘菜单与设置窗口提供启动、停止、诊断，退出托盘即停止 daemon。GPU worker 由 voimed 按配置加载，托盘不启动 worker。USER §4.6
PTT按住热键开启会话；会话内 VAD 软切分多个段；松开硬切分，结束当前段并停止监听；需要 key-up。USER §3.1
Toggle按一下开启会话，再按一下硬切分结束；会话内 VAD 连续软切分多个段；目标失焦自动结束；会话期间预览浮层保持可见。USER §3.1
ContinuousVAD 自动分段；热键不参与。USER §3.2
临时浮层显示当前 Partial；Final 触发后保留最后一条 Partial，不再更新；Final 或丢弃结果到达后清空（Toggle 会话保留空白浮层）。不抢焦点、可点击穿透。USER §3.4
最终提交SendInput 注入 UTF-16 文本；提交前校验目标。USER §4.2
daemon 不可用放行热键、清空浮层、定时重连。USER §4.5
