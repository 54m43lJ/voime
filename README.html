分支范围：本分支包含跨平台源码、构建清单、脚本、模型清单与文档； frontends/windows（P3 托盘 / 后台听写）与 packaging/windows 已落地；TSF（P4）保持可选，未包含在本分支。

1. WHAT & WHY

↑

1.1 IDEAL：要解决的问题

桌面语音输入通常依赖云服务、独立输入法或 GPU 推理环境。Voime 把语音识别放在本机： 一个常驻 daemon 持有音频、VAD、ASR、标点与会话历史，平台前端只负责热键、目标输入位置、 临时文本与最终提交。Linux 前端运行在 Fcitx5 内；Windows 前端以独立桌面进程提供后台听写。 运行时不联网、不上传音频；默认不需要 GPU 或 Python，只有可选的 GPU Final 才使用 voime-gpu-firered 或 voime-gpu-qwen3。

1.2 GOAL：什么算成功

  • Linux 上安装 voime addon 后，addon 随 Fcitx5 在后台加载，不注册输入法条目；Windows 上安装前端后，用户可在支持的桌面应用中按热键说话。
  • 前端配置一个模式：ptt（按住说话）、toggle（按一下切换）或 continuous（VAD 自动分段）。
  • 前端配置一个热键；ptt 按住说话，toggle 切换录音，continuous 忽略热键。
  • 说话期间显示当前段的临时文本；最终结果提交到语音段开始时聚焦的输入位置，失焦时不向其他窗口注入。
  • 音频、模型、VAD、SenseVoice 与会话历史由独立 voimed 守护进程持有；GPU Final 由可选的 voime-gpu-firered（FireRed AED + FireRedPunc）或 voime-gpu-qwen3（Qwen3-ASR）处理。
  • 可选 TUI 连接 daemon，显示模式、热键、临时结果与历史；关闭 TUI 不影响热键、临时窗口与上屏。
  • 模型安装默认只装 SenseVoice + VAD；--firered 追加 FireRed AED + Punc，--qwen3 追加 Qwen3-ASR 1.7B；两个 GPU 选项可同时安装。
  • 运行时不需要网络与 Python；默认纯 CPU，GPU 只用于 Final；模型由安装脚本生成，voimed 完全离线运行。

1.3 非目标

  • 不做拼音、形码、候选词或通用键盘输入法；Voime 只负责语音文本的提交。
  • 不实现跨平台统一 UI 抽象；各平台前端保留自己的热键、目标、预览与提交实现。
  • 不保证锁屏、安全桌面、提权窗口、游戏或未使用受支持输入协议的应用。
  • 不使用客户端 preedit 作为 Linux 临时文本；Fcitx 输入面板由宿主渲染。
  • 不把 GPU 用于 Preview，不并行运行多个 Final，不做 CPU AED / CPU Qwen；GPU 只通过两个模型专用的独立 worker 运行，不引入通用 runtime 插件或动态 EP 选择。
  • 不实现规则纠错、文本改写、摘要或翻译；不增加 --rewrite 或文本后处理阶段。
  • 不保存音频、按键或识别历史到磁盘。

2. 用户交互

↑

场景行为详细契约
Linux 安装 addon 把 voime.so 与 addon 描述文件安装到 Fcitx5，重启 Fcitx；Voime 作为后台 addon 加载，不需要加入输入法组。 fcitx-addon BUILD · fcitx-addon USER
配置 Linux 在 fcitx5-configtool 或 ~/.config/fcitx5/conf/voime.conf 中设置 Mode 与 Hotkey；Windows 在托盘右键菜单或设置窗口中配置，热键通过按键录制。 fcitx-addon USER §4.1 · windows USER §4.1
选择 Final 模型 配置界面列出 Final 候选，显示 CPU / GPU 与可用性；选择后显示“待重启”，重启后端只重建 Final，Preview 仍由 SenseVoice 处理。 根 USER §4.1 · voimed USER §4.2 · fcitx-addon USER §4.1 · windows USER §5
PTT 模式 Mode=ptt：按住 Hotkey 开始，松开结束；按住期间可被静音自动结束。 fcitx-addon USER §3.1 · windows USER §3.1
Toggle 模式 Mode=toggle：按一下 Hotkey 开始，再按一下结束；每个 Final 后清空文本但保留空白临时窗口；目标失焦或断线时自动结束。 fcitx-addon USER §3.1 · windows USER §3.1
Continuous 模式 Mode=continuous：忽略热键，VAD 检测到语音起点即开始、终点即结束；无需按键。 fcitx-addon USER §3.2 · windows USER §3.2
临时文本窗口 说话期间显示当前段的 Partial；Toggle 会话在 Final/空段/ASR 错误后保持空白窗口，直到再次按热键关闭、目标失焦或断线；PTT / Continuous 在 Final 后清空。 fcitx-addon USER §3.3 · windows USER §3.4
最终结果 语音段结束后识别并加标点，提交到语音段开始时聚焦的输入位置；失焦则不提交。 fcitx-addon USER §4.2 · windows USER §4.2
普通输入 除热键外的按键全部由宿主或系统正常处理；Voime 不抓取、不转发普通按键。 fcitx-addon USER §2 · windows USER §2
TUI voime 可选连接 daemon，显示模式、热键、临时结果与历史；q 只 detach。 voime USER
停止 daemon Linux 使用 voime ctl quit 或停止 systemd 用户服务；Windows 托盘托管 daemon，托盘菜单 / 设置窗口的“停止服务并退出”会停止服务并退出托盘。 voimed USER §4.1 · voime USER §4.2
运行环境缺失 前端未加载、daemon 未启动或没有文本焦点时，在日志 / doctor 说明原因；不静默注入文本。 voime USER §4.4 · windows USER §4.5
