Voime — 纯本地语音输入法

USER CORE PROVIDER BUILD ASR

1. WHAT & WHY

↑

1.1 IDEAL：要解决的问题

Hyprland / Wayland 上的语音输入通常要依赖云服务、GPU，或者在 Fcitx5 旁边再挂一个剪贴板工具。 本项目用一个常驻 daemon 取代 Fcitx5 的输入法位置：它和普通输入法一样接管键盘、在任意窗口响应全局 PTT、把识别结果直接写进当前输入框，同时把非 PTT 按键原样交还给应用。全部识别与标点都在本机 CPU 上完成，运行时不联网、不上传音频。

1.2 GOAL：什么算成功

  • 停用 Fcitx5 后，voimed 成为该 seat 上唯一的输入法；启动失败时明确提示冲突，不静默降级。
  • 用户在任意窗口按住 Super+F2（可配置）说话、松开结束；再提供一个“按一下开始 / 再按一下结束”组合键。
  • 普通键盘输入不受影响：除 PTT 组合键外，字符、修饰键、快捷键、组合键和长按重复都保持原有行为。
  • 原生 Wayland 应用通过输入法协议在光标处插入最终文本；中文、英文、标点和 emoji 都按 UTF-8 原样提交。
  • XWayland 应用与没有 text-input 的应用通过剪贴板 + 粘贴回退，保证“能输入”。
  • PTT 每次录音硬上限 30 s；TUI 显示 ● Remaining: xx s，达到上限自动结束当前句并立即开始下一段。
  • daemon 与 TUI 分离：voimed 拥有音频、模型、输入法、键盘抓取、上屏与会话历史；voime 只是可选监视器。
  • TUI 关闭、崩溃或从未启动时，PTT、普通打字与上屏仍然工作。
  • 提供最小托盘：图标 + 右键菜单，菜单只有“退出”；没有托盘宿主时静默降级。
  • 识别链路为 FireRedVAD → FireRedASR2-CTC → FireRedPunc，全部在本机 CPU 上完成。
  • 单个 daemon 加本地模型包即可运行；运行时不需要网络、GPU、Python 或云服务。
  • 首次安装由项目脚本完成；安装完成后运行期完全离线。

1.3 非目标

  • 不实现拼音、形码、候选词、云输入或屏幕软键盘；Voime 只负责语音文本上屏。
  • 不与 Fcitx5 / IBus 共存为两个输入法，也不实现 Fcitx5 插件；运行 voimed 前必须停用其他输入法。
  • 不实现 X11 与 Windows 后端；本版只支持 Hyprland / Wayland，XWayland 仅做兼容回退。
  • 不保证 XWayland 的 preedit、临时结果或光标位置；XWayland 只保证最终文本能粘贴进去。
  • 不保存音频或识别历史到磁盘；daemon 退出后会话历史丢失。
  • 不自动把整段会话写入剪贴板；剪贴板只在回退粘贴时承载单条最终文本。
  • 不提供设置界面、悬浮窗、通知或托盘菜单之外的 GUI；所有配置在命令行完成。
  • 不调用云 ASR、云标点，不做说话人分离、语种识别、翻译、润色或大模型改写。

2. 用户交互

↑

场景行为详细契约
启动 daemon 停用 Fcitx5 后启动 voimed；它可以由 Hyprland exec-once 或 systemd user service 拉起，不要求终端。 USER §2 · USER §4.1
启动 TUI voime 连接 daemon，显示会话与录音状态；TUI 是可选监视器，关闭不影响 daemon。 USER §2 · USER §5
按住说话 按住默认 Super+F2 开始录音，松开结束；组合键可在命令行配置。 USER §2 · USER §4.1
按一下切换 按一次默认 Super+F3 开始，再按一次结束；录音收尾期间的重复按下被忽略。 USER §2 · USER §4.1
普通打字 PTT 组合键以外，字符、快捷键、组合键和修饰键在任意应用中照常工作。 USER §2
最终结果（原生 Wayland） 文本直接插入当前输入框的光标位置，不覆盖剪贴板。 USER §2 · USER §3
最终结果（XWayland / 终端） 写入单条最终文本到剪贴板并发送粘贴快捷键；终端使用 Ctrl+Shift+V，普通应用使用 Ctrl+V。 USER §2 · PROVIDER §4.4
临时结果 录音过程中 TUI 当前行按固定节奏刷新未加标点的临时文本；不同语音段不共享同一行。 USER §5.2
PTT 倒计时 录音时在临时行上方显示 ● Remaining: xx s，从 30 s 递减；continuous 不显示。 USER §5.2
清空工作区 TUI 中按 Ctrl+X 清空已完成结果与内存会话历史；剪贴板保持不变。 USER §2 · USER §5.2
关闭 TUI q 或 Ctrl+C 只断开 TUI；PTT、普通打字与上屏继续运行。 USER §2 · USER §3.7
退出 daemon voime ctl quit 或托盘右键“退出”；退出前取消当前段，不产生最终结果。 USER §2 · USER §5.3
安装模型 首次使用前运行 scripts/install_models.sh 安装 FireRedVAD / FireRedASR2-CTC / FireRedPunc 模型包；安装需要网络，完成后应用离线运行。 BUILD §3 · PROVIDER §4.2
启动失败 模型缺失 / 校验失败、没有录音设备、Wayland 或输入法不可用、Fcitx5 占用 seat 时，把原因写到 stderr 并以非零码退出。 USER §4.1 · PROVIDER §4.6
