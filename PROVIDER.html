1. TERMS

↑

术语定义
输入设备（Input device） 操作系统暴露的录音端点。Linux 上由 ALSA / PulseAudio / PipeWire 提供；cpal 把它们统一为 Device。
宿主（Host） cpal 对某个平台音频后端的抽象；cpal::default_host() 返回当前系统的默认宿主。
AudioChunk 音频回调交付的一块交织 PCM 样本，带原生采样率与声道数；样本已归一化为 f32。
帧（Frame） VAD 的一次推理单位。帧移由模型包 manifest 声明，推荐 10 ms；所有帧等长，末帧不补零。
fbank Kaldi 风格的梅尔滤波器组特征。FireRedVAD、FireRedASR2-CTC 的输入特征；参数以模型包 manifest 为准。
语音概率（Speech probability） FireRedVAD 对每一帧输出的 [0, 1] 概率；分段器按阈值与最短时长把它转成语音段边界。
流式状态（Streaming state） FireRedVAD 在帧间保留的缓存张量；每次推理的输出状态在下一帧作为输入回灌，语音段结束时必须清零。
FireRedASR2-CTC FireRedASR2 的 CTC 分支；单个 ONNX 图，Conformer 编码器 + 线性 CTC head，本项目默认 ASR 模型。
CMVN 倒谱均值方差归一化。CTC 模型的均值 / 逆标准差存放在 ONNX metadata 的 cmvn_mean / cmvn_inv_stddev；运行期先归一化 fbank 再推理。
greedy CTC 逐帧取 argmax，合并连续重复 token，再过滤 blank 0 的解码方式；不做 beam search。
FireRedPunc 基于 BERT 的 token 级标点分类模型；对每个输入 token 预测其后应插入的标点标签。
标点标签（Label） FireRedPunc 输出向量中的一项；labels.json 把 id 映射为实际插入的字符串，id 0 为空字符串。
模型包（Model package） 由安装脚本从 FireRed 官方权重生成或下载的 ONNX 文件、词表、标签表与校验和集合；由 manifest.json 描述，权重不提交到仓库。
ONNX Runtime 执行 ONNX 模型的推理库；本项目只使用 CPU Execution Provider，由 ort 绑定。
Wayland input-method-v2 zwp_input_method_manager_v2 / zwp_input_method_v2：输入法占用 seat、接收 text-input 状态并提交文本的协议。
键盘抓取（grab_keyboard） zwp_input_method_v2.grab_keyboard() 返回的 zwp_input_method_keyboard_grab_v2；输入法通过它接收整个 seat 的硬件键盘事件。
text-input-v3 zwp_text_input_v3：应用向合成器声明输入框、接收提交文本的协议；input-method-v2 只与 text-input 应用交换文本。
virtual-keyboard zwp_virtual_keyboard_manager_v1 / zwp_virtual_keyboard_v1：客户端向合成器注入 keymap、key 与 modifiers 的协议。
xkb keymap 键盘布局描述；grab 的 keymap 事件提供它，输入法用它把 keycode + modifiers 转成 keysym，并同步给 virtual-keyboard。
Hyprland IPC Hyprland 的 Unix socket 控制接口；j/activewindow 返回当前窗口的 class、title 与 xwayland 标志。
XWayland 在 Wayland 合成器内运行 X11 应用的兼容层；X11 客户端不使用 text-input-v3，因此不能接收 input-method-v2 的提交。
XTEST X11 扩展，用于向 X server 注入按键；本项目只在 XWayland 粘贴兜底时使用。
StatusNotifierItem D-Bus 托盘图标规范；由 daemon 注册，宿主通过 StatusNotifierWatcher 发现 item。
DBusMenu D-Bus 菜单规范；托盘右键菜单只有“退出”。
StatusNotifierWatcher / Host 发现并显示 StatusNotifierItem 的 D-Bus 服务与桌面宿主；缺失时托盘不可见，但不影响 daemon。
剪贴板所有者（Clipboard owner） 在 X11 中负责响应剪贴板内容请求的进程。写入文本的进程退出后，若无剪贴板管理器接管，内容可能丢失。
备用屏幕（Alternate screen） 终端模拟器提供的第二块屏幕缓冲区；TUI 退出后恢复原屏幕，不污染终端回滚区。

2. CONVENTIONS

↑

约定内容
契约范围 本节只记录项目实际消费的接口子集；cpal、ONNX Runtime、arboard、crossterm、Wayland 协议、Hyprland IPC 与 StatusNotifierItem 的完整定义以各自官方文档为准。
本地性 运行期所有边界调用都在本机完成；模型包、音频、剪贴板均不经过网络。安装脚本在首次安装时访问模型托管站点，该步骤不属于运行时边界。
音频格式 进入项目内部的唯一格式是 16 kHz、单声道、f32。设备原生格式的转换属于项目侧，不要求 Provider 支持重采样。
采样格式 只接受 I16、U16、F32 三种输入样本格式；其他格式在启动时以 UnsupportedSampleFormat 失败。
模型不可变 模型包在运行期只读；启动时校验 SHA-256 与张量签名，校验失败不进入 daemon 事件循环。运行期不重新读取权重。
模型上限 FireRedASR2-CTC 单段音频硬上限 60 s；项目把 PTT 硬上限限制为 30 s，超过 30 s 由项目分段，Provider 不再截断或补零。
标点上限 FireRedPunc 的单次 token 上限由 manifest 声明，推荐 400；超长文本由 CORE 切块，Provider 不静默截断。
CPU 推理 只启用 CPU Execution Provider；不注册 CUDA、DirectML、Vulkan 或其他执行提供者。线程数由命令行决定。
输入法唯一性 一个 seat 只允许一个 input-method-v2 对象。Fcitx5 / IBus 必须先停用；第二个输入法会收到 unavailable。
键盘抓取 Voime 持有 grab_keyboard 并接收 seat 的全部键盘事件；非 PTT 按键与 modifiers 必须原样转发到 virtual-keyboard。
同连接 input-method-v2、keyboard grab 与 virtual-keyboard 使用同一个 wl_display；Hyprland 据此抑制 IM 自己注入的按键。
合成器优先级 Hyprland 先处理 bind / bindr，再把剩余按键交给 IM grab；PTT 组合键不得与合成器绑定冲突。
XWayland 边界 XWayland 不使用 text-input-v3，commit_string 到不了；最终文本走剪贴板 + 粘贴，PTT 与普通按键转发仍可用。
剪贴板文本 只写 UTF-8 纯文本，内容为单条最终文本，不含会话前缀、临时结果或错误信息；不写 HTML、图片或多格式剪贴板对象。
终端能力 终端能力与 crossterm 只属于 voime TUI；voimed 不要求 TTY、不启用 raw mode / 备用屏幕。TUI 要求 TTY、UTF-8 与 ANSI 转义支持。
托盘依赖 托盘依赖 StatusNotifierWatcher / 宿主；缺失时只记录 warning，daemon 继续运行。D-Bus session bus 不可用时托盘不可见，但 voime ctl quit 仍可用。
错误映射 Provider 错误在边界处转换为项目错误类型并附上上下文；错误文本不进入 TUI 内容区，启动期写 stderr，运行期按 §4.6 处理。
  • 权威定义：cpal、ort / ONNX Runtime、arboard、crossterm、input-method-unstable-v2、virtual-keyboard-unstable-v1、StatusNotifierItem。
  • 模型来源：FireRedASR2-CTC int8、FireRedVAD、FireRedPunc。

3. DIAGRAMS

↑

3.1 音频采集边界

  • 回调只负责把设备样本转换为 AudioChunk 并入队；重采样与 VAD 在项目内部完成，不属于 cpal 边界。
  • 错误回调与数据回调可能来自不同线程；错误以零长度错误标记写入同一有界通道，由工作线程维护连续错误计数。

3.2 模型推理边界

  • VAD、CTC 与标点分别使用独立的 ONNX 会话；会话在启动时创建，运行期只调用 run。
  • CTC 的 CMVN 从 ONNX metadata 读取；VAD / Punc 的 CMVN 与归一化在导出时融合进模型图。

3.3 input-method-v2 键盘与提交边界

  • grab_keyboard 返回的 keyboard grab 接收 keymap / key / modifiers / repeat_info；commit_string + commit(serial) 写回 text-input 应用。
  • unavailable 是唯一的失败事件；对象随后 inert，项目直接退出。

3.4 virtual-keyboard 转发边界

  • virtual-keyboard 只发送 keymap、key 与 modifiers；不发送文本、不实现输入法。
  • IM 自己注入的按键必须被合成器识别为同一客户端，否则会再次进入 grab。

3.5 剪贴板与粘贴回退

  • 只有输入法 inactive 或显式 clipboard sink 才写剪贴板；内容为单条 Final，不写会话。
  • 粘贴键优先经 virtual-keyboard；XWayland 下失败时用 XTEST 兜底。

3.6 Hyprland 焦点与终端识别

  • j/activewindow 的 xwayland 标志与 class 决定粘贴键；普通 GUI 用 Ctrl+V，终端用 Ctrl+Shift+V。
  • 查询失败不阻塞 PTT 或普通按键转发；只影响 Final 的粘贴目标。

3.7 StatusNotifierItem 托盘

  • 托盘只提供图标与“退出”菜单；没有宿主时静默降级。
  • 菜单 activate 只发送 TrayEvent::Quit，不触发录音或设置。

  • schema 固定为 2；asr.kind 为 fire-red-ctc 或 fire-red-aed（legacy）。CTC 包只需要 model.int8.onnx 与 tokens.txt。

错误触发条件处理
NoInputDevice系统没有默认输入设备。启动失败，stderr + 退出码 1。
DeviceNotFound--input-device 名称不存在。启动失败，stderr + 退出码 1。
DefaultConfig / BuildStream / PlayStream设备配置或流建立失败。启动失败，stderr + 退出码 1。
UnsupportedSampleFormat设备只提供 I16 / U16 / F32 之外的格式。启动失败，stderr + 退出码 1。
StreamLost运行期音频流错误。丢弃当前语音段；连续失败 3 次后关闭 daemon 并以 1 退出。
MissingFile / DigestMismatch模型文件缺失或被修改。启动失败，stderr + 退出码 1。
TensorMismatch / SessionONNX 元数据与 manifest 不符，或会话创建失败。启动失败，stderr + 退出码 1。
MissingMetadataCTC 模型缺少 CMVN metadata。启动失败；重新安装模型包。
AudioTooLong语音段超过 30 s / 60 s 上限。丢弃当前段；CORE 应在分段阶段避免触发。
ImUnavailableseat 已被其他输入法占用。启动失败，提示停用 Fcitx5 / IBus。
GrabFailed键盘抓取失败、keymap 超时或 grab 被销毁。关闭 daemon；没有 grab 就没有 PTT。
KeyForwardFailedvirtual-keyboard 发送失败。关闭 daemon，不能继续持有 grab 却不转发。
NoFocusedWindowFinal 产生时没有可投递焦点。文本留在剪贴板；记录 DeliveryFailed。
PasteFailed / ClipboardFailed粘贴键或剪贴板写入失败。文本可能仍在剪贴板；记录错误，下一次 Final 重试。
WaylandProtocol协议版本、对象状态或 4000 字节限制异常。启动期失败；运行期关闭 daemon。
TrayUnavailable没有 StatusNotifierWatcher / 宿主，或 D-Bus 不可用。只记录 warning；daemon 继续；voime ctl quit 仍可用。
NotATty / Terminal IoTUI 的 stdin / stdout 不是终端。TUI 启动失败，stderr + 退出码 1；daemon 不受影响。
  • 启动期错误一律在创建托盘 / 进入 TUI 之前报告；运行期错误不写入 TUI 内容区。
  • 错误文本包含失败的文件、设备、窗口或协议对象名，便于定位；不输出模型权重或用户音频内容。

4.7 Wayland input-method-v2

项目消费契约
管理器 / 对象zwp_input_method_manager_v2.get_input_method(seat) 创建 zwp_input_method_v2；一个 seat 最多一个。
键盘抓取zwp_input_method_v2.grab_keyboard() 返回 zwp_input_method_keyboard_grab_v2；启动后立即创建，整个 daemon 生命周期持有，deactivate 不释放。
keymapkeymap(format, fd, size)；格式为 WL_KEYBOARD_KEYMAP_FORMAT_XKB_V1 时用 xkbcommon 解析，并同步给 virtual-keyboard。
按键key(serial, time, key, state)；key 与 wl_keyboard.key 同语义（evdev code），xkb 查询时 + 8，VK 转发时原样发送。
修饰键modifiers(serial, depressed, latched, locked, group)；更新 xkb state 并转发 VK。
重复repeat_info(rate, delay)；优先让客户端按 repeat_info 重复，必要时由项目合成重复 press。
激活activate / deactivate / done；activate 表示有 text-input 焦点，commit_string 才有效。
提交commit_string(text) 后跟 commit(serial)；serial 等于已收到的 done 事件数。单次文本不超过 4000 字节。
preeditset_preedit_string(text, cursor_begin, cursor_end)；v1 不调用，Phase 2 可选。
不可用unavailable 是唯一事件；对象 inert，项目以 ImUnavailable 失败退出。
  • Hyprland 的 grab 是 seat 级：即使当前没有 text-input 焦点，仍会把按键交给 grab；项目据此在终端和 XWayland 窗口也提供 PTT。
  • 其他合成器可能只在 active 时路由按键；本项目只承诺 Hyprland / Wayland。
  • 合成器键绑定优先于 IM grab；PTT 组合键必须未被 Hyprland 绑定。

4.8 Wayland virtual-keyboard

项目消费契约
创建zwp_virtual_keyboard_manager_v1.create_virtual_keyboard(seat)；与 input-method-v2 同一个 wl_display。
keymapkeymap(format, fd, size)；在发送第一个 key 前必须设置；使用 grab 提供的 keymap。
按键key(time, key, state)；key 为 evdev code，state 为 pressed / released。
修饰键modifiers(depressed, latched, locked, group)；与物理键盘状态同步。
回环Hyprland 忽略持有 IM grab 的同一客户端注入的按键；IM 与 VK 共用连接是硬约束。
粘贴发送 Ctrl+V / Ctrl+Shift+V 的 key / modifiers 序列；不发送文本。
  • virtual-keyboard 是普通按键转发的唯一通道；它失效时普通打字与粘贴都会失效。
  • 不通过 virtual-keyboard 逐字输入最终文本；最终文本走 input-method 提交或剪贴板。

4.9 Hyprland 焦点与粘贴

项目消费契约
查询Hyprland IPC j/activewindow；返回 class、title、xwayland。
终端识别默认 class：kitty、foot、Alacritty、org.wezfurlong.wezterm、com.mitchellh.ghostty、XTerm；可用 --terminal-class 追加。
粘贴键普通 GUI：Ctrl+V；终端：Ctrl+Shift+V。优先经 VK 发送；XWayland 下 VK 失败时用 XTEST 兜底。
无焦点不发送粘贴键，记录 NoFocusedWindow；文本留在剪贴板。
  • XWayland 只保证“能输入”，不保证 preedit、临时结果或光标位置。
  • 终端里粘贴的是命令文本，用户按 PTT 时应当明确目标；项目不额外做终端安全确认。

4.10 preedit（Phase 2）

项目消费契约
提交set_preedit_string(text, cursor_begin, cursor_end)；cursor 以字节计，隐藏光标时两者为 -1。
清除set_preedit_string("", 0, 0) 后 commit(serial)。
长度单次不超过 4000 字节；按 UTF-8 字符边界截断。
启用--preedit 才启用；v1 默认关闭，临时结果只在 TUI 显示。
  • preedit 只影响原生 Wayland text-input 应用；XWayland 与终端没有 preedit。
  • 临时结果更新频率与 ASR 相同，不额外增加推理。

4.12 StatusNotifierItem / DBusMenu 托盘
