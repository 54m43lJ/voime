1. TERMS

↑

术语定义
输入设备（Input device） 操作系统暴露的录音端点。Linux 上由 ALSA / PulseAudio / PipeWire 提供，Windows 上由 WASAPI 提供；cpal 把它们统一为 Device。
宿主（Host） cpal 对某个平台音频后端的抽象；cpal::default_host() 返回当前系统的默认宿主。
AudioChunk 音频回调交付的一块交织 PCM 样本，带原生采样率与声道数；样本已归一化为 f32。
帧（Frame） VAD 的一次推理单位。帧移由模型包 manifest 声明，推荐 10 ms；所有帧等长，末帧不补零。
fbank Kaldi 风格的梅尔滤波器组特征。FireRedVAD、FireRedASR2-AED 的输入特征；参数以模型包 manifest 为准。
语音概率（Speech probability） FireRedVAD 对每一帧输出的 [0, 1] 概率；分段器按阈值与最短时长把它转成语音段边界。
流式状态（Streaming state） FireRedVAD 在帧间保留的缓存张量；每次推理的输出状态在下一帧作为输入回灌，语音段结束时必须清零。
FireRedASR2-AED FireRedASR2 的 Attention-based Encoder-Decoder 变体；本项目唯一的 ASR 模型。
编码器 / 解码器（Encoder / Decoder） AED 的两个 ONNX 会话：编码器把 fbank 序列编码为声学表示；解码器在编码结果上自回归生成 token。
beam search 解码器逐步保留若干候选 token 序列的搜索策略；本项目的实现约束见 CORE §4.14。
FireRedPunc 基于 BERT 的 token 级标点分类模型；对每个输入 token 预测其后应插入的标点标签。
标点标签（Label） FireRedPunc 输出向量中的一项；labels.json 把 id 映射为实际插入的字符串，id 0 为空字符串。
模型包（Model package） 由 manifest.json 描述的 ONNX 文件、词表、标签表与校验和的集合；权重不提交到仓库。
ONNX Runtime 执行 ONNX 模型的推理库；本项目只使用 CPU Execution Provider，由 ort 绑定。
剪贴板所有者（Clipboard owner） 在 X11 中负责响应剪贴板内容请求的进程。写入文本的进程退出后，若无剪贴板管理器接管，内容可能丢失。
备用屏幕（Alternate screen） 终端模拟器提供的第二块屏幕缓冲区；应用退出后恢复原屏幕，不污染终端回滚区。

2. CONVENTIONS

↑

约定内容
契约范围 本节只记录项目实际消费的接口子集；cpal、ONNX Runtime、arboard、crossterm 的完整定义以各自官方文档为准，不复制进本文档。
本地性 所有边界调用都在本机完成；模型包、音频、剪贴板均不经过网络。运行期不存在 HTTP / WebSocket / D-Bus 依赖。
音频格式 进入项目内部的唯一格式是 16 kHz、单声道、f32。设备原生格式的转换属于项目侧，不要求 Provider 支持重采样。
采样格式 只接受 I16、U16、F32 三种输入样本格式；其他格式在启动时以 UnsupportedSampleFormat 失败，不做隐式转换。
模型不可变 模型包在运行期只读；启动时校验 SHA-256 与张量签名，校验失败不进入 TUI。运行期不重新读取权重。
量化 模型包默认提供 int8 量化 ONNX；导出工具必须在固定验证集上确认识别与标点质量后再发布。运行时只加载 manifest 声明的精度，不在启动时做动态量化。
清单权威 ONNX 输入 / 输出名称、形状、fbank 参数、帧移、标签表都由 manifest.json 声明；代码不得硬编码张量名或形状。
模型上限 FireRedASR2-AED 单段音频硬上限 60 s；超过上限由 CORE 拒绝，Provider 不再截断或补零。
标点上限 FireRedPunc 的单次 token 上限由 manifest 声明，推荐 400；超长文本由 CORE 切块，Provider 不静默截断。
CPU 推理 只启用 CPU Execution Provider；不注册 CUDA、DirectML、Vulkan 或其他执行提供者。线程数由命令行决定。
剪贴板文本 只写 UTF-8 纯文本，行分隔符固定为 \n；不写 HTML、图片或多格式剪贴板对象。
终端能力 要求 TTY、UTF-8 与 ANSI 转义支持；不要求真彩色、鼠标、括号粘贴或键盘增强协议。鼠标上报必须关闭。
错误映射 Provider 错误在边界处转换为项目错误类型并附上上下文；错误文本不进入 TUI 内容区，启动期写 stderr，运行期按 §4.6 处理。
  • 权威定义：cpal、ort / ONNX Runtime、arboard、crossterm。
  • 模型来源与推理代码：FireRedASR2S、FireRedVAD、FireRedPunc。

3. DIAGRAMS

↑

3.1 音频采集边界

  • 回调只负责把设备样本转换为 AudioChunk 并入队；重采样与 VAD 在项目内部完成，不属于 cpal 边界。
  • 错误回调与数据回调可能来自不同线程；错误通过独立通道交给工作线程，不在回调中恢复设备。

3.2 模型推理边界

  • VAD、ASR 编码器、ASR 解码器与标点分别使用独立的 ONNX 会话；会话在启动时创建，运行期只调用 run。
  • 模型文件由 tools/export_models.py 从 FireRed 官方权重导出；张量名与形状写入 manifest，不在图中固定。

3.3 剪贴板边界

  • 每次最终结果后整体覆盖写入会话文本；不追加、不保留旧剪贴板内容。
  • X11 下剪贴板内容由本进程持有；程序退出后能否保留取决于桌面剪贴板管理器，见 §4.4。

4.3 推理运行时：ONNX Runtime / ort

消费项签名 / 类型用途
环境ort::environment::Environment进程级 ONNX Runtime 环境；启动时创建一次。
会话构建Session::builder() + with_intra_threads(n) + commit_from_file(path)为 VAD、编码器、解码器、标点分别建立会话。
图优化GraphOptimizationLevel::Level3启用全部 CPU 图优化。
张量ort::value::Tensor<f32> / Tensor<i64>输入 fbank、token ids、mask；输出概率与 logits。
执行Session::run(inputs)单次同步推理；不并发调用同一会话。
pub enum ModelError {
    MissingFile { path: PathBuf },
    DigestMismatch { path: PathBuf },
    TensorMismatch { name: String, expected: String, actual: String },
    Session(ort::Error),
    AudioTooLong { max_ms: u64 },
}
  • 只使用 CPU Execution Provider；不调用 with_execution_providers 注册 GPU 后端。
  • 会话由 pipeline 工作线程独占，run 不在多个线程间共享；ONNX Runtime 的线程池只用于单个会话内部。
  • 推理错误在边界处转换为 ModelError，由 CORE 决定丢弃当前段还是终止启动。

4.4 剪贴板：arboard

消费项签名 / 类型用途
建立句柄arboard::Clipboard::new() -> Result<Clipboard, arboard::Error>启动时建立一次；失败则启动失败。
写入文本Clipboard::set_text<T: Into<String>>(&mut self, text: T) -> Result<(), arboard::Error>每次最终结果后整体覆盖会话文本。
pub enum ClipboardError {
    Unsupported,
    Occupied,
    WriteFailed { detail: String },
}
  • 写入内容为 UTF-8 纯文本，行分隔符 \n，无末尾换行；空会话不写入。
  • Linux：X11 下本进程是剪贴板所有者，退出后若没有剪贴板管理器接管，内容可能丢失；Wayland 由合成器管理，行为随桌面环境而定。Wayland 构建需启用 arboard 的 wayland-data-control 特性。程序不启动后台常驻进程来维持剪贴板。
  • Windows：剪贴板内容在进程退出后由系统保留；写入失败按 §4.6 处理。

错误触发条件处理
NoInputDevice系统没有默认输入设备。启动失败，stderr + 退出码 1。
DeviceNotFound--input-device 名称不存在。启动失败，stderr + 退出码 1。
DefaultConfig / BuildStream / PlayStream设备配置或流建立失败。启动失败，stderr + 退出码 1。
UnsupportedSampleFormat设备只提供 I16 / U16 / F32 之外的格式。启动失败，stderr + 退出码 1。
StreamLost运行期音频流错误。丢弃当前语音段；连续失败 3 次后恢复终端并以 1 退出。
MissingFile / DigestMismatch模型文件缺失或被修改。启动失败，stderr + 退出码 1。
TensorMismatch / SessionONNX 元数据与 manifest 不符，或会话创建失败。启动失败，stderr + 退出码 1。
AudioTooLong语音段超过 60 s 硬上限。丢弃当前段；CORE 应在分段阶段避免触发。
ClipboardUnsupported / Occupied剪贴板不可用或被占用。启动期失败；运行期不回滚结果行，下一次最终结果重试。
Clipboard WriteFailed写入系统剪贴板失败。不影响结果行；下一次最终结果整体重写。
NotATty / Terminal Iostdin / stdout 不是终端，或终端控制失败。启动失败，stderr + 退出码 1；运行期恢复终端后退出。
  • 启动期错误一律在进入备用屏幕之前报告；运行期错误不写入 TUI 内容区，以保持界面只有两个元素。
  • 错误文本包含失败的文件、设备或张量名，便于定位；不输出模型权重或用户音频内容。
