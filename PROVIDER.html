1. TERMS

↑

术语定义
Fcitx5 Linux 输入法框架；本项目作为 addon 运行在 fcitx5 进程内，由它持有键盘与输入上下文。
addon Fcitx 的可加载组件。Voime addon 在后台加载，不注册输入法条目；负责热键、目标输入框、临时窗口与最终提交。
输入上下文（InputContext） Fcitx 中代表一个客户端输入目标的上下文；提供 commitString、inputPanel、hasFocus。
frontend Fcitx 与客户端之间的输入协议实现，例如 Wayland text-input 或 XIM。Voime 不直接实现 frontend。
InputContextKeyEvent Fcitx 的按键事件；addon 在 PreInputMethod 阶段读取并决定是否消费。
PreInputMethod Fcitx 事件管线的输入法前阶段；Voime 的 PTT / toggle 热键在这里匹配。
InputPanel / preedit Fcitx 输入面板。Voime 用 setPreedit 把 Partial 写入面板，由 Fcitx UI 渲染临时窗口。
commit string / commit filter InputContext::commitString 提交的文本；Fcitx 的 commit filter 可能在到达客户端前转换文本。
Mode / Hotkey addon 配置；Mode 取 ptt / toggle / continuous，Hotkey 是唯一组合键。
XIM X11 输入法协议；Fcitx XIM frontend 用于 XWayland / X11 客户端。Voime 不实现 XIM。
FireRedASR2-CTC 本项目的离线 CTC 语音识别模型；单 ONNX，输入 fbank，输出 log_probs。
CMVN 倒谱均值方差归一化；CTC 模型把它放在 ONNX metadata 的 cmvn_mean / cmvn_inv_stddev 中。
greedy CTC 逐帧取 argmax、合并连续重复、去掉 blank 0 的解码方式。
token id 词表 tokens.txt 每行是 token 与 id；id 0 为 blank，英文 ▁ 表示词边界。
fbank Kaldi 风格梅尔滤波器组特征；参数由 manifest 声明，与 CTC 训练预处理一致。
模型包 FireRedVAD、FireRedASR2-CTC、FireRedPunc 的 ONNX、词表、标签与 manifest.json。

2. CONVENTIONS

↑

约定内容
契约范围 本节只记录项目实际消费的 Fcitx / cpal / ONNX Runtime / crossterm 子集；完整定义以官方文档为准。
Fcitx 版本 要求 Fcitx5 ≥ 5.1.23；KeyEventMatchingMode::MatchAllNormalizedKeys 与 checkKeyList 以该版本为准。
addon 加载 OnDemand=False；Fcitx 启动时后台加载 addon，不安装 inputmethod 条目。
键盘所有权 Fcitx 持有键盘与 frontend；Voime 不抓键盘、不转发按键、不注入按键。
热键范围 只有 Fcitx 能收到按键的输入上下文才触发热键；没有文本焦点、未使用 Fcitx 的窗口不保证。
热键消费 命中后调用 filterAndAccept；普通按键继续由 Fcitx 路由。
临时窗口 InputPanel::setPreedit + updateUserInterface(InputPanel)；Toggle 会话在 Final / 空段 / 单段错误后写入空白 preedit 保持窗口，直到 toggle off；停止 / 目标丢失 / 断线清空。
目标输入框 语音段开始时聚焦的 InputContext；提交前重新检查存在与 hasFocus()。
提交 commitString 无返回值；不保证客户端接受。Fcitx commit filter 与长文本分块由 Fcitx 负责。
addon ABI voime.so 与 Fcitx5 头文件绑定；Fcitx 大版本升级后重新编译。
配置 Mode / Hotkey 只来自 addon 配置；daemon 通过 IPC 接收；socket 使用默认路径。
本地性 运行期所有边界调用在本机完成；模型包、音频与 IPC 不经过网络。
音频格式 进入项目内部的唯一格式是 16 kHz、单声道、f32；设备原生格式由项目侧重采样。
模型不可变 模型包运行期只读；启动时校验 SHA-256 与张量签名，失败不进入运行态。
量化 默认 int8 ONNX；发布前在固定验证集上确认识别质量；运行期不做动态量化。
清单权威 ONNX 输入输出、fbank 参数、帧移、词表与标签由 manifest.json 声明；代码不硬编码形状。
CTC 上限 默认 max_segment_ms=30000；超过上限由分段器切段，Provider 不截断或补零。
CPU 推理 只启用 CPU Execution Provider；线程数由命令行决定。
错误映射 Provider 错误在边界处转换为项目错误类型并附上下文；启动期写 stderr / 日志，运行期按 §4.7 处理。

3. DIAGRAMS

↑

3.1 音频采集边界

  • 回调只负责把设备样本转换为 AudioChunk 并入队；重采样与 VAD 在项目内部完成。
  • 错误回调与数据回调可能来自不同线程；错误以零长度标记写入同一有界通道。

3.2 CTC 推理边界

  • 单 ONNX 会话；CMVN 从 metadata 读取；greedy CTC 在项目侧完成。
  • VAD 与 FireRedPunc 仍各自使用独立 ONNX 会话；会话在启动时创建。

3.3 Fcitx 按键与热键边界

  • Voime 在 PreInputMethod 读取事件；命中 Hotkey 后 filterAndAccept。
  • Mode 只影响 Voime 对热键的解释；普通按键继续由 Fcitx 交给当前输入法或应用。

3.4 Fcitx 输入面板边界

  • Partial 写入 InputPanel::setPreedit，由 Fcitx UI 渲染；Voime 不创建窗口。
  • Final / 停止 / 断线时清空 preedit；最终提交前先关闭窗口。Toggle 会话在 Final 后重新写入空白 preedit，直到 toggle off 或目标失焦。

3.5 Fcitx 提交边界

  • Voime 只调用 InputContext::commitString；Fcitx 选择 Wayland / XIM frontend 并处理长文本。
  • 目标输入框失焦或销毁时不提交；文本保留在 daemon 历史。

4.2 模型包：FireRedVAD / FireRedASR2-CTC / FireRedPunc

{
  "schema": 2,

  "fbank": { "num_bins": 80, "frame_ms": 25, "shift_ms": 10 },
  "max_segment_ms": 30000,
  "vad": {
    "model": "vad/stream-vad.onnx",
    "sha256": "...",
    "inputs": [ ... ],
    "outputs": [ ... ]
  },
  "asr": {
    "kind": "fire-red-ctc",
    "model": {
      "model": "asr/model.int8.onnx",
      "sha256": "...",
      "inputs": [ ... ],
      "outputs": [ ... ]
    },
    "tokens": "asr/tokens.txt",
    "token_count": 8667
  },
  "punc": {
    "model": "punc/model.onnx",
    "vocab": "punc/vocab.txt",
    "labels": "punc/labels.json"
  }
}
项目契约
ASR 文件asr/model.int8.onnx（约 740 MiB）+ asr/tokens.txt。
输入x: float32[1,T,80] fbank；x_lens: int64[1]。
输出log_probs: float32[1,T',8667]；log_probs_len: int64[1]。
CMVNONNX metadata cmvn_mean / cmvn_inv_stddev；运行期做 (x - mean) * inv_stddev。值可能是 JSON 数组或空白 / 逗号 / 分号分隔的浮点串，两种编码都要解析；mean 与 inv_stddev 必须等长且非空。
词表tokens.txt 为 token / id；id 0 为 blank；英文 ▁ 转为空格；token_count 必须等于输出类别数。
Punc 输入input_ids 为词表 id；attention_mask 固定 1；token_type_ids 是 0/1 句段 id，固定填 0，不能填 token id。
安装安装脚本下载官方 .tar.bz2，解出 ONNX / tokens 并写 manifest。
  • VAD / Punc 的 manifest 字段与张量契约沿用项目现有结构；ASR 只描述 CTC 单模型。
  • 模型包在运行期只读；启动校验失败不进入 TUI / daemon 运行态。
  • 官方模型包为 sherpa-onnx-fire-red-asr2-ctc-zh_en-int8-2026-02-25（Hugging Face）；model.int8.onnx 775,861,420 bytes，SHA-256 ca3dbabd82170110cc0b343c2890866d449984bc9cd92b9a18371ff80a81bb99；tokens.txt SHA-256 1bc613de2112d257e61a349c3e72d1b1a9cf19c33d3ca954197ad2171e5ea07b。官方包不含 cmvn.ark。
  • 预处理与 sherpa 对齐：normalize_samples=false、dither=0、snip_edges=true、low_freq=20、high_freq=0、use_power=true、use_log_fbank=true，输入乘 32768。
  • 模型为 Conformer 编码器 + 线性 CTC head，没有帧级 cache；VAD 负责流式切分，CTC 每次处理完整语音段。
  • 参考性能（AMD Ryzen 7 9800X3D、2 threads）：RTF 约 0.08；10 s 约 0.7–0.8 s，30 s 约 2.3 s，60 s 约 5.6 s。int8 英文子词质量有限（官方 0.wav 有缺失），发布前需用真实麦克风数据评估。

4.7 消息与错误

pub enum ProviderError {
    Audio(AudioError),
    Model(ModelError),
    Fcitx(FcitxError),
    Inference(InferenceError),
    Terminal(TerminalError),
}
错误触发条件处理
NoInputDevice系统没有默认输入设备。daemon 启动失败，stderr + 退出码 1。
DeviceNotFound--input-device 名称不存在。daemon 启动失败。
UnsupportedSampleFormat设备只提供 I16 / U16 / F32 之外的格式。daemon 启动失败。
StreamLost运行期音频流错误。丢弃当前段；连续失败后 daemon 退出。
MissingFile / DigestMismatch模型文件缺失或被修改。daemon 启动失败。
TensorMismatch / SessionONNX 元数据与 manifest 不符或会话创建失败。daemon 启动失败。
CtcModelMismatchCTC 输入输出或词表不符合 manifest。daemon 启动失败。
CmvnMetadataMissingCTC ONNX 缺少 CMVN metadata。daemon 启动失败。
TokenizerFormattokens.txt 行格式错误。daemon 启动失败。
FcitxUnavailableFcitx 未运行或 addon 未加载。无热键 / 临时窗口；TUI 可手动控制；日志说明。
AddonNotLoadedaddon 描述文件缺失或加载失败。日志 / voime doctor；不消费热键。
RoleConflict已有 role=Fcitx 客户端连接。daemon 发送 Error 后断开新连接；addon 由 2 s timer 重试。
NoInputContext没有聚焦文本输入框。不开始语音段；不提交。
CommitTargetLost目标输入框失焦或销毁。清空临时窗口；Final 保留历史。
DaemonUnavailableaddon 无法连接 socket。放行热键；固定每 2 s 重连；不影响普通输入。
IpcDisconnected / IpcVersionMismatchIPC 断线或版本不匹配。清理状态；版本不匹配拒绝连接。
AddonAbiMismatchFcitx 升级后 addon ABI 不匹配。重新编译 addon；Fcitx 日志记录。
NotATty / Terminal IoTUI 没有终端或控制失败。TUI 启动失败；daemon 不受影响。

4.8 addon 描述文件与配置

# share/fcitx5/addon/voime.conf
[Addon]
Name=Voime
Category=InputMethod
Version=@PROJECT_VERSION@
Library=voime
Type=SharedLibrary
OnDemand=False
Configurable=True

# 不安装 share/fcitx5/inputmethod/voime.conf：Voime 不进入输入法列表。

# ~/.config/fcitx5/conf/voime.conf
Mode=ptt
Hotkey=Super+F2
  • OnDemand=False 让 addon 在 Fcitx 启动时后台加载，从而在其他输入法活动时也能收到按键。
  • Library=voime 对应 $PREFIX/lib/fcitx5/voime.so；CMake 关闭 lib 前缀，不能生成 libvoime.so。没有输入法条目引用它，因此不会出现在输入法组。
  • readAsIni / safeSaveAsIni 不会自动补 .conf，配置文件路径必须写全 conf/voime.conf。
  • socket 使用 $XDG_RUNTIME_DIR/voime/voimed.sock 默认路径，不暴露为用户配置。
