PROVIDER — Voime

README USER CORE BUILD

根 PROVIDER 定义产品与外部世界之间的下边界：平台宿主、音频设备、推理运行时与固定模型目录。 具体消费的 API、消息和张量契约由各组件的 PROVIDER 定义；本文只做边界映射与全局约束。

1. TERMS

↑

术语定义
外部 provider Voime 不能拥有、只能消费的下层系统：桌面输入框架 / OS 输入栈、音频设备与驱动、ONNX Runtime、模型文件、终端。
平台宿主 为前端提供键盘、焦点与提交路径的系统组件。Linux 上是 Fcitx5；Windows 上是 Win32 / UIA 或 TSF。
音频栈 从麦克风到 cpal 的整条采集链路；Voime 只消费设备枚举、默认配置与 PCM 回调。
推理运行时 执行 ONNX 模型的进程内库。CPU SenseVoice / VAD / Punc 使用 CPU Execution Provider；GPU FireRed AED 使用 DirectML / MIGraphX / CUDA，且只出现在 voime-gpu。
模型目录 模型根目录下四个固定目录：vad、sense-voice、fire-red-aed、punc；每个目录一份 manifest.json 与对应 ONNX / 词表 / 标签，运行期只读。没有模型包选择或 active 指针。
GPU runtime 包 按 OS + EP 拆分的独立 voime-gpu 运行时：Linux MIGraphX、Windows DirectML、Linux / Windows CUDA；不进入模型目录，也不进入基础安装。
本地端点 daemon 与客户端之间的本机传输端点：Linux Unix domain socket，Windows named pipe。
隐私边界 音频、按键与识别文本只在本机内存与本地端点之间流动，不落盘、不出网。

2. CONVENTIONS

↑

约定内容
本地性运行期所有 provider 调用在本机完成；模型、音频与 IPC 不经过网络。
模型不可变模型目录运行期只读；启动时校验 manifest、SHA-256 与张量签名，失败不进入运行态。
推理进程隔离voimed / voime-core 只加载 CPU ORT；DirectML / MIGraphX / CUDA 只由 voime-gpu 加载。基础安装不包含 GPU runtime。
GPU runtime 包按 OS + EP 拆分，独立目录、版本、SHA 与签名；模型目录不自带可执行文件。GPU Final 不可用或初始化失败时回退 CPU SenseVoice。
OS API 收敛OS 输入、传输与权限 API 只出现在 voime-transport 与平台前端；核心、协议与 daemon 业务代码不直接调用。
键盘最小化Fcitx 持有键盘；Windows 前端只监听配置热键，不记录、不转发普通按键。
音频不落盘设备 PCM 只在内存中重采样、分段与推理；不写文件、不做网络上传。
错误映射Provider 错误在边界处转换为项目错误类型并附上下文；启动期失败写日志并阻止进入运行态，运行期单段失败丢弃该段。
版本契约Provider 版本要求写在各组件 PROVIDER；实现只消费已声明的子集，不依赖未记录行为。

3. DIAGRAMS

↑

3.1 Provider 边界

  • Voime 作为单一参与者；内部组件不展开。
  • 平台宿主、音频栈、CPU / GPU 推理运行时、模型目录与 GPU runtime 包是外部 provider；本地端点是 daemon 与客户端之间的传输 provider。
  • CPU ORT 由 voime-core 消费；GPU ORT / EP 由 voime-gpu 消费，二者不共享进程或运行时目录。
  • 每条边的消费 API 由对应组件 PROVIDER 定义。

3.2 模型加载与推理边界

  • 启动时读取固定模型目录并校验；每个语音段只重置解码状态，不重新加载权重。
  • CPU SenseVoice、VAD 与 FireRedPunc 在 voimed 内加载；GPU FireRed AED 只在 voime-gpu 内加载。只有 FireRed 与 Punc 目录同时存在时才尝试 GPU Final。
  • 具体张量名、形状、CMVN 与 fbank 参数见 voime-core PROVIDER §4.2；GPU AED 契约见 voime-gpu PROVIDER §4.2。

4.3 Provider 失败策略

失败阶段行为
没有输入设备 / 设备名不存在启动daemon 启动失败，stderr + 非零退出；doctor 显示原因。
音频流错误运行丢弃当前段；连续失败达到阈值后 daemon 退出。
模型缺失 / SHA 不匹配 / 张量不符启动daemon 启动失败；不进入 TUI / runtime。
sense-voice 目录缺失 / 损坏启动daemon 启动失败；Preview 与 CPU Final 都不可用。
GPU runtime 缺失 / 驱动不匹配 / 显存不足启动 / 运行标记 GPU Final 不可用；回退 CPU SenseVoice；Preview 继续；不加载 CPU AED。
worker 崩溃 / 超时 / 推理失败运行重启 worker；连续失败回退 CPU SenseVoice；当前段丢弃或按回退策略处理。
推理失败运行丢弃当前段并继续监听；错误进入日志 / IPC Error。
端点被占用 / 无法绑定启动已有 daemon 时幂等退出；其他绑定错误启动失败。
平台宿主不可用运行前端放行热键、清空临时文本；不影响普通输入。
TSF 注册 / 编辑会话失败运行不提交；保留 daemon 历史；前端记录平台错误。
  • 各 provider 的具体错误码与建议动作见对应组件 PROVIDER。
  • 任何失败都不得把文本注入到非目标窗口。
