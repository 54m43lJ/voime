2. CONVENTIONS

↑

约定内容
进程模型一个 worker 进程只服务一个 daemon；读帧线程与推理线程分离，推理串行，不引入异步运行时。
单请求同一时刻只处理一个 Transcribe；请求循环在收到 Result / Error 前不读下一段音频。
ORT runtimeort 固定 default-features=false + api-29 + load-dynamic；EP feature 按平台只启用一个。
EP 固定进程内只注册安装时选定的 EP；不注册 CPU EP，不在运行期注册第二个 EP，不回退到 CPU ORT。
runtime 目录ORT 动态库从 worker 自己的 runtime 目录加载；不写全局 LD_LIBRARY_PATH，不与 Qwen 共享库目录。
精度两个模型只加载 FP32 ONNX；不加载 int8 / FP16 变体，不做运行期量化。
模型目录来源模型根目录与设备只来自 Hello 的 model_dir / device；启动参数只带 runtime 与日志级别，不从全局配置或环境变量猜路径。
模型校验启动时校验 schema 5、id、kind、文件存在 / 大小 / SHA-256、相对路径；任一失败不创建会话。
模型只读模型目录与文件只读；不允许可执行文件、脚本、系统库或符号链接逃逸。
fbankKaldi fbank，80-bin、25 / 10 ms、snip_edges、无 dither、16-bit 缩放；每次从完整段独立计算。
CMVNcmvn.ark 只读一次；按 Kaldi 统计计算 80 维 mean / inverse stddev，逐帧应用。
AED 解码greedy；<sos> 3 开始、<eos> 4 停止；decoder cache 在段内传递，段间清零。
FireRedPunc5 类 token 标签；按 tokenizer 的字符偏移插回原文；分块处理，返回前完成全部标点。
取消读帧线程收到 Cancel 时只在 id 匹配时置位；推理线程在 decoder 步之间与分块标点之间检查，不中断正在执行的 ORT run。
错误边界内部使用 anyhow::Result + 上下文；边界映射到 common 错误码，不新增后端私有码。
日志与隐私stdout 只写协议帧；stderr 日志只记长度、耗时、错误码、模型路径与 SHA 前缀，不记文本。
无网络运行期不联网、不下载、不改写模型；安装与发布流程负责获取权重。
依赖隔离不依赖 voime-core、VAD、Preview、前端 IPC、llama.cpp、GGML 或 voime-gpu-qwen3。
  • 仓库级进程 / 线程边界见 根 CORE §2；协议字段与错误码见 voime-gpu-common USER。
  • 工程常量不在此表赋值；推荐值只出现在签名注释中，具体值以源码为准。

4.6 worker.rs 文件树

pub enum WorkerCommand {
    Transcribe {
        request: Transcribe,
        audio: Vec<f32>,
    },
    Shutdown,
}

#[derive(Clone)]
pub struct CancelFlag { /* Arc<AtomicBool> + current id */ }
impl CancelFlag {
    pub fn new() -> Self;
    pub fn arm(&self, id: u64);
    pub fn cancel(&self, id: u64);
    pub fn is_cancelled(&self) -> bool;
    pub fn flag(&self) -> &AtomicBool;
    pub fn clear(&self);
}

pub struct Worker {
    runtime: Runtime,
    aed: Aed,
    punc: Punc,
    cancel: CancelFlag,
}

pub fn validate_hello(hello: &Hello) -> anyhow::Result<()>;
pub fn read_loop(tx: Sender<WorkerCommand>, cancel: CancelFlag);

impl Worker {
    pub fn new(models: ModelSet, runtime: Runtime) -> anyhow::Result<Self>;
    pub fn run(&mut self, commands: Receiver<WorkerCommand>)
        -> anyhow::Result<()>;
    fn handle(&mut self, request: Transcribe, audio: &[f32]) -> Response;
    fn transcribe(&mut self, id: u64, samples: &[f32])
        -> anyhow::Result<String>;
    fn shutdown(&mut self);
}
  • Request / Response 来自 voime-gpu-common USER §4.2 / §4.3；本文不复制字段。
  • validate_hello 校验 protocol / backend / model_dir；device 前缀必须与安装时 EP 匹配，否则返回 device_unavailable。
  • read_loop 只读帧并投递命令；Cancel 不进入命令通道，只置位 CancelFlag。EOF 按 Shutdown 处理。
  • run 从命令通道取 Transcribe / Shutdown；推理串行，取消标志在 decoder 步之间检查。
  • 每个 Transcribe 以 Result / Error 结束；随后 clear 当前 id，准备下一段。

4.11 asr/aed.rs 文件树

pub const CACHE_LAYERS: usize;    // 推荐值 16

pub struct AedConfig {
    pub max_tokens: usize,
    pub sos_id: i64,
    pub eos_id: i64,
}

pub struct EncoderOutput {
    pub output: Tensor,
    pub mask: Tensor,
    pub frames: usize,
}

pub struct Aed {
    encoder: Session,
    decoder: Session,
    tokenizer: AedTokenizer,
    cmvn: Cmvn,
    fbank: Fbank,
    config: AedConfig,
}

impl Aed {
    pub fn new(manifest: &ModelManifest,
               runtime: &Runtime) -> anyhow::Result<Self>;
    pub fn transcribe(&mut self, samples: &[f32],
                      cancel: &AtomicBool)
        -> anyhow::Result<String>;
    fn encode(&mut self, features: &[Vec<f32>])
        -> anyhow::Result<EncoderOutput>;
    fn decode_greedy(&mut self, encoder: &EncoderOutput,
                     cancel: &AtomicBool)
        -> anyhow::Result<Vec<i64>>;
    fn empty_cache(&self) -> Vec<Tensor>;
}
  • new 创建 encoder / decoder 会话，读取 config.json 的特殊 token id 与最大输出长度；ctc.onnx 不创建会话。
  • decode_greedy 每步取 logits argmax，命中 eos_id 或达到 max_tokens 停止；每个新段用 empty_cache 重建 cache。
  • cancel 在每一步 decoder 前检查；命中时返回取消错误，由 worker 映射到 common 语义。
  • worker 不再分段；假设 daemon 已按 30 s 上限切分。仍校验输入帧数，超过上游 max_encoder_frames 时返回 inference_failed。

5.1 启动与加载

voimed::worker::Worker::spawn(Firered, model_root)
└── std::process::Command::new("voime-gpu-firered")
    └── voime_gpu_firered::main()
        ├── config::parse()
        └── voime_gpu_firered::run(args)
            ├── voime_gpu_common::read_frame(stdin)
            ├── 判断 Hello -> worker::validate_hello(&hello)
            ├── model::load(Path::new(&hello.model_dir))
            │   ├── ModelManifest::load(fireredasr2-aed/manifest.json)
            │   ├── ModelManifest::verify(fireredasr2-aed)
            │   ├── ModelManifest::load(fireredpunc/manifest.json)
            │   └── ModelManifest::verify(fireredpunc)
            ├── runtime::Runtime::load(args.runtime, &hello.device)
            │   └── runtime::register_ep(&env, args.runtime)
            ├── worker::Worker::new(models, runtime)
            │   ├── Aed::new(&models.asr, &runtime)
            │   │   ├── Runtime::create_with_spec(encoder.onnx, inputs, outputs)
            │   │   ├── Runtime::create_with_spec(decoder.onnx, inputs, outputs)
            │   │   ├── Cmvn::load(cmvn.ark)
            │   │   └── AedTokenizer::load(dict.txt, train_bpe1000.model)
            │   └── Punc::new(&models.punc, &runtime)
            │       ├── Runtime::create_with_spec(model.onnx, inputs, outputs)
            │       ├── PuncTokenizer::load(tokens.txt)
            │       └── PuncLabels::load(out_dict, punc.json)
            ├── crossbeam_channel::unbounded()
            ├── worker::read_loop(tx, worker.cancel.clone())   // 独立读帧线程
            ├── voime_gpu_common::write_frame(Ready)
            └── worker::Worker::run(rx)
  • Hello 之前不加载模型；模型根目录与设备只取 hello.model_dir / hello.device。
  • Hello 校验失败返回 protocol_mismatch（id 0）；模型 / runtime / 会话失败返回 load_failed / runtime_missing / device_unavailable，均在 Ready 前。
  • 任何一步失败都不阻塞 daemon：daemon 标记 firered 不可用并继续 CPU Final。
  • ctc.onnx 只参与 manifest 校验，不创建会话。
  • 模型与 runtime 常驻；每个 Final 不重新加载权重。

5.2 Final 识别

worker::read_loop(tx, cancel)
├── voime_gpu_common::read_frame(stdin)
└── 判断 Request::Transcribe
    ├── cancel.arm(id)
    └── tx.send(WorkerCommand::Transcribe { request, audio })

worker::Worker::run(rx)
└── 判断 WorkerCommand::Transcribe -> Worker::handle(request, audio)
    ├── Worker::transcribe(id, samples)
    │   ├── Aed::transcribe(samples, self.cancel.flag())
    │   │   ├── Fbank::compute(samples)
    │   │   ├── Cmvn::apply(&mut features)
    │   │   ├── Aed::encode(features)
    │   │   │   └── Session::run(encoder, input, input_lengths)
    │   │   ├── Aed::decode_greedy(&encoder, cancel)
    │   │   │   ├── Session::run(decoder, ys, encoder_output, src_mask, caches)
    │   │   │   └── 判断 token == eos_id -> 停止
    │   │   └── AedTokenizer::decode(ids)
    │   ├── Punc::punctuate(text, self.cancel.flag())
    │   └── 判断 text.trim().is_empty() -> 返回空文本
    └── voime_gpu_common::write_frame(Result)
  • Fbank 与 Cmvn 每次从完整段独立计算；decoder cache 只在本段内传递。
  • 空文本仍返回 Result，由 daemon 按空段丢弃；worker 不伪造 Final。
  • 失败在边界映射为 common 错误码；当前段是否回退 CPU 由 daemon 决定。

5.3 标点

Punc::punctuate(text, cancel)
├── PuncTokenizer::encode(text)
├── split_chunks(text, &tokenizer, MAX_TOKENS)
└── 逐块 Punc::punctuate_chunk(chunk)
    ├── PuncTokenizer::encode(chunk)
    ├── Session::run(model.onnx, input_ids, lengths)
    ├── labels::argmax(logits)
    └── PuncLabels::insert(text, pieces, ids)
  • 空文本直接返回空字符串，不调用 tokenizer / session。
  • 每个块独立推理；块与块之间不共享上下文，只在最终文本上按偏移插入标点。
  • 任一块推理失败则不返回部分加标点文本；错误交给 worker 边界。

5.4 取消与超时

worker::read_loop(tx, cancel)
├── voime_gpu_common::read_frame(stdin)
└── 判断 Request::Cancel(id) -> cancel.cancel(id)

worker::Worker::run(rx)
├── 判断 cancel.is_cancelled() -> Aed::decode_greedy 提前返回
│   └── voime_gpu_common::write_frame(Error)
└── 判断 daemon 超时 -> 进程被终止（worker 不发送响应）
  • 取消是协作式的：只在下一次检查点生效，不保证立即停止当前 ORT run。
  • 加载与识别的超时预算由 daemon 计时；worker 不自行定义墙钟超时，也不在超时后切换 EP。
  • 取消 / 超时后的重启与 CPU 回退由 voimed USER §4.5 负责。

5.5 关闭

worker::read_loop(tx, cancel)
└── 判断 Request::Shutdown -> tx.send(WorkerCommand::Shutdown)

worker::Worker::run(rx)
└── 判断 WorkerCommand::Shutdown -> Worker::shutdown()
    ├── drop(Punc)
    ├── drop(Aed)
    ├── drop(Runtime)
    └── voime_gpu_common::write_frame(Bye)
  • Shutdown 与 Cancel 都是协作式的：命令在下一个检查点生效；若推理未在 5 s 关闭预算内退出，daemon 强杀 worker。
  • 关闭顺序先释放会话与 runtime，再写 Bye；不删除模型文件、不写配置。
  • worker 不创建子进程，不留下孤儿进程。
