1. 环境

↑

项目要求
Ruststable 工具链；无平台特定系统依赖。
平台Linux / Windows 均可构建；本 crate 不含 OS 调用。

2. 构建

↑

cargo build -p voime-ipc
cargo build --release -p voime-ipc
产物说明
libvoime_ipc.rlib供 daemon、CLI、Windows 前端链接；C++ 前端按协议自行实现，不链接本库。

3. 测试

↑

cargo test -p voime-ipc
cargo clippy -p voime-ipc --all-targets
cargo fmt -p voime-ipc --check
测试覆盖
单元测试Hello 往返、SetBackend 往返、外部标签与小写值、超长消息、缺少换行、协议 5 版本。
tests/ipc.rs握手 / 角色 / Mode / SetBackend / framing / 协议 5 的跨组件集成测试；不包含模型列表或 package_id。
协议金样C++ 前端与 Rust 客户端共用同一组 JSON 样例；新增消息字段时必须同步并提升 PROTOCOL_VERSION。
  • 根 workspace 的完整测试与发布命令见 根 BUILD §6。
  • 协议版本变化时必须更新 USER §4.8 与金样测试。
