2. CONVENTIONS

↑

约定内容
零依赖只用 std；不引入日志框架。
无 OS API只用 std::env / std::fs / std::time；平台差异收敛到默认目录的选择。
失败静默写日志失败不 panic、不反馈给调用方；日志永远不能拖垮业务。
全局单例每个进程一个组件、一个日志文件；init 可重复调用，以最后一次为准。
宏优先调用方一律使用 vlog!；未启用时连 format_args 的求值都省去。
  • 仓库级依赖方向见 根 CORE §2；环境变量契约见 USER §4.1。

5. Call stack tree

↑

5.1 初始化

进程 main()
└── voime_log::init(component)
    ├── resolve_dir(env::var_os("VOIME_LOG"))
    │   ├── 判断未设置 / 空 → 禁用返回
    │   ├── 判断 "1" / "true" / "on" → default_directory()
    │   │   └── base_state_dir().join("voime").join("logs")
    │   └── 其他值 → PathBuf::from(值)
    └── open_log(dir, component)
        ├── fs::create_dir_all(dir)
        ├── 判断 metadata(path).len() ≥ ROTATE_BYTES → fs::rename(path, path + ".1")
        └── OpenOptions append + create → File

5.2 写入

调用方 vlog!(...)
├── 判断 enabled()（AtomicBool，未启用即返回）
└── voime_log::write(format_args!(...))
    ├── render(component, message) → "时间戳 [组件] 消息\n"
    ├── File::write_all(line)
    └── File::flush()
