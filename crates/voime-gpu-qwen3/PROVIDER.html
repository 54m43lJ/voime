PROVIDER — voime-gpu-qwen3

根：README USER CORE PROVIDER ｜ 本组件：README USER CORE

本文只记录 Qwen worker 实际消费的外部子集：Qwen3-ASR 的 BF16 GGUF 主模型与 BF16 mmproj、 llama.cpp / GGML 的 mtmd 音频接口，以及 Vulkan / CUDA backend。完整定义以官方模型卡与 llama.cpp / llama-cpp-4 文档为准；产品级下边界见 根 PROVIDER。

1. TERMS

↑

术语定义
GGUF llama.cpp 使用的模型容器格式；一个文件包含张量、tokenizer、模型配置与 chat template 等元数据。本后端的主模型与 mmproj 都是 GGUF。
mmproj 多模态投影器文件；本项目只使用 Qwen3-ASR 的音频投影器，把音频编码成语言模型可消费的嵌入。它不是第二个 ASR 或标点模型。
BF16 Brain floating point 16；本后端主模型与 mmproj 的固定精度。
mtmd llama.cpp 的 multimodal 支持库 / llama-cpp-4 的 mtmd feature；提供音频 bitmap、tokenize 与 eval_chunks。
音频 bitmap MtmdBitmap::from_audio(&[f32]) 创建的音频输入对象；数据是 little-endian f32 PCM，不经过 WAV 容器。
Whisper 风格 log-mel mmproj 内部使用的 128-bin log-mel 音频特征；由 mmproj / mtmd 计算，worker 只提供 16 kHz f32 PCM。
Vulkan 跨平台 GPU API；AMD Linux 的 Qwen 后端唯一 runtime。使用系统 Vulkan loader 与 GPU 驱动，不引入 ROCm / HIP。
CUDA NVIDIA GPU runtime；用于 Linux / Windows 的 NVIDIA 设备。与 Vulkan 一样，一次构建只选一个 backend。
EOS 模型生成的结束 token；LlamaModel::is_eog_token 为真时停止 greedy 解码。
chat template GGUF 内自带的对话模板；worker 用它构造单轮 ASR prompt，并插入 MtmdContext::default_marker()。
revision / SHA-256 模型来源的固定版本与文件内容摘要；安装清单与运行期校验共用，运行期不联网解析最新版本。

2. CONVENTIONS

↑

约定内容
BF16 only主模型与 mmproj 固定 BF16；不加载 Q8_0 / FP16，不在运行期量化或转换。
同版本主模型与 mmproj 必须来自同一模型版本、同一 revision；更换任一文件都要重新跑目标语料金样。
不混 Q8 mmproj上游同时提供 Q8_0 mmproj，但 Q8 mmproj 不是产品路径；不得与 BF16 主模型混用。
模型不可变模型目录运行期只读；启动时校验 manifest、SHA-256 与大小，失败不进入运行态。
PCM 直通只消费 16 kHz、单声道、f32 PCM；不读 WAV / MP3，不重采样，不生成临时文件。
mel 在 mmproj 内Whisper 风格 128-bin log-mel 由 mmproj 内部处理；worker 不实现 fbank / mel 前端，也不传特征张量。
30 s 段每次只处理一个完整语音段，上限 30 s；超过约 2 分钟的长音频在 llama.cpp 上可能无输出，本方案不触发。
Greedy / EOSgreedy 采样；遇到 EOS 或 token 上限停止；不引入温度、top-p、重复惩罚或束搜索。
AMD Linux 只 Vulkan不构建、不安装、不探测 HIP / ROCm；Vulkan 不可用即该后端不可用。
一个 backend / 二进制vulkan 与 cuda 不共存于同一 worker 构建；安装包按 runtime 分开。
版本锁定llama-cpp-4 固定 0.11.0；对应 llama.cpp commit 随 llama-cpp-sys-4 固定并记录在发布清单，不跟随 master。
音频 experimentalllama.cpp 的音频输入仍是 experimental；升级 crate / commit 必须重跑 30 s 段金样与长段边界测试。
无 ORT不链接 ONNX Runtime / ONNX；Qwen 路径与 FireRed 的 ORT 路径完全隔离。

3. DIAGRAMS

↑

Qwen 后端的边界分为两张图：USER §3.1 的 daemon ↔ worker 协议时序， 以及本节 runtime-load.svg 的 worker ↔ llama.cpp / 模型目录加载边界。 §3.2 用表格列出 Transcribe 使用的边界 API，不展开 mtmd / prompt / decode 内部阶段。

3.1 模型加载边界

  • worker 先读 manifest.json 并校验文件 SHA-256 / 大小，再初始化 llama.cpp backend、加载 BF16 主模型与 BF16 mmproj。
  • 加载后用 MtmdCapabilities.audio 与 audio_sample_rate() 自检；自检失败只使 Qwen 后端不可用。
  • 加载完成后模型常驻；每个 Final 只创建 / 重置 LlamaContext，不重新加载 GGUF。
  • 内部 mtmd / prompt / decode 阶段不在图中展开；daemon 与 worker 的请求边界见 USER §3.1。

3.2 Transcribe 边界

Transcribe 只跨越 worker → llama.cpp / mtmd 的已声明 API；不把 mtmd 音频编码、prompt 拼接或 greedy 循环拆成内部阶段图。

边界调用作用约束
MtmdBitmap::from_audio(&[f32]) 把完整 PCM 段包装成音频 bitmap。 16 kHz、单声道、f32；不写临时 WAV；样本数受 30 s 上限约束。
MtmdInputText::new(&prompt, true, true) 把含 media marker 的 ASR prompt 包装成 mtmd 文本输入。 prompt 来自 GGUF chat template；只插入一个音频 marker。
MtmdContext::tokenize(&text, &[&bitmap], &mut chunks) 把 prompt 与音频 bitmap 编码成 MtmdInputChunks。 bitmap 数量必须与 marker 数量一致；失败返回 inference_failed。
MtmdContext::eval_chunks(&mut lctx, &chunks, 0, 0, n_batch, true, &mut n_past) 编码音频并 prefill 到 LlamaContext。 n_batch 来自上下文；不在 worker 内展开 mtmd 编码阶段。
LlamaSampler::greedy() / sample / LlamaContext::decode 逐 token greedy 生成；遇 EOS 停止。 不采样、不并行生成；每轮只 decode 一个新 token。
LlamaModel::detokenize(&tokens, true, false) 把生成 token 还原成文本。 移除 special token；之后必须经 clean::clean_text。
  • 音频特征由 mmproj 内部计算，worker 不持有 128-bin log-mel 张量，也不提供 fbank 参数。
  • 失败只影响当前段；daemon 按 USER §4.3 回退 CPU SenseVoice。

  • 音频 marker 使用 MtmdContext::default_marker()；prompt 的 chat template 来自主模型 GGUF，不由 worker 手写。

4.4 Vulkan / CUDA runtime 与启动自检

平台 / 设备Qwen runtime约束
Linux + AMDVulkan只接受 Vulkan；使用系统 Vulkan loader / GPU 驱动；不安装 ROCm / HIP。
Linux + NVIDIACUDA 或 Vulkan编译时二选一；同一构建只含一个 backend。
Windows + NVIDIACUDA 或 Vulkan与 Linux 分开打包；runtime 各自独立目录。
Windows + AMD / IntelVulkan不使用 DirectML / ROCm；Vulkan loader 与驱动由系统提供。
无 GPU / 驱动不匹配—不启动 worker；Qwen 后端不可用；当前段回退 CPU。
顺序启动自检
1LlamaBackend::init() 成功，且初始化的是编译时选中的 backend。
2BF16 主模型可加载；LlamaModel::ftype() 表明权重为 BF16。
3BF16 mmproj 可加载；MtmdContext::init_from_file 成功。
4capabilities(&model).audio == true，且 audio_sample_rate() == 16000。
5一次短静音 warmup 完成 mtmd / decode，不触发 backend 错误。
6向 daemon 返回 Ready，携带 runtime、device 与显存信息。
失败错误码行为
Vulkan / CUDA runtime 缺失或版本不匹配runtime_missingQwen 后端不可用；当前段回退 CPU；提示重装 GPU 模块。
无 GPU、驱动不匹配、显存不足、Vulkan loader 缺失device_unavailable不启动 worker；Qwen 后端不可用；当前段回退 CPU；doctor 报原因。
模型缺失、SHA 不匹配、mmproj 能力缺失、精度不是 BF16load_failedQwen 后端不可用；当前段回退 CPU；记录路径与 SHA 前缀。
from_audio / tokenize / eval / decode 失败inference_failed当前段回退 CPU；重启 worker；连续失败标记不可用。
加载或识别超时timeout杀 worker；当前段回退 CPU；按崩溃路径重启。
协议版本 / backend 不匹配protocol_mismatch拒绝 worker；当前段回退 CPU；提示重装 GPU 模块。
  • 错误码定义见 voime-gpu-common USER §4.5，超时 / 取消语义见 §4.7；本文只记录 Qwen provider 触发条件。
  • Vulkan 不支持只使 Qwen 后端不可用，不影响核心 VAD / Preview / CPU Final，也不影响另一个 GPU 后端。
  • 不静默降级 Q8 / FP16，不在 worker 内跑 CPU 大模型；CPU 回退由 daemon 用核心 SenseVoice 完成。
