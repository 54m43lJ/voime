USER — voime-gpu-qwen3

根：README USER CORE PROVIDER ｜ 本组件：README CORE PROVIDER

本文定义 Qwen worker 对 daemon 与 GPU 安装脚本暴露的边界：输入输出约定、启动时序、 模型目录、runtime 构建选择、错误回退与安装 / 卸载入口。帧格式、请求 / 响应字段与错误码 由 voime-gpu-common USER 拥有；本文只链接，不复制。

1. TERMS

↑

术语定义
Qwen worker voime-gpu-qwen3 可执行文件；由 voimed 按 final.backend = qwen3 拉起，只处理完整语音段的 Final 识别。
BF16 主模型 Qwen3-ASR-1.7B-bf16.gguf；Qwen3-ASR 1.7B 的 BF16 GGUF 权重，包含 tokenizer 与模型配置。
BF16 mmproj mmproj-Qwen3-ASR-1.7B-bf16.gguf；同一模型版本的音频投影器，把音频编码成语言模型可消费的嵌入。它不是第二个 ASR 或标点模型。
完整 PCM 输入 一个语音段的完整音频：16 kHz、单声道、f32、样本范围 [-1, 1]；不接收活动段增量。
输出清洗 去掉 Qwen3-ASR 输出中可能出现的 language ... 前缀与 asr_text 包装，只保留识别文本；不修改模型自带标点与大小写。
空段 清洗后为空的输出；按空语音段处理，daemon 丢弃该段，不提交文本。
Qwen runtime Qwen worker 编译时选定的 llama.cpp / GGML 后端：vulkan 或 cuda；一次构建只包含一个 backend feature。
后端不可用 Qwen worker 未安装、runtime 缺失、模型校验失败、设备不可用或连续失败；daemon 保留配置值，但当前段回退 CPU。
GPU 模块安装脚本 scripts/install-gpu.sh / scripts/install-gpu.ps1；负责 workers、runtime 与模型目录，不改变核心安装。

2. CONVENTIONS

↑

约定内容
BF16 固定 主模型与 mmproj 都必须是 BF16；不加载 Q8_0 / FP16 作为替代，也不在运行期量化。
同版本约束 主模型与 mmproj 必须来自同一模型版本、同一 revision；不混用 Q8 mmproj，也不把不同发布批次的两个文件放进同一目录。
PCM 固定 只接受 16 kHz、单声道、f32 的完整语音段；worker 不重采样、不读音频文件、不生成临时 WAV。
只做 Final 一次请求一个完整语音段；不接收 VAD 状态、活动段音频、Partial 请求、前端 IPC、热键或目标。
模型常驻 daemon 在启动时拉起选中的 worker；worker 在 Hello 后加载模型并保持常驻，不在每次 Final 前重新加载 GGUF / mmproj。
串行请求 同一 worker 一次只处理一个 Final；daemon 不在上一段未完成时发送下一段。
内置标点 / 大小写 标点与大小写来自 Qwen3-ASR 模型输出；不加载 FireRedPunc，不做二次标点或英文大小写修正。
必须清洗包装 Qwen3-ASR 输出可能带 language ... / asr_text 包装；worker 在返回前必须清洗。清洗后为空则按空段处理。
30 s 段上限 语音段由 daemon 按 30 s 上限切分；worker 拒绝超过上限的输入。llama.cpp 上超过约 2 分钟的长音频可能无输出，本方案不触发该边界。
AMD Linux 只 Vulkan AMD Linux 只接受 --qwen-runtime vulkan；不安装、不探测、不回退 ROCm / HIP。
不静默降级 Vulkan / CUDA 不满足时只把 Qwen 后端标记为不可用；不降级到 Q8 / FP16，也不在 worker 内跑 CPU 大模型。
超时预算 加载与识别超时由 daemon 持有；worker 不延长预算，收到 Cancel 后按 voime-gpu-common USER §4.7 的取消语义结束当前请求。
日志不含文本 stdout 只用于协议；日志写 stderr，由 daemon 转发到 voime-log。日志只记录长度、耗时、错误码与后端名，不记录识别文本。
无直接用户入口 用户通过 GPU 安装脚本安装、通过 final.backend 选择；不直接运行 worker，也没有窗口或 TUI。

3. DIAGRAMS

↑

3.1 daemon 与 worker 边界

  • daemon 在 Hello 中给出协议、backend、模型目录与设备；worker 加载 manifest、GGUF 主模型与 BF16 mmproj 后返回 Ready，其中 punc 为 false（没有独立标点模型）。
  • Transcribe(PCM) 送入一个完整语音段；Result(text) 只返回最终文本。内部处理只画一个 内部处理 self-loop，不展开 mtmd / prompt / decode / 清洗。
  • 超时与取消只表现为边界消息：daemon 发送 Cancel，预算耗尽时杀掉 worker。超时 / 崩溃的当前段由 daemon 回退 CPU SenseVoice；主动取消的终态由 daemon 丢弃，不执行回退。
  • 空输出按空段处理，不返回半成品文本；worker 不产生 Partial，也不接收 VAD / 前端消息。
  • 帧格式与字段见 voime-gpu-common USER §4.1；错误码见 §4.5。

4. INTERFACES

4.1 模型目录

模型安装在 ~/.local/share/voime/models/qwen3-asr-1.7b/ （Windows 为 %LOCALAPPDATA%\voime\models\qwen3-asr-1.7b\）。 目录名是稳定标识，版本写在 manifest.json；运行期只读。 

qwen3-asr-1.7b/
├── manifest.json
├── Qwen3-ASR-1.7B-bf16.gguf
├── mmproj-Qwen3-ASR-1.7B-bf16.gguf
└── LICENSE
文件作用体积 / 约束
manifest.json 模型清单：通用字段见 根 CORE §4.8；本模型固定 kind=asr，runtime 为 qwen3 / gguf / bf16。 与目录名一致；运行期只读；缺失或 schema 不符使 Qwen 后端不可用。
Qwen3-ASR-1.7B-bf16.gguf Qwen3-ASR 1.7B 的 BF16 主模型；tokenizer 与模型配置已包含在 GGUF 内。 4,069,674,944 bytes（约 4.07 GB）；必须为 BF16。
mmproj-Qwen3-ASR-1.7B-bf16.gguf 同一模型版本的 BF16 音频投影器；把完整 PCM 编码成音频嵌入。 641,773,984 bytes（约 642 MB）；必须为主模型同版本 BF16，不得使用 Q8 mmproj。
LICENSE Qwen3-ASR 模型许可证文本。 随模型目录分发；不参与推理。 
{
  "schema": 5,
  "id": "qwen3-asr-1.7b",
  "kind": "asr",
  "version": "<发布清单冻结值>",
  "license": "Apache-2.0",
  "files": [
    { "path": "Qwen3-ASR-1.7B-bf16.gguf", "sha256": "...", "size": 4069674944 },
    { "path": "mmproj-Qwen3-ASR-1.7B-bf16.gguf", "sha256": "...", "size": 641773984 }
  ],
  "runtime": {
    "backend": "qwen3",
    "format": "gguf",
    "precision": "bf16",
    "max_segment_ms": 30000
  }
}
  • worker 只接受 daemon 传入的模型目录，不从全局配置或环境变量猜路径；目录外文件、绝对路径与 .. 一律拒绝。
  • 启动时逐文件校验 SHA-256 与大小；任一文件缺失、被修改或精度声明不是 bf16，按 §4.3 的 load_failed 处理。
  • 目录内不允许可执行文件、脚本或系统库；安装脚本用同盘临时目录 + rename 原子替换，失败不留下半成品。
  • 具体来源、revision 与 SHA-256 见 PROVIDER §4.1 / §4.2。

4.2 runtime 构建选择

Qwen runtime 在编译时选定，不是运行期开关。安装脚本按 --qwen-runtime 选择预编译的 worker 与 runtime 包；worker 二进制只包含一个 llama.cpp backend feature。

--qwen-runtime适用平台依赖说明
vulkan Linux AMD（唯一选项）· Linux NVIDIA · Windows AMD / Intel / NVIDIA 系统 Vulkan loader、匹配的 GPU 驱动 不安装 ROCm / HIP；AMD Linux 只允许此值。
cuda Linux NVIDIA · Windows NVIDIA 匹配的 NVIDIA 驱动与 CUDA runtime 不用于 AMD；worker 自己的 runtime 目录，不写全局 LD_LIBRARY_PATH。
项目契约
AMD Linux只接受 vulkan；安装脚本拒绝 cuda，也不暴露 hip / rocm 选项。
NVIDIAcuda 或 vulkan；由预编译包在编译时确定，安装脚本只透传选择，不在运行期切换。
Windows AMD / Intelvulkan；不使用 DirectML 或 ROCm。
未指定安装脚本按平台选择受支持的 runtime；AMD Linux 仍固定 Vulkan。
错误值安装失败并非零退出；不构建“自动探测后回退”的路径。
runtime 缺失 / 版本不匹配worker 返回 runtime_missing；Qwen 后端不可用，当前段回退 CPU。
  • final.backend = qwen3 与 --qwen-runtime 是两件事：前者选择 Final 后端，后者选择该 worker 的 llama.cpp 后端。
  • Vulkan 不可用时，只使 Qwen 后端不可用；不回退 ROCm、Q8 或 FP16。
  • runtime 构建选择的平台矩阵与启动自检见 PROVIDER §4.4。

4.3 错误与回退

错误码的完整定义见 voime-gpu-common USER §4.5， 超时 / 取消语义见 §4.7。 本表只列 Qwen 后端的触发条件与 daemon 动作。

错误码Qwen 触发条件daemon 动作
runtime_missing llama.cpp / Vulkan / CUDA runtime 未安装、版本不匹配或 worker 构建的 backend 与安装包不符。 标记 Qwen 后端不可用；当前段回退 CPU SenseVoice；提示重装 GPU 模块。
device_unavailable 没有可用 GPU、驱动不匹配、Vulkan loader 缺失或显存不足。 不启动 worker；Qwen 后端不可用；当前段回退 CPU；doctor 报原因。
load_failed manifest 缺失 / schema 不符、主模型或 mmproj 缺失、SHA-256 不匹配、精度不是 BF16、音频投影能力缺失。 Qwen 后端不可用；当前段回退 CPU SenseVoice；日志记录路径与 SHA 前缀，不记录文本。
inference_failed 音频包装、特征编码或解码失败，或输入超过 30 s 段上限。 当前段回退 CPU；重启 worker；连续失败后标记 Qwen 后端不可用。
timeout 加载或识别超过 daemon 预算。 杀掉 worker；当前段回退 CPU；按崩溃路径重启，连续超时标记不可用。
protocol_mismatch 协议版本、backend 名或消息形状与 daemon 不一致。 拒绝 worker；Qwen 后端不可用；当前段回退 CPU；提示重装 GPU 模块。
情况Qwen 行为daemon 行为
输出清洗后为空返回空文本，而不是半成品或错误文本。按空段丢弃；不回退 CPU，不提交。
Vulkan 不支持启动自检失败，返回 device_unavailable 或 runtime_missing。只使 Qwen 后端不可用；核心 VAD / Preview / CPU Final 继续。
worker 崩溃 / 管道断开无响应；由 daemon 检测进程退出或超时。当前段回退 CPU；按退避重启；连续失败标记不可用。
模型 / runtime 被删除下次启动加载失败。保留 final.backend 配置值但标记不可用；当前段回退 CPU。
  • Qwen worker 内部不做“GPU 失败 → CPU 大模型”的回退；CPU 回退由 daemon 用核心 SenseVoice 完成，见 根 USER §4.4。
  • Qwen 后端失败不影响 VAD、Preview、热键、目标或另一个 GPU 后端；daemon 仍以 CPU Final 启动，同一时刻仍只有一个 worker 运行。
  • 错误码以 voime-gpu-common USER §4.5 为准，超时 / 取消以 §4.7 为准；本文不复制字段定义。

4.4 安装 / 卸载入口

scripts/install-gpu.sh --qwen3
scripts/install-gpu.sh --qwen3 --qwen-runtime vulkan
scripts/install-gpu.sh --qwen3 --backend qwen3
scripts/install-gpu.sh --qwen3 --uninstall
scripts/install-gpu.ps1 --qwen3 --qwen-runtime cuda
选项行为
--qwen3只安装预编译的 Qwen worker / runtime 包与 qwen3-asr-1.7b 模型；不改变 final.backend。
--qwen-runtime vulkan|cuda选择预编译的 Qwen worker / runtime 变体；AMD Linux 只接受 vulkan；不提供 HIP / ROCm。
--backend qwen3安装后写入 final.backend = qwen3；该后端必须已安装；不自动重启 daemon。
--uninstall删除 Qwen worker、runtime 包与 qwen3-asr-1.7b 模型；不触碰核心、FireRed 后端或另一个 runtime。
--no-models只装 worker 与 runtime 包；模型目录由用户提供，仍按 §4.1 校验。
--source-dir <dir>离线模型 / runtime 源；不联网。
  • GPU 安装脚本先验证核心已安装；缺少核心时失败，不创建“只有 GPU 模块”的孤立安装。
  • 安装体积约 4.7 GB；脚本显示模型体积并支持断点续传 / 离线源；下载失败非零退出并清理临时目录，不写 manifest、不做 rename。
  • 卸载只删除本后端；Qwen 的配置值不静默改写。若 final.backend 仍为 qwen3，daemon 按 §4.3 标记不可用并回退 CPU。
  • Windows 与 Linux 使用同一语义：install-gpu.ps1 的 --qwen3 / --qwen-runtime / --uninstall 与 Linux 对应。
  • 安装脚本只在安装阶段准备 runtime；运行期不安装、不编译、不切换 runtime。
