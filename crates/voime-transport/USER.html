状态：目标 P0 接口。本文是 daemon / CLI / Rust 前端共同消费的传输契约； Unix 与 Windows 实现必须满足同一组语义。

1. TERMS

↑

术语定义
端点（Endpoint）一个本机传输地址：Unix 文件系统路径或 Windows 命名管道名。
监听器（Listener）已绑定的端点；可阻塞 accept，也可从其他线程 shutdown 唤醒。
流（Stream）一个已建立的字节流；实现 Read + Write + Send。
bind创建 listener；负责父目录 / 权限 / 陈旧端点处理。
connect客户端连接端点并返回 stream。
accept从 listener 取出下一个 stream；阻塞直到有连接或被 shutdown 唤醒。
try_clone复制流句柄，供读线程与写线程独立使用（Unix fd / Windows handle）。
shutdown关闭 listener / stream，并唤醒阻塞的 accept / read。
EOF对端关闭；读操作返回 0 字节。

2. CONVENTIONS

↑

约定内容
平台选择使用 cfg(unix) / cfg(windows) 与 target-specific dependencies；不引入用户可见的 --features unix / --features windows。
契约共享Unix 与 Windows 实现不共享代码，只共享 trait 与函数签名。
字节流只负责字节读写；不解析 JSON、不检查消息长度、不处理协议版本。
阻塞语义accept 与 read 可以阻塞；shutdown 必须能从其他线程唤醒。
线程安全Listener 必须 Send + Sync，可从 accept 线程与关闭线程共享；Stream 至少 Send。
读写分离daemon 每个客户端用 try_clone 复制流：一个线程读、一个线程写。
安全只允许当前用户访问：Unix 目录 0700 / socket 0600；Windows 当前用户 DACL、拒绝远程客户端。
陈旧端点bind 前检查是否已有活动 daemon；Unix 删除陈旧 socket，Windows 关闭即消失。
错误统一返回 io::Error，附端点 / 管道名上下文；不把 OS 错误码暴露给上层业务。
测试内存 transport 只用于测试，放在 cfg(test) 或 dev-dependency，不作为生产 feature。

3. DIAGRAMS

↑

3.1 绑定、连接与关闭

  • daemon 先 bind，客户端再 connect；accept 线程持续取出连接。
  • 关闭 listener 会唤醒阻塞 accept；关闭 stream 会唤醒阻塞 read。
  • 平台实现差异只出现在虚线框内，上层看到同一组方法。

4. INTERFACES

↑

4.1 端点

pub enum Endpoint {
    #[cfg(unix)]
    Unix(PathBuf),
    #[cfg(windows)]
    NamedPipe(String),
}
变体平台契约
Unix(PathBuf)Linux / macOS 等 Unix文件系统路径；父目录由 transport 创建并设为 0700。
NamedPipe(String)Windows形如 \\.\pipe\voime-<session>-<user>；名字包含会话与用户标识。

4.2 Listener / Stream

pub trait Stream: Read + Write + Send {
    fn try_clone(&self) -> io::Result<Box<dyn Stream>>;
    fn shutdown(&mut self) -> io::Result<()>;
}

pub trait Listener: Send + Sync {
    fn accept(&self) -> io::Result<Box<dyn Stream>>;
    fn shutdown(&self) -> io::Result<()>;
}
方法契约
Stream::try_clone复制底层句柄；Unix 复制 fd，Windows 使用 DuplicateHandle。克隆出的流共享同一连接。
Stream::shutdown关闭读写方向并唤醒阻塞 read；幂等。
Listener::accept阻塞直到新连接；listener 被 shutdown 后返回错误。
Listener::shutdown唤醒阻塞 accept 并释放端点；可从其他线程调用。

4.3 入口函数

pub fn bind(endpoint: &Endpoint) -> io::Result<Box<dyn Listener>>;
pub fn connect(endpoint: &Endpoint) -> io::Result<Box<dyn Stream>>;
函数契约
bind创建父目录 / 安全描述符、处理陈旧端点、绑定并返回 listener；端点已被活动 daemon 占用时返回错误。
connect连接端点并返回 stream；失败附端点上下文。

4.5 错误

错误触发条件建议动作
端点已存在且可连接已有 daemon 在运行。daemon 幂等退出；客户端直接连接。
权限错误目录 / socket / DACL 不允许当前用户。检查运行用户与安装权限；不要放宽到其他用户。
连接被拒绝daemon 未启动或端点陈旧。客户端重试；daemon 清理陈旧端点。
accept / read 被 shutdown 唤醒daemon 正在关闭。上层视为正常退出。
句柄复制失败fd / handle 耗尽或权限不足。关闭客户端；记录上下文。
