2. CONVENTIONS

↑

约定内容
薄 adapter只做端点、句柄、权限、accept / connect / clone / shutdown；不解析消息、不维护会话。
平台隔离lib.rs 只做 cfg 分发；Unix / Windows 模块互不引用。
句柄所有权listener 拥有绑定端点；stream 拥有连接；drop 时释放资源。Unix bind 负责删除自己的 socket 文件，但不能删除其他 daemon 的端点。
关闭唤醒listener 的内部句柄 / 原子标志必须支持跨线程取消，所以 shutdown(&self)。
Windows 读写同步命名管道的挂起 ReadFile 会阻塞同连接的写；read 先用 PeekNamedPipe 轮询可用字节，再同步读取。shutdown 设置共享取消标志并调用 CancelIoEx。
错误上下文所有 io::Error 在边界处附端点路径 / 管道名；上层不解析 Win32 错误码。
安全默认权限收紧而不是放宽；不提供“允许其他用户连接”的开关。
测试内存 transport 仅用于跨平台契约测试；不进入生产构建。

5. Call stack tree

↑

5.1 bind

voime_transport::bind(endpoint)
├── 判断 cfg(unix)
│   └── unix::bind(path)
│       ├── unix::prepare_parent(path)
│       ├── 判断 path.exists()
│       │   ├── UnixStream::connect(path) 成功 → io::Error（daemon 已在运行）
│       │   └── std::fs::remove_file(path)
│       ├── UnixListener::bind(path)
│       ├── std::fs::set_permissions(path, 0o600)
│       └── UnixListener::set_nonblocking(true)
└── 判断 cfg(windows)
    └── windows::bind(name)
        ├── windows::current_user_sddl()
        └── CreateNamedPipeW(..., PIPE_REJECT_REMOTE_CLIENTS)

5.2 accept 与关闭

voimed accept thread
└── Listener::accept()
    ├── UnixListener::accept()
    └── NamedPipeListener::accept()
        ├── duplicate_current_thread()
        └── ConnectNamedPipe()

voimed shutdown
└── Listener::shutdown(&self)
    ├── 设置取消标志
    ├── UnixListener::shutdown()
    └── NamedPipeListener::shutdown()
        ├── CancelSynchronousIo(accept 线程)
        └── CancelIoEx / CloseHandle

5.3 connect 与读写分离

voime::client::Client::connect(endpoint)
└── voime_transport::connect(endpoint)
    ├── UnixStream::connect(path)
    └── NamedPipeStream::connect(name)

client::reader thread
└── Stream::try_clone()
    ├── UnixStream::try_clone()（dup fd）
    └── NamedPipeStream::try_clone()（DuplicateHandle）
        └── BufReader::read

5.4 字节流关闭

Client::drop()
├── Stream::shutdown(&mut stream)
│   ├── UnixStream::shutdown(Both)
│   └── NamedPipeStream::DisconnectNamedPipe / CloseHandle
└── Drop for Stream（释放句柄）
