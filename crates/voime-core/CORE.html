2. CONVENTIONS

↑

约定内容
线程模型pipeline 只有一个工作线程；音频回调线程只做格式转换与入队；不引入异步运行时。
音频通道容量由 audio::capture::AUDIO_CHANNEL_CAPACITY 拥有；回调使用 try_send，满时丢弃当前块，不阻塞设备线程。
命令通道有界；worker 使用 select_biased!，命令优先于音频，保证 Stop 不被积压音频阻塞。
Fbank 生命周期StreamingFbank 只服务 VAD，保留滑动窗口与未消费样本；Fbank::compute 每次从完整段独立计算，服务 CTC。两者不共享实例。
CTC 状态每帧更新 prev（包括 blank）；仅当 id != 0 && id != prev 时输出；final 与尾部 partial 复用同一会话，不跨段保留状态。
Partial 门槛最小间隔、最小新增音频与尾部长度由 pipeline 模块常量拥有；一次慢推理会推迟下一次 Partial，避免立即重跑。
分段MIN_SPEECH_MS / MIN_SILENCE_MS / PTT_AUTO_END_MS 由 segmenter 模块拥有；达到 max_segment_ms 时强制结束。
模型校验加载清单时校验 schema、采样率、张量声明与参数范围；verify 校验文件存在、非空与 SHA-256；rebase 拒绝绝对路径与 ..。
错误边界库内部使用 anyhow::Result + 上下文；音频错误类型保留 AudioError；pipeline 把可恢复错误转为 SegmentDropped。
无 OS 依赖不直接使用 Unix socket、named pipe、Fcitx、Win32 或 TUI API；config 只保留模型目录的 XDG / HOME 回退。
  • 仓库级依赖方向与进程边界见 根 CORE §2。
  • 工程常量不在此表赋值；具体值以源码为准，推荐值可写在签名注释中。
  • 当前 Mode 来自 voime-ipc；彻底去除该依赖的方案见 PLATFORM §3.4。

5.1 启动与模型加载

voimed::main()
└── voime_core::config::resolve(args)
    ├── ModelManifest::load(manifest.json)
    ├── ModelManifest::verify(model_dir)
    │   ├── verify_file(vad/model, sha256)
    │   ├── verify_file(asr/model.int8.onnx, sha256)
    │   └── verify_file(punc/model.onnx, sha256)
    └── ModelManifest::rebase(model_dir)

voime_core::pipeline::spawn(&config, factory, audio_rx)
├── std::thread::Builder::spawn(Worker::run)
└── Worker::new(&manifest, &factory, events)
    ├── FireRedVad::new(&manifest.vad, factory, VadConfig)
    ├── FireRedCtc::new_with_factory(&manifest.asr, factory)
    ├── FireRedPunc::new_with_factory(&manifest.punc, factory, PuncConfig)
    └── Segmenter::new(manifest.max_segment_ms)
  • 模型校验、会话创建与 worker 启动在 pipeline::spawn 返回前完成；任一步失败直接返回错误。
  • 音频设备在 pipeline 成功后才打开；见 voimed CORE §5.1。

5.2 音频、VAD 与 Continuous

Worker::run(audio_rx, commands)
└── loop
    ├── crossbeam_channel::select_biased!
    │   ├── 判断 command → Worker::handle_command(command)
    │   └── 判断 AudioChunk → Worker::handle_audio(chunk)
    └── Worker::drain_queue()

Worker::handle_audio(chunk)
├── 判断 chunk.is_stream_error() → 丢弃当前段 + Recording(false)
├── 判断 !should_process() → 清空待处理音频并返回
├── 判断 resampler.is_none() → StreamResampler::new(chunk.sample_rate, chunk.channels)
├── StreamResampler::push(chunk)
└── Worker::process_pending_audio(false)
    └── Worker::process_vad_batch(batch, frame_samples)
        ├── FireRedVad::push(batch)
        └── 逐帧 Worker::handle_frame(frame, audio)
            └── Segmenter::push(frame, samples, mode)
                ├── 判断 SpeechStart → PipelineEvent::Recording(true)
                ├── 判断 Partial 门槛 → Worker::emit_partial()
                └── 判断 SpeechEnd → Worker::finalize(segment) / enqueue(segment)
  • Continuous 的 SpeechEnd 进入容量有限的完成段队列；PTT / Toggle 立即 finalize。
  • Toggle 在 SpeechEnd 后保持 collecting=true 并再次发送 Recording(true)；PTT 仅在 MaxDuration 时继续收集。

5.3 PTT / Toggle 命令

Pipeline::start_segment()
└── PipelineCommand::StartSegment
    └── Worker::handle_command(StartSegment)
        ├── 判断 mode != Continuous && !collecting && !segmenter.is_active()
        ├── FireRedVad::reset()
        ├── Segmenter::reset()
        └── PipelineEvent::Recording(true)

Pipeline::finish_segment()
└── PipelineCommand::FinishSegment
    ├── Worker::prepare_command(FinishSegment)
    │   ├── 排空 audio_rx
    │   └── Worker::process_pending_audio(true)
    └── Worker::handle_command(FinishSegment)
        ├── Segmenter::force_end()
        ├── PipelineEvent::Recording(false)
        └── Worker::finalize(segment) / SegmentDropped

5.4 Partial

Worker::emit_partial()
├── 判断 !segmenter.is_active() → reset_partial_schedule()
├── 截取 active_samples() 末尾 PARTIAL_MAX_MS
├── Fbank::new(fbank).compute(tail)
├── FireRedCtc::transcribe(features)
├── 判断 text 非空 → PipelineEvent::Partial(text)
└── Worker::finish_partial_schedule(started)
  • 尾部被截断时文本前加省略号；Partial 不进入历史、不提交。
  • 慢推理会按耗时推迟下一次 Partial；具体调度见 finish_partial_schedule。

5.5 Final 与标点

Worker::finalize(segment)
├── 判断 segment.samples.is_empty() → SegmentDropped("空语音段")
├── Fbank::new(fbank).compute(segment.samples)
├── 判断 features.is_empty() → SegmentDropped("音频过短")
├── FireRedCtc::transcribe(features)
├── 判断 asr.text.trim().is_empty() → SegmentDropped("空识别结果")
├── FireRedPunc::punctuate(&asr.text)
├── Worker::reset_after_segment()
└── 判断 final 非空 → PipelineEvent::Final(final)

5.6 音频错误、丢弃与关闭

Worker::handle_audio(chunk)
└── 判断 chunk.is_stream_error()
    ├── audio_error_streak += 1
    ├── Segmenter::reset()
    ├── FireRedVad::reset()
    ├── PipelineEvent::Recording(false)
    ├── PipelineEvent::SegmentDropped("音频流错误")
    └── 判断 audio_error_streak >= AUDIO_STREAM_ERROR_LIMIT → anyhow::bail!

Pipeline::shutdown()
├── PipelineCommand::Shutdown
├── Worker::run 返回
└── JoinHandle::join()

Worker::drain_queue()
└── 逐个 Worker::finalize(segment)
