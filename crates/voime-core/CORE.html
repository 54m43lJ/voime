2. CONVENTIONS

↑

约定内容
线程模型pipeline 只有一个工作线程；音频回调线程只做格式转换与入队；不引入异步运行时。CPU Final 由 daemon 在 Finalizing 调用，核心用同一把推理锁与 Preview 串行化。
音频通道容量由 audio::capture::AUDIO_CHANNEL_CAPACITY 拥有；回调使用 try_send，满时丢弃当前块，不阻塞设备线程。
命令通道有界；worker 使用 select_biased!，命令优先于音频，保证 Stop / CancelPreview 不被积压音频阻塞。
Fbank 生命周期StreamingFbank 只服务 VAD，保留滑动窗口与未消费样本；Fbank::compute 每次从完整段独立计算，服务 SenseVoice。两者不共享实例。
SenseVoice 预处理80-bin fbank、25 / 10 ms、LFR 7 / 6、560 维 CMVN、use_itn=true；参数由模型 manifest 固定，代码不硬编码替代值。
Preview 门禁pipeline 持有 preview_gate；FinishSegment / CancelPreview 关闭门禁并丢弃未开始的预览任务；StartSegment 重新打开。
Partial 门槛最小间隔、最小新增音频与尾部长度由 pipeline 模块常量拥有；一次慢推理会推迟下一次 Partial，避免立即重跑。
分段MIN_SPEECH_MS / MIN_SILENCE_MS / PTT_AUTO_END_MS 由 segmenter 模块拥有；达到 MAX_SEGMENT_MS 时强制结束。
最长段MAX_SEGMENT_MS 固定 30 s 上限，推荐值 30_000；manifest 的 max_segment_ms 与长段测试使用同一上限。
模型校验加载 manifest 时校验 schema 5、id 等于目录名、kind 匹配；verify 校验文件存在、大小、非空与 SHA-256；rebase 拒绝绝对路径与 ..。
错误边界库内部使用 anyhow::Result + 上下文；音频错误类型保留 AudioError；pipeline 把可恢复错误转为 SegmentDropped。
无 OS 依赖不直接使用 Unix socket、named pipe、Fcitx、Win32 或 TUI API；config 只保留模型目录的平台默认值回退（Windows 读 LOCALAPPDATA，Unix 走 XDG / HOME）。
  • 仓库级依赖方向与进程边界见 根 CORE §2。
  • 工程常量不在此表赋值；具体值以源码为准，推荐值可写在签名注释中。

└── Worker::new(&config.models, &factory, events)

  • 音频设备在 pipeline 成功后才打开；见 voimed CORE §5.1。

5.2 音频、VAD 与 Continuous

Worker::run(audio_rx, commands)
└── loop
    ├── crossbeam_channel::select_biased!
    │   ├── 判断 command → Worker::handle_command(command)
    │   └── 判断 AudioChunk → Worker::handle_audio(chunk)
    └── Worker::drain_queue()

Worker::handle_audio(chunk)
├── 判断 chunk.is_stream_error() → 丢弃当前段 + Recording(false)
├── 判断 !should_process() → 清空待处理音频并返回
├── 判断 resampler.is_none() → StreamResampler::new(chunk.sample_rate, chunk.channels)
├── StreamResampler::push(chunk)
└── Worker::process_pending_audio(false)
    └── Worker::process_vad_batch(batch, frame_samples)
        ├── FireRedVad::push(batch)
        └── 逐帧 Worker::handle_frame(frame, audio)
            └── Segmenter::push(frame, samples, mode)
                ├── 判断 SpeechStart → PipelineEvent::Recording(true)
                ├── 判断 preview_gate 开启且达到 Partial 门槛 → Worker::emit_partial()
                └── 判断 SpeechEnd → Worker::emit_segment(segment) / enqueue(segment)
  • Continuous 的 SpeechEnd 进入容量有限的完成段队列；PTT / Toggle 立即 emit_segment。
  • Toggle 在 SpeechEnd 后保持 collecting=true 并再次发送 Recording(true)；PTT 仅在 MaxDuration 时继续收集。

5.3 PTT / Toggle 命令与 Finalizing

Pipeline::start_segment()
└── PipelineCommand::StartSegment
    └── Worker::handle_command(StartSegment)
        ├── 判断 mode != Continuous && !collecting && !segmenter.is_active()
        ├── FireRedVad::reset()
        ├── Segmenter::reset()
        ├── preview_gate = true
        └── PipelineEvent::Recording(true)

Pipeline::finish_segment()
└── PipelineCommand::FinishSegment
    ├── Worker::prepare_command(FinishSegment)
    │   ├── 排空 audio_rx
    │   └── Worker::process_pending_audio(true)
    └── Worker::handle_command(FinishSegment)
        ├── Worker::cancel_preview()
        │   ├── preview_gate = false
        │   └── 丢弃未开始的预览任务
        ├── Segmenter::force_end()
        ├── PipelineEvent::Recording(false)
        └── Worker::emit_segment(segment) / SegmentDropped

Pipeline::cancel_preview()
└── PipelineCommand::CancelPreview
    └── Worker::handle_command(CancelPreview)
        └── Worker::cancel_preview()
  • FinishSegment 与 CancelPreview 都幂等；重复取消不会产生新事件。
  • Finalizing 期间 emit_partial 直接返回；下一个 StartSegment 重新打开门禁。

5.4 Preview

Worker::emit_partial()
├── 判断 !preview_gate → reset_partial_schedule()
├── 判断 !segmenter.is_active() → reset_partial_schedule()
├── 截取 active_samples() 末尾 PARTIAL_MAX_MS
├── Fbank::new(fbank).compute(tail)
├── apply_lfr(features, 7, 6)
├── SenseVoice::transcribe(features)
├── 判断 text 非空 → PipelineEvent::Partial(text)
└── Worker::finish_partial_schedule(started)
  • 尾部被截断时文本前加省略号；Partial 不进入历史、不提交。
  • 慢推理会按耗时推迟下一次 Partial；具体调度见 finish_partial_schedule。

5.5 CPU Final

voimed::daemon::Daemon::finalize(segment)
├── 判断 backend == Cpu → Final::transcribe(segment.samples)
│   ├── 判断 samples.is_empty() → 返回空字符串
│   ├── Fbank::new(fbank).compute(segment.samples)
│   ├── 判断 features.is_empty() → 返回空字符串
│   ├── apply_lfr(features, 7, 6)
│   ├── SenseVoice::transcribe(features)
│   └── 返回 asr.text
├── 判断 text.trim().is_empty() → SegmentDropped
└── IpcServer::broadcast(Final { segment_id, text })
  • CPU Final 只执行一次；GPU Final 不调用本路径，只有 GPU 失败回退时才调用。
  • Final 与 Preview 共用 SenseVoice 会话；核心推理锁保证 Finalizing 期间没有并行 Preview。

5.6 音频错误、丢弃与关闭

Worker::handle_audio(chunk)
└── 判断 chunk.is_stream_error()
    ├── audio_error_streak += 1
    ├── Segmenter::reset()
    ├── FireRedVad::reset()
    ├── Worker::cancel_preview()
    ├── PipelineEvent::Recording(false)
    ├── PipelineEvent::SegmentDropped("音频流错误")
    └── 判断 audio_error_streak >= AUDIO_STREAM_ERROR_LIMIT → anyhow::bail!

Pipeline::shutdown()
├── PipelineCommand::Shutdown
├── Worker::run 返回
└── JoinHandle::join()

Worker::drain_queue()
└── 逐个 Worker::emit_segment(segment)
