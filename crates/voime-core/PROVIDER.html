本文只记录 voime-core 实际消费的外部子集：cpal 音频接口、ONNX Runtime 会话接口 与模型包文件契约。完整定义以官方文档为准；产品级下边界见 根 PROVIDER。

1. TERMS

↑

术语定义
cpal host平台音频后端；Linux 上通常为 ALSA，Windows 上为 WASAPI。
输入设备（device）cpal 枚举到的录音端点；本项目按设备名精确匹配。
输入流（stream）cpal 建立的回调流；数据回调交付 PCM，错误回调交付 StreamError。
样本格式（sample format）设备原生样本类型；当前只支持 I16 / U16 / F32。
ONNX Runtime 环境进程级推理环境；本项目只启用 CPU Execution Provider。
ONNX 会话（session）加载一个 ONNX 模型并可执行推理的运行时对象。
metadataONNX 模型自带的键值元数据；CTC 的 CMVN 从这里读取。
Execution ProviderONNX Runtime 的推理后端；本项目只使用 CPU。
fbankKaldi 风格梅尔滤波器组特征；参数由模型清单声明。
CMVN倒谱均值方差归一化；cmvn_mean / cmvn_inv_stddev 两个 metadata。
模型包VAD / CTC / Punc 的 ONNX、词表、标签与 manifest.json。
manifest模型包的权威描述：文件、SHA-256、张量、fbank、分段上限。
Artifactmanifest 中一个 ONNX 条目；含相对路径、SHA-256、输入 / 输出张量。
SHA-256模型文件内容摘要；启动时逐文件校验。

2. CONVENTIONS

↑

约定内容
设备选择--input-device 按设备名精确匹配；未指定时使用 cpal 默认输入设备。
音频格式设备原生格式由核心转换为 16 kHz、单声道、f32；只接受 I16 / U16 / F32。
本地性音频、模型与推理都在本机完成；运行期不联网。
模型不可变模型包运行期只读；启动时校验 SHA-256 与张量签名，失败不进入运行态。
清单权威ONNX 输入输出、fbank 参数、帧移、词表与标签由 manifest.json 声明；代码不硬编码形状。
CPU 推理只启用 CPU Execution Provider；线程数由命令行决定。
量化默认 int8 ONNX；运行期不做动态量化。
CTC 模式单 ONNX；CMVN 从 metadata 读取；greedy 解码在项目侧完成。
VAD 模式流式状态张量；状态由清单声明为固定形状，项目侧保存与更新。
错误映射Provider 错误在边界处转换为项目错误并附上下文；启动期写日志 / 返回错误，运行期按 §4.5 处理。

3. DIAGRAMS

↑

3.1 音频采集边界

  • 回调只负责把设备样本转换为 AudioChunk 并入队；重采样与 VAD 在项目内部完成。
  • 错误回调与数据回调可能来自不同线程；错误以零长度哨兵写入同一有界通道。

3.2 模型加载与推理边界

  • 启动时读取并校验模型文件，然后创建会话；每个语音段只重置解码状态，不重新加载权重。
  • VAD 与 FireRedPunc 各自使用独立 ONNX 会话；CTC 单会话。

4.2 模型包

{
  "schema": 2,
  "sample_rate": 16000,
  "fbank": { "num_bins": 80, "frame_ms": 25, "shift_ms": 10 },
  "max_segment_ms": 30000,
  "vad": {
    "model": "vad/stream-vad.onnx",
    "sha256": "...",
    "inputs": [ ... ],
    "outputs": [ ... ]
  },
  "asr": {
    "kind": "fire-red-ctc",
    "model": {
      "model": "asr/model.int8.onnx",
      "sha256": "...",
      "inputs": [ ... ],
      "outputs": [ ... ]
    },
    "tokens": "asr/tokens.txt",
    "token_count": 8667
  },
  "punc": {
    "model": "punc/model.onnx",
    "sha256": "...",
    "vocab": "punc/vocab.txt",
    "labels": "punc/labels.json"
  }
}
项目契约
ASR 文件asr/model.int8.onnx（约 740 MiB）+ asr/tokens.txt。
ASR 输入x: float32[1,T,80] fbank；x_lens: int64[1]。
ASR 输出log_probs: float32[1,T',8667]；log_probs_len: int64[1]。
CMVNONNX metadata cmvn_mean / cmvn_inv_stddev；运行期做 (x - mean) * inv_stddev。值可能是 JSON 数组或空白 / 逗号 / 分号分隔的浮点串；两者都必须解析，mean 与 inv_stddev 必须等长且非空。
词表tokens.txt 每行为 token 与 id；id 0 为 blank；英文 ▁ 转为空格；token_count 必须等于输出类别数。
VAD 输入fbank 特征 + 清单声明的状态张量；状态形状必须固定。
VAD 输出逐帧语音概率；数量必须等于本批特征帧数。
Punc 输入input_ids 为词表 id；attention_mask 固定 1；token_type_ids 是 0/1 句段 id，固定填 0，不能填 token id。
Punc 输出逐 token 类别 logits；类别数不得小于标签表。
安装安装脚本下载官方 .tar.bz2，解出 ONNX / tokens 并写 manifest。
  • 官方模型包为 sherpa-onnx-fire-red-asr2-ctc-zh_en-int8-2026-02-25；model.int8.onnx 775,861,420 bytes，SHA-256 ca3dbabd82170110cc0b343c2890866d449984bc9cd92b9a18371ff80a81bb99；tokens.txt SHA-256 1bc613de2112d257e61a349c3e72d1b1a9cf19c33d3ca954197ad2171e5ea07b。官方包不含 cmvn.ark。
  • 预处理与 sherpa 对齐：normalize_samples=false、dither=0、snip_edges=true、low_freq=20、high_freq=0、use_power=true、use_log_fbank=true，输入乘 32768。
  • 模型为 Conformer 编码器 + 线性 CTC head，没有帧级 cache；VAD 负责流式切分，CTC 每次处理完整语音段。

4.3 推理运行时：ONNX Runtime / ort

消费项签名 / 类型用途
环境ort::EnvironmentCPU Execution Provider 与线程配置。
会话SessionBuilder::commit_from_file(path) -> Session加载 VAD / CTC / Punc ONNX。
元数据Session::metadata()读取 CTC 的 cmvn_mean / cmvn_inv_stddev。
输入Tensor::from_array((shape, data))x / x_lens 等张量。
推理Session::run(inputs![...])执行 CPU 推理。
输出try_extract_tensor::<T>()读取 logits / log_probs / 概率。
  • CTC 单会话；final 与尾部 partial 复用同一个 FireRedCtc，不跨段保留状态。
  • greedy CTC 在项目侧完成：argmax → 合并连续重复 → 去掉 blank 0 → tokenizer。
  • 只启用 CPU Execution Provider；不注册 GPU / NPU 后端。

4.5 错误与处理

AudioError 的变体定义见 voime-core USER §4.5； 本表只记录 provider 触发条件与映射。

错误触发条件处理
NoInputDevice系统没有默认输入设备。daemon 启动失败，stderr + 退出码 1。
DeviceNotFound--input-device 名称不存在。daemon 启动失败。
UnsupportedSampleFormat设备只提供 I16 / U16 / F32 之外的格式。daemon 启动失败。
StreamLost / 流错误哨兵运行期音频流错误。丢弃当前段；连续失败后 daemon 退出。
模型文件缺失 / SHA-256 不匹配模型文件缺失或被修改。daemon 启动失败。
张量 / 会话错误ONNX 元数据与 manifest 不符或会话创建失败。daemon 启动失败。
CMVN 错误缺少 metadata、维度不一致或解析失败。daemon 启动失败。
词表错误tokens.txt 行格式错误、id 重复或数量不符。daemon 启动失败。
  • 模型 / 推理错误当前以 anyhow::Error + 路径 / 张量上下文返回，不伪造统一 Provider 错误枚举。
  • 运行期单段推理错误转为 PipelineEvent::SegmentDropped，不终止 daemon。
