本文只记录 voime-core 实际消费的外部子集：cpal 音频接口、ONNX Runtime 会话接口 与模型包文件契约。完整定义以官方文档为准；产品级下边界见 根 PROVIDER。

1. TERMS

↑

术语定义
cpal host平台音频后端；Linux 上通常为 ALSA，Windows 上为 WASAPI。
输入设备（device）cpal 枚举到的录音端点；本项目按设备名精确匹配。
输入流（stream）cpal 建立的回调流；数据回调交付 PCM，错误回调交付 StreamError。
样本格式（sample format）设备原生样本类型；当前只支持 I16 / U16 / F32。
ONNX Runtime 环境进程级推理环境；voime-core 只启用 CPU Execution Provider。
ONNX 会话（session）加载一个 ONNX 模型并可执行推理的运行时对象。
metadataONNX 模型自带的键值元数据；SenseVoice 的 CMVN / LFR / ITN 从这里读取。
Execution ProviderONNX Runtime 的推理后端；本组件只使用 CPU；Vulkan / CUDA runtime 在对应 GPU worker。
fbankKaldi 风格梅尔滤波器组特征；参数由模型清单声明。
CMVN倒谱均值方差归一化；SenseVoice 使用 neg_mean / inv_stddev 两个 metadata。
模型包SenseVoice + FireRedVAD 基础包的 ONNX / 词表 / 标签与 manifest.json；FireRed / Qwen 包由 voime-gpu 消费。
manifest模型包的权威描述：schema、文件、SHA-256、张量、fbank、分段上限、requires 与 backend。
Artifactmanifest 中一个 ONNX 条目；含相对路径、SHA-256、输入 / 输出张量。
SHA-256模型文件内容摘要；启动时逐文件校验。

2. CONVENTIONS

↑

约定内容
设备选择--input-device 按设备名精确匹配；未指定时使用 cpal 默认输入设备。
音频格式设备原生格式由核心转换为 16 kHz、单声道、f32；只接受 I16 / U16 / F32。
本地性音频、模型与推理都在本机完成；运行期不联网。
模型不可变模型包运行期只读；启动时校验 SHA-256 与张量签名，失败不进入运行态。
清单权威ONNX 输入输出、fbank 参数、帧移、词表与标签由 manifest.json 声明；代码不硬编码形状。
CPU 推理只启用 CPU Execution Provider；线程数由命令行决定。Vulkan / CUDA runtime 只属于 GPU worker。
量化SenseVoice 使用 int8 ONNX；FireRed / Qwen 使用 FP16，但不在本组件加载。
SenseVoice 模式单 ONNX；CMVN / LFR / ITN 从 metadata 读取；greedy 解码在项目侧完成。
VAD 模式流式状态张量；状态由清单声明为固定形状，项目侧保存与更新；VAD 保持现状。
Final 包核心只消费 daemon 传入的 Final manifest；GPU 包的 requires / backend 由核心校验，张量由 worker 校验。
错误映射Provider 错误在边界处转换为项目错误并附上下文；启动期写日志 / 返回错误，运行期按 §4.5 处理。

3. DIAGRAMS

↑

3.1 音频采集边界

  • 回调只负责把设备样本转换为 AudioChunk 并入队；重采样与 VAD 在项目内部完成。
  • 错误回调与数据回调可能来自不同线程；错误以零长度哨兵写入同一有界通道。

3.2 模型加载与推理边界

  • 启动时读取并校验模型文件，然后创建会话；每个语音段只重置解码状态，不重新加载权重。
  • VAD 与 SenseVoice 使用独立 CPU ONNX 会话；FireRedPunc 在 FireRed worker 内。
  • FireRed / Qwen 不在本组件加载；它们的张量与 runtime 见 voime-gpu PROVIDER §4.2。

项目契约
schema只接受 4；旧 schema 直接拒绝。
ASR 文件asr/model.int8.onnx（约 229 MiB）+ asr/tokens.txt；SenseVoice 包不含 punc/。
ASR 输入x: float32[1,T,560] LFR fbank；x_length: int32[1]；language / text_norm: int32[1]。
ASR 输出logits: float32[1,T',25055]；greedy 解码在项目侧完成。
fbank / LFR / CMVN80 bin、25 / 10 ms、hamming；LFR 7 / 6，保持当前完整窗口实现；CMVN 560 维，从 metadata 读取，(x + neg_mean) * inv_stddev。
metadata必须提供 LFR、normalize_samples、vocab_size、blank_id、ITN、语言 id、neg_mean / inv_stddev；清单只声明期望值，启动时交叉校验。
词表tokens.txt；token_count 必须等于 25055；不要从词表推断语言 / ITN id。
VAD 输入fbank 特征 + 清单声明的状态张量；状态形状必须固定。
VAD 输出逐帧语音概率；数量必须等于本批特征帧数。
requires / backendSenseVoice 基础包写 backend.kind=builtin；GPU 包必须写 requires: ["sense-voice-2024-int8"] 与 backend.kind=worker，模型契约见 voime-gpu PROVIDER §4.2。
安装安装脚本下载官方包，解出 ONNX / tokens 并写 manifest；安装后校验 SHA-256 与 metadata。
  • 官方 SenseVoice 包为 sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17；use_itn=true、内置标点，不再提供 noITN + FireRedPunc 变体。
  • FireRed / Qwen 的模型、FP16、前端与 GPU runtime 契约写在 voime-gpu PROVIDER §4.2，不在本文件重复。

4.3 推理运行时：ONNX Runtime / ort

消费项签名 / 类型用途
环境ort::Environment只配置 CPU Execution Provider 与线程数。
会话SessionBuilder::commit_from_file(path) -> Session加载 VAD / SenseVoice ONNX。
元数据Session::metadata()读取 SenseVoice 的 CMVN、LFR、ITN 与语言 id。
输入Tensor::from_array((shape, data))x / x_length / language / text_norm。
推理Session::run(inputs![...])执行 CPU 推理。
输出try_extract_tensor::<T>()读取 logits / 概率。
  • 只启用 CPU Execution Provider；不注册 GPU / NPU 后端，不加载 GPU runtime。
  • CPU ort 版本按 proposal §3.5 实验结论固定；构建信息与 EP 写入金样测试。
  • greedy 解码在项目侧完成：argmax → 合并连续重复 → 去掉 blank 0 → AsrTokenizer。

4.5 错误与处理

AudioError 的变体定义见 voime-core USER §4.5； 本表只记录 provider 触发条件与映射。

错误触发条件处理
NoInputDevice系统没有默认输入设备。daemon 启动失败，stderr + 退出码 1。
DeviceNotFound--input-device 名称不存在。daemon 启动失败。
UnsupportedSampleFormat设备只提供 I16 / U16 / F32 之外的格式。daemon 启动失败。
StreamLost / 流错误哨兵运行期音频流错误。丢弃当前段；连续失败后 daemon 退出。
模型文件缺失 / SHA-256 不匹配模型文件缺失或被修改。daemon 启动失败。
张量 / 会话错误ONNX 元数据与 manifest 不符或会话创建失败。daemon 启动失败。
CMVN / metadata 错误缺少 metadata、维度不一致或解析失败。daemon 启动失败。
词表错误tokens.txt 行格式错误、id 重复或数量不符。daemon 启动失败。
requires 缺失GPU 包未声明 SenseVoice 基础包，或基础包不存在。拒绝加载 Final；SenseVoice Preview 仍可用。
GPU 包张量 / runtime 错误worker 侧发现 encoder / decoder 或 EP 不可用。由 voimed 标记 GPU Final 不可用并回退 CPU；core 只收到 worker 错误。
  • 模型 / 推理错误当前以 anyhow::Error + 路径 / 张量上下文返回，不伪造统一 Provider 错误枚举。
  • 运行期单段推理错误转为 PipelineEvent::SegmentDropped，不终止 daemon。
