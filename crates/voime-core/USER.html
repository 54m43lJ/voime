1. TERMS

↑

术语定义
音频块（AudioChunk）设备回调交付的一批 PCM 样本及其采样率 / 声道数；进入核心后统一转换为 16 kHz 单声道 f32。
流错误哨兵零采样率、零声道、空样本的 AudioChunk；由 cpal 错误回调写入音频通道，表示当前音频流失败。
VAD 帧（VadFrame）FireRedVAD 对固定帧移音频给出的语音概率与二值判断；帧移与 fbank 参数见 PROVIDER §4.2。
会话采集（collection）从 StartSegment 到 FinishSegment 的一段采集；PTT / Toggle 会话对应一个采集区间，可包含多个语音段。
语音段（Segment）分段器输出的一段 16 kHz 单声道样本及起止毫秒；产品级定义见 根 USER §1。
软切分PTT / Toggle 采集期间 VAD 报告终点：交付当前 Segment 后重置分段器，继续采集下一段，不结束会话。
硬切分FinishSegment：排空音频、强制结束当前段并停止采集；之后不再产生下一段，直到新的 StartSegment。
活动段分段器当前正在累积的语音段；Preview 只读取活动段末尾。
模型清单（ModelManifest）单个模型目录的权威描述：schema、id、kind、version、license、文件列表与 runtime 声明；不承载 ONNX 张量形状、fbank / LFR / CMVN 参数或词表内容。
文件条目（FileSpec）manifest 中一个文件的相对路径、SHA-256 与字节大小。
runtime 声明（RuntimeSpec）模型要求的 backend、format、precision 与 max_segment_ms；核心只读。
模型集合（ModelSet）模型根目录下的 firered-vad 与 sensevoice-small 两个模型清单。
会话工厂（SessionFactory）创建 CPU ONNX 会话并按模型目录校验输入 / 输出张量。
fbankKaldi 风格梅尔滤波器组特征；VAD 使用流式窗口，SenseVoice 使用整段独立计算。
LFR低帧率特征拼接；SenseVoice 默认使用 7 帧窗、6 帧移，输出 560 维；每条特征流只应用一次。
CMVN倒谱均值方差归一化；SenseVoice 对默认 560 维 LFR 特征做均值 / 方差归一化。
SenseVoice核心唯一 ASR 模型；同时服务 Preview 与 CPU Final，固定 use_itn=true，输出自带标点。
CPU Final（Final）对完整语音段执行一次 SenseVoice 推理并返回文本；不执行独立标点或其它二次标点。
Finalizing当前段结束到 Final 或丢弃结果到达之间的状态；期间不再产生新的 Partial。

2. CONVENTIONS

↑

约定内容
音频格式进入核心内部后统一为 16 kHz、单声道、f32；设备原生格式在核心内转换。
单活动段同一时刻只有一个语音段处于采集或收尾状态；调用方通过 Recording / SegmentReady 事件跟踪段边界。
段边界StartSegment 丢弃按键前已采集的音频；VAD SpeechEnd 在 PTT / Toggle 中执行软切分；FinishSegment 结束当前段（硬切分）。
Partial活动段的临时文本；可能滞后或丢弃；不进入历史、不提交。
Preview 中断FinishSegment 与 CancelPreview 后不再产生新的 Partial；软切分只冻结当前段，下一段继续。
CPU Final只对 SegmentReady 的完整段执行一次 SenseVoice；空音频或空文本不产生 Final 文本。
模式Mode 由 voime-ipc USER §4.1 定义；核心只消费，不解析命令行。PTT / Toggle 使用会话采集，Continuous 由 VAD 自动分段。
模型生命周期启动时按一模型一目录加载并校验 firered-vad / sensevoice-small；会话常驻内存；每段只重置解码状态，不重新加载权重。
模型目录核心只读取模型根目录下的两个固定目录；不扫描其它目录、不做动态发现、不接受别名或符号链接逃逸。
识别延迟识别慢于语音时完成段可能丢弃；采集与输入不被阻塞。
错误策略初始化失败返回错误；运行期单段失败产生 SegmentDropped；连续音频错误达到上限产生 Fatal。
无持久化不写音频、模型缓存或识别文本到磁盘；模型目录只读。

3. DIAGRAMS

↑

3.1 Pipeline 生命周期

  • 调用方只发送命令并消费事件；内部处理对调用方不可见。
  • PTT / Toggle 由调用方的 StartSegment / FinishSegment 划定会话；会话内 VAD 每次终点软切分并继续下一段。
  • FinishSegment 是硬切分：结束当前段并停止采集，直到下一次 StartSegment。
  • Continuous 由 VAD 端点自动分段，无会话命令。
  • Final 触发后 Preview 中断；完整段通过 SegmentReady 交给 daemon，由 daemon 选择 CPU 或 GPU Final。
  • 内部队列、Preview 节流与 Finalizing 状态见 CORE §2。

default_model_root平台默认模型根目录；端点由 voime-transport 管理。
  • final.backend 由 voimed 读取，不属于本组件配置。

项目契约

stop暂停并丢弃流；幂等，不等待回调结束。
格式覆盖当前只接受 I16 / U16 / F32；其他格式返回 UnsupportedSampleFormat。

pub struct Pipeline { /* ... */ }
pub struct Final { /* shared SenseVoice session */ }

pub fn spawn(config: &Config, factory: SessionFactory,

impl Pipeline {

    pub fn finish_segment(&self) -> anyhow::Result<()>;

    pub fn transcribe(&mut self, samples: &[f32]) -> anyhow::Result<String>;
}
消息 / 方法语义调用方处理
StartSegment打开采集会话；非 Continuous 模式下重置 VAD / 分段器并开始 Preview。已在采集时忽略。daemon 进入 Recording。
FinishSegment硬切分：结束当前段并停止 Preview；产生 SegmentReady 或 SegmentDropped，之后不再采集下一段。daemon 进入 Finalizing。
CancelPreview立即停止 Preview 并丢弃未开始的任务；幂等。下一个 StartSegment 重新开始。daemon 在 Final 触发时调用。
SetMode切换 ptt / toggle / continuous；存在活动段时 daemon 必须先 FinishSegment，旧段 Final / 丢弃后才调用。切换清理旧会话的待处理音频与 Partial 调度，不得截断活动段。daemon 在旧段收尾后同步配置。
Recording(true/false)段开始 / 采集结束；PTT / Toggle 每次软切分后再次产生 Recording(true) 表示下一段，硬切分时产生 Recording(false)。更新前端录音标记与 daemon phase。
Partial(text)活动段末尾的 SenseVoice 临时识别；可丢弃；当前段 Finalizing 期间不再产生。显示临时文本，不提交。
SegmentReady(segment)一次软切分或硬切分产生的完整段 PCM 与起止时间；核心不在事件中执行 Final。daemon 选择 CPU / GPU Final；CPU 调用 Final::transcribe。
SegmentDropped当前段因空音频、音频过短、SenseVoice 失败等原因被丢弃。daemon 清空当前段并广播 IPC Error{segment_dropped, segment_id}；会话仍活动时继续下一段，否则回到 Idle。
Fatal音频流连续失败或 pipeline 不可恢复错误。daemon 记录并退出。
Final::transcribe对完整段执行一次 SenseVoice CPU 推理；fbank、LFR、CMVN 各执行一次；空文本返回空字符串；不做二次标点。daemon 生成 Final 或按空段丢弃。
shutdown发送 Shutdown 并等待 worker 退出。daemon 停止服务。
  • Preview 与 CPU Final 的特征链路都只应用一次 LFR / CMVN；调用方不预先应用 LFR。
  • Mode 切换不截断活动段：daemon 先 FinishSegment，旧段 Final / 丢弃后才调用 SetMode；切换清理旧会话的采样与 Partial 调度，不把旧状态带入新会话。
  • Final 与 Preview 共用同一 SenseVoice 模型与会话；核心内部串行化推理，Finalizing 期间不会有 Preview 推理并发。
  • SegmentReady 之后由 daemon 决定走 CPU 还是 GPU；核心不读取 final.backend。
  • SegmentReady 是完整段的唯一交付点；daemon 不应从 Partial 拼接最终文本。
  • SegmentDropped 是核心内部事件；daemon 将它映射为 IPC Error{code:"segment_dropped", segment_id}，前端自行决定清理或提示。

4.5 错误

pub enum AudioError {
    NoInputDevice,
    DeviceNotFound { name: String },
    Devices(cpal::DevicesError),
    DefaultConfig(cpal::DefaultStreamConfigError),
    UnsupportedSampleFormat(cpal::SampleFormat),
    BuildStream(cpal::BuildStreamError),
    PlayStream(cpal::PlayStreamError),
    PauseStream(cpal::PauseStreamError),
    StreamLost(String),
}
错误 / 事件触发条件建议动作
NoInputDevice系统没有默认输入设备。启动失败；doctor 提示连接麦克风。
DeviceNotFound--input-device 名称不存在。启动失败；列出设备名后重试。
UnsupportedSampleFormat设备只提供 I16 / U16 / F32 之外的格式。启动失败；更换设备或补充格式支持。
PlayStream / PauseStream启动或暂停输入流失败。启动失败；重试后仍失败则提示设备不可用。
StreamLost / 流错误哨兵运行期音频流错误。丢弃当前段；连续失败达到上限后 daemon 退出。
模型目录 / manifest 缺失firered-vad 或 sensevoice-small 不存在、缺 manifest.json。启动失败；重新安装核心模型。
schema / id / kind 不匹配schema 5 之外的 manifest、目录名不符或模型类型错误。启动失败；不接受 schema 5 之外的布局。
文件缺失 / 大小或 SHA-256 不匹配模型文件被删除、截断或修改。启动失败；重新安装对应模型。
张量 / 会话错误ONNX 输入输出与核心预期不符或会话创建失败。启动失败；检查模型来源与 ONNX 文件。
SegmentDropped单段音频过短、SenseVoice 推理失败或结果为空。丢弃该段；继续监听。
Fatal不可恢复的音频 / pipeline 错误。daemon 退出并记录日志。
  • 模型下载失败属于安装脚本错误，不进入核心运行期；见 根 PROVIDER §4.3。
  • GPU 模型 / runtime 缺失不影响本组件；voimed 仍可用 CPU Final。
