1. TERMS

↑

术语定义
音频块（AudioChunk）设备回调交付的一批 PCM 样本及其采样率 / 声道数；进入核心后统一转换为 16 kHz 单声道 f32。
流错误哨兵零采样率、零声道、空样本的 AudioChunk；由 cpal 错误回调写入音频通道，表示当前音频流失败。
VAD 帧（VadFrame）FireRedVAD 对固定帧移音频给出的语音概率与二值判断；帧移与 fbank 参数见 PROVIDER §4.2。
语音段（Segment）分段器输出的一段 16 kHz 单声道样本及起止毫秒；产品级定义见 根 USER §1。
活动段分段器当前正在累积的语音段；Partial 只读取活动段末尾。
完成段队列Continuous 模式下已结束、等待最终识别的语音段队列；有界，满时丢弃最旧段。
模型清单（manifest.json）每个模型子目录一份 JSON，声明本目录的 schema / kind、模型文件、SHA-256、张量契约、fbank 参数与分段上限；模型目录共享资源包父目录，但不共享清单。
Artifact清单中一个 ONNX 模型条目：相对路径、SHA-256、输入 / 输出张量声明。
PyTorch / ONNX 张量声明（TensorSpec）张量名、dtype 与形状；用 -1 表示动态维。
会话工厂（SessionFactory）创建 CPU ONNX 会话并按清单校验输入 / 输出张量。
fbankKaldi 风格梅尔滤波器组特征；VAD 使用流式窗口，SenseVoice 使用整段独立计算。
CMVN倒谱均值方差归一化；从 SenseVoice / AED ONNX metadata 读取。
greedy decode逐帧 argmax、合并连续重复、去掉 blank 0 的解码方式；SenseVoice 使用该路径。
pipeline worker核心内部唯一的工作线程；串行执行重采样、VAD、分段、SenseVoice / Final 与标点。
Preview语音段进行中的 Partial 路径；固定由常驻 SenseVoice 产生。
Final 后端（FinalBackend）产生 Final 的抽象：CPU SenseVoice 或由 daemon 注入的 worker 实现；核心不加载 GPU 库。
预卷（pre-roll）VAD 判定语音起点前保留的一段音频，交给 ASR 的窗口向前扩展；不改变 VAD 判定。

2. CONVENTIONS

↑

约定内容
音频格式进入核心内部后统一为 16 kHz、单声道、f32；设备原生格式在核心内转换。
单活动段同一时刻只有一个语音段处于采集或收尾状态；StartSegment 在非 Idle 状态被忽略。
命令优先pipeline 先处理命令，再处理音频；FinishSegment 不会排在已积压的音频块之后。
段边界StartSegment 丢弃按键前已采集的音频，但保留配置的预卷；FinishSegment 先排空已采集音频，再强制结束当前段。
Partial按时间与新增音频双重门槛节流，只读取活动段末尾；固定由 SenseVoice 产生，不进入历史、不提交；可丢弃。
Final完整段交给 FinalBackend：CPU SenseVoice 或 daemon 注入的 worker；随后按 PuncPolicy 处理标点。空文本不产生 Final，产生 SegmentDropped。
模式Mode 由 voime-ipc USER §4.1 定义；核心只消费，不解析命令行。
模型生命周期VAD 与 SenseVoice 始终加载；FireRedASR 与 Punc 只在后端设置为 GPU 且 firered 资源包完整时加载。每段只重置解码状态，不重新加载权重。GPU worker 由 daemon 管理。
Final 后端核心读取 models/backend（或显式 Args.backend）：cpu 只加载 default/ 资源包；gpu 再加载 firered/ 资源包的 fire-red-aed + punc。没有 active 或候选列表。
有界队列完成段队列容量有限；慢识别时音频通道也可能丢弃，不承诺零丢失。
错误策略初始化失败返回错误；运行期单段失败产生 SegmentDropped；连续音频错误达到上限产生 Fatal。
无持久化不写音频、模型缓存或识别文本到磁盘；模型目录只读。

3. DIAGRAMS

↑

3.1 Pipeline 生命周期

  • 调用方只发送命令并消费事件；重采样、VAD、分段与 SenseVoice 在 pipeline worker 内串行执行。
  • PTT / Toggle 由调用方的 Start / Stop 驱动；Continuous 由 VAD 端点自动分段。
  • GPU 后端通过 daemon 注入的 worker 完成；Partial 始终由 SenseVoice 产生。
  • 队列与 Partial 节流的具体常量和内部状态见 CORE §2。

字段 / 函数契约
model_root模型根目录；默认 $XDG_DATA_HOME/voime/models（未设置时 ~/.local/share/voime/models）。Windows 优先使用 %LOCALAPPDATA%\voime\models，仅在 LOCALAPPDATA 未设置时回退到 XDG / HOME 路径。
backendcpu 或 gpu；显式 Args.backend 优先，否则读 model_root/backend，缺失时 CPU。

vad_dir / vad_manifestmodel_root/default/vad 与已加载、校验并重定位的 VAD 清单；始终存在。
sense_voice_dir / sense_voice_manifestmodel_root/default/sense-voice 与已加载、校验并重定位的 SenseVoice 清单；始终存在，服务 Preview 与 CPU 后端 Final。
fire_red / punc仅 backend=gpu 时为 Some，对应 model_root/firered/fire-red-aed 与 model_root/firered/punc；两者必须同时存在。
input_deviceNone 使用系统默认输入设备；Some(name) 按设备名精确匹配。
threadsONNX Runtime intra-op 线程数；必须大于 0。
preview_enabled是否产生 Partial；默认 true。Preview 始终使用 default 资源包的 SenseVoice，与后端选择无关。
pre_roll_ms交给 ASR 的段前音频长度；默认 250 ms；不改变 VAD 判定。
gpu_finalbackend == gpu 时返回 true；CPU 后端不加载 firered 资源包。
resolve解析后端设置 → 加载 default/vad 与 default/sense-voice → gpu 时加载 firered/ 的清单 / SHA-256 / 张量 / 词表；firered 不完整或初始化失败时返回错误。
load_firered_pack独立加载并校验 firered 资源包；daemon 在空闲切换到 GPU 时复用。
read_backend / write_backend读写 model_root/backend；写入使用临时文件 + rename；缺失按 CPU。
resolve_at在显式模型根目录上执行同一解析；测试与 doctor 使用。
default_model_root平台默认模型根目录；端点由 voime-transport 管理。

格式覆盖当前只接受 I16 / U16 / F32；其他格式返回 UnsupportedSampleFormat。

消息 / 方法语义调用方处理
StartSegment开始采集；非 Continuous 模式下重置 VAD / 分段器。已在本段时忽略。daemon 进入 Recording。
FinishSegment排空音频并强制结束当前段；空段产生 SegmentDropped。daemon 进入 Finalizing。
SetMode切换 ptt / toggle / continuous；下一段生效。daemon 同步配置。
Recording(true/false)采集开始 / 结束；Toggle 可在 Final 后再次产生 Recording(true)。更新前端录音标记与 daemon phase。
Partial(text)活动段末尾的临时识别；固定由 SenseVoice 产生；可丢弃。显示临时文本，不提交。
Final(text)完整段经 FinalBackend 识别并按 PuncPolicy 加标点后的最终文本。加入历史并广播。
SegmentDropped当前段因空音频、音频过短、Final 推理 / 标点失败等原因被丢弃。清空临时文本，继续监听；daemon 决定是否回退 CPU。
Fatal音频流连续失败或不可恢复的核心错误。daemon 记录并退出。
shutdown发送 Shutdown 并等待 pipeline 退出；worker 由 daemon 另行关闭。daemon 停止服务。

4.5 错误

pub enum AudioError {
    NoInputDevice,
    DeviceNotFound { name: String },
    Devices(cpal::DevicesError),
    DefaultConfig(cpal::DefaultStreamConfigError),
    UnsupportedSampleFormat(cpal::SampleFormat),
    BuildStream(cpal::BuildStreamError),
    PlayStream(cpal::PlayStreamError),
    PauseStream(cpal::PauseStreamError),
    StreamLost(String),
}
错误 / 事件触发条件建议动作
NoInputDevice系统没有默认输入设备。启动失败；doctor 提示连接麦克风。
DeviceNotFound--input-device 名称不存在。启动失败；列出设备名后重试。
UnsupportedSampleFormat设备只提供 I16 / U16 / F32 之外的格式。启动失败；更换设备或补充格式支持。
PlayStream / PauseStream启动或暂停输入流失败。启动失败；重试后仍失败则提示设备不可用。
StreamLost / 流错误哨兵运行期音频流错误。丢弃当前段；连续失败达到上限后 daemon 退出。
模型加载错误清单缺失、SHA 不匹配、张量不符、词表格式错误。启动失败；重新安装模型。
SegmentDropped单段推理失败、GPU worker 不可用或结果为空。丢弃该段；daemon 可回退 CPU SenseVoice 并继续监听。
Fatal不可恢复的音频 / 核心错误。daemon 退出并记录日志。
