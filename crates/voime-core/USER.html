1. TERMS

↑

术语定义
音频块（AudioChunk）设备回调交付的一批 PCM 样本及其采样率 / 声道数；进入核心后统一转换为 16 kHz 单声道 f32。
流错误哨兵零采样率、零声道、空样本的 AudioChunk；由 cpal 错误回调写入音频通道，表示当前音频流失败。
VAD 帧（VadFrame）FireRedVAD 对固定帧移音频给出的语音概率与二值判断；帧移与 fbank 参数见 PROVIDER §4.2。
语音段（Segment）分段器输出的一段 16 kHz 单声道样本及起止毫秒；产品级定义见 根 USER §1。
活动段分段器当前正在累积的语音段；Partial 只读取活动段末尾。
完成段队列Continuous 模式下已结束、等待最终识别的语音段队列；有界，满时丢弃最旧段。
模型清单（ModelManifest）声明模型文件、SHA-256、张量契约、fbank 参数与分段上限的 JSON 对象。
Artifact清单中一个 ONNX 模型条目：相对路径、SHA-256、输入 / 输出张量声明。
PyTorch / ONNX 张量声明（TensorSpec）张量名、dtype 与形状；用 -1 表示动态维。
会话工厂（SessionFactory）创建 CPU ONNX 会话并按清单校验输入 / 输出张量。
fbankKaldi 风格梅尔滤波器组特征；VAD 使用流式窗口，CTC 使用整段独立计算。
CMVN倒谱均值方差归一化；从 CTC ONNX metadata 读取。
greedy CTC逐帧 argmax、合并连续重复、去掉 blank 0 的解码方式。
pipeline worker核心内部唯一的工作线程；串行执行重采样、VAD、分段、CTC 与标点。

2. CONVENTIONS

↑

约定内容
音频格式进入核心内部后统一为 16 kHz、单声道、f32；设备原生格式在核心内转换。
单活动段同一时刻只有一个语音段处于采集或收尾状态；StartSegment 在非 Idle 状态被忽略。
命令优先pipeline 先处理命令，再处理音频；FinishSegment 不会排在已积压的音频块之后。
段边界StartSegment 丢弃按键前已采集的音频；FinishSegment 先排空已采集音频，再强制结束当前段。
Partial按时间与新增音频双重门槛节流，只读取活动段末尾；不进入历史、不提交；可丢弃。
Final对完整段执行 CTC，再执行标点；空文本不产生 Final，产生 SegmentDropped。
模式Mode 由 voime-ipc USER §4.1 定义；核心只消费，不解析命令行。
模型生命周期启动时加载并校验 VAD / CTC / Punc；会话常驻内存；每段只重置解码状态，不重新加载权重。
有界队列完成段队列容量有限；慢识别时音频通道也可能丢弃，不承诺零丢失。
错误策略初始化失败返回错误；运行期单段失败产生 SegmentDropped；连续音频错误达到上限产生 Fatal。
无持久化不写音频、模型缓存或识别文本到磁盘；模型目录只读。
过渡字段Config.socket 与 default_socket 是 P0 前的过渡 API；目标由 voime-transport 管理端点。

3. DIAGRAMS

↑

3.1 Pipeline 生命周期

  • 调用方只发送命令并消费事件；重采样、VAD、分段与推理在 pipeline worker 内串行执行。
  • PTT / Toggle 由调用方的 Start / Stop 驱动；Continuous 由 VAD 端点自动分段。
  • 队列与 Partial 节流的具体常量和内部状态见 CORE §2。

字段 / 函数契约

input_deviceNone 使用系统默认输入设备；Some(name) 按设备名精确匹配。

socket过渡字段；P0 后由 transport Endpoint 替代。
manifestresolve 加载、校验并重定位后的模型清单。
resolve加载清单 → 校验 SHA-256 / 张量 / 词表 → 将相对路径重定位到 model_dir；失败返回带路径上下文的错误。
default_model_dir / default_socket平台默认路径；default_socket 仅 P0 前使用。

项目契约
start打开设备、注册数据 / 错误回调并启动流；返回的句柄停止时关闭流。
数据回调把 I16 / U16 / F32 设备样本转换为 f32 并入队；队列满时丢弃当前块，不阻塞音频线程。
错误回调向同一通道写入流错误哨兵；上层据此丢弃当前段。
list_input_devices按宿主报告顺序返回设备名；只读，不影响当前流。
default_input_device_name返回系统默认输入设备名；没有默认设备时返回 None。
stop暂停并丢弃流；幂等，不等待回调结束。
格式覆盖当前只接受 I16 / U16 / F32；其他格式返回 UnsupportedSampleFormat。

4.3 模型清单

pub struct ModelManifest {
    pub schema: u32,
    pub sample_rate: u32,
    pub fbank: FbankManifest,
    pub max_segment_ms: u32,
    pub vad: VadArtifact,
    pub asr: CtcArtifact,
    pub punc: PuncArtifact,
}

impl ModelManifest {
    pub fn load(path: &Path) -> anyhow::Result<Self>;
    pub fn verify(&self, dir: &Path) -> anyhow::Result<()>;
    pub fn rebase(&mut self, dir: &Path) -> anyhow::Result<()>;
}

pub struct Artifact {
    pub model: PathBuf,
    pub sha256: String,
    pub inputs: Vec<TensorSpec>,
    pub outputs: Vec<TensorSpec>,
}

pub struct CtcArtifact {
    pub kind: String,
    pub model: Artifact,
    pub tokens: PathBuf,
    pub token_count: usize,
}

pub struct PuncArtifact {
    pub model: Artifact,
    pub vocab: PathBuf,
    pub labels: PathBuf,
    pub max_tokens: usize,
}

pub fn resolve_inside(dir: &Path, relative: &Path) -> anyhow::Result<PathBuf>;
字段 / 函数契约
schema必须等于当前支持的版本；不兼容版本启动失败。
sample_rate必须为 16 kHz；否则启动失败。
fbankVAD / CTC 共用的 fbank 参数；由模型清单声明，具体值与预处理见 PROVIDER §4.2。
max_segment_ms单段上限；达到上限强制结束并继续收集后续语音。
vad / asr.model / punc.modelONNX 文件、SHA-256 与张量声明；verify 校验文件存在、非空且摘要匹配。
asr.tokens / punc.vocab / punc.labels辅助文件；verify 只检查存在与非空，格式错误在加载时报告。
resolve_inside拒绝绝对路径、.. 与空路径，防止模型包逃逸目录。

    pub fn start_segment(&self) -> anyhow::Result<()>;

    pub fn shutdown(self) -> anyhow::Result<()>;

消息 / 方法语义调用方处理
StartSegment开始采集；非 Continuous 模式下重置 VAD / 分段器。已在本段时忽略。daemon 进入 Recording。
FinishSegment排空音频并强制结束当前段；空段产生 SegmentDropped。daemon 进入 Finalizing。
SetMode切换 ptt / toggle / continuous；下一段生效。daemon 同步配置。
Recording(true/false)采集开始 / 结束；Toggle 可在 Final 后再次产生 Recording(true)。更新前端录音标记与 daemon phase。
Partial(text)活动段末尾的临时识别；可丢弃。显示临时文本，不提交。
Final(text)完整段识别并加标点后的最终文本。加入历史并广播。
SegmentDropped当前段因空音频、音频过短、CTC / 标点失败等原因被丢弃。清空临时文本，继续监听。
Fatal音频流连续失败或 worker 不可恢复错误。daemon 记录并退出。
shutdown发送 Shutdown 并等待 worker 退出。daemon 停止服务。

4.5 错误

pub enum AudioError {
    NoInputDevice,
    DeviceNotFound { name: String },
    Devices(cpal::DevicesError),
    DefaultConfig(cpal::DefaultStreamConfigError),
    UnsupportedSampleFormat(cpal::SampleFormat),
    BuildStream(cpal::BuildStreamError),
    PlayStream(cpal::PlayStreamError),
    StreamLost(String),
}
错误 / 事件触发条件建议动作
NoInputDevice系统没有默认输入设备。启动失败；doctor 提示连接麦克风。
DeviceNotFound--input-device 名称不存在。启动失败；列出设备名后重试。
UnsupportedSampleFormat设备只提供 I16 / U16 / F32 之外的格式。启动失败；更换设备或补充格式支持。
StreamLost / 流错误哨兵运行期音频流错误。丢弃当前段；连续失败达到上限后 daemon 退出。
模型加载错误清单缺失、SHA 不匹配、张量不符、词表格式错误。启动失败；重新安装模型。
SegmentDropped单段识别失败或结果为空。丢弃该段；继续监听。
Fatal不可恢复的 worker / 音频错误。daemon 退出并记录日志。
