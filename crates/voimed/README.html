1. WHAT & WHY

↑

1.1 IDEAL：要解决的问题

语音识别需要常驻的音频流、VAD、预览、分段与最终识别；这些资源不能放进 Fcitx 进程， 也不应该由每个平台前端各复制一份。voimed 是唯一的应用守护进程：它持有音频、 pipeline、会话历史与 Final 后端选择，通过本机 IPC 向平台前端、TUI 与控制客户端提供 SegmentStarted / Partial / Final 等事件，并按配置把完整语音段 交给核心 CPU Final 或选中的 GPU worker。

1.2 GOAL：什么算成功

  • voimed 在 Linux 与 Windows 上功能相同，但不可跨平台复用。
  • 平台前端只发送 Start / Stop / Toggle 与配置，不接触模型、音频或 Final 后端。
  • 同一时刻只有一个语音段；segment_id 由 daemon 分配并广播。
  • 默认 final.backend = cpu；安装 GPU 不自动切换；只有配置显式指定 qwen3 才启动对应 worker。
  • daemon 启动时只加载选中的 GPU worker 并保持常驻；默认 cpu 时不启动 worker。
  • Finalizing 期间停止 Preview 计算；Final 在后台队列中串行执行，不阻塞新录音；cpu Final 只执行一次，GPU Final 不再调用 SenseVoice ASR。
  • GPU 加载失败、超时、崩溃或显存不足时，当前段回退 CPU SenseVoice；Preview 不中断。
  • daemon 退出顺序见 CORE §5.7。

1.3 非目标

  • 不负责具体模型推理；VAD / SenseVoice / CPU Final 在 voime-core，Qwen 在 worker。
  • 不处理热键、输入焦点、目标绑定、临时窗口或文本提交。
  • 不实现平台 UI、托盘、配置界面或安装器；GPU worker 由本 crate 拉起，但前端不感知。
  • 不解析命令行模式 / 热键；这些由前端通过 IPC 提供。
  • 不提供 --backend 命令行选项，也不提供运行中后端热切换；只读取配置文件。
  • 不保存音频、按键或历史到磁盘。
  • 不直接依赖 Fcitx / Win32；OS 传输由 voime-transport 负责。
  • 不负责协议消息形状；前端协议见 voime-ipc USER，GPU 协议见 voime-gpu-common USER。
  • 不安装、不编译、不切换 GPU runtime；这些属于 GPU 安装脚本与 worker。
  • 产品级术语见 根 USER §1；daemon 行为见 USER。
  • 核心音频 / 模型契约在 voime-core PROVIDER，端点契约在 voime-transport PROVIDER，GPU 协议在 voime-gpu-common USER。

2. 用户交互

↑

角色 / 入口交互契约
平台前端连接 daemon，发送 Hello / Configure / Start / Stop / Toggle，接收 SegmentStarted / State / Partial / Final。USER §4.2 · voime-ipc USER
TUI（voime）连接为 tui，读取 Snapshot / Partial / Final；无 frontend 连接时可发送 Start / Stop / Toggle / ClearHistory 调试命令，frontend 连接期间只观察；不操作输入法。voime USER §4.2
voime ctl连接为 control，发送 Start / Stop / Toggle / Status / ClearHistory / Quit；backend 直接写配置，不通过 daemon。voime USER §4.1
systemd / 登录启动启动 / 重启 / 停止 daemon；Linux 使用 systemd 用户服务，Windows 由托盘托管 daemon，随托盘启动和退出。本组件 §2
voimed CLI指定模型根目录、输入设备、线程数、端点路径与日志；Final 后端只从配置文件读取。USER §4.1
GPU workerdaemon 按 final.backend 拉起一个 worker，完成 Hello / Ready 后发送完整语音段；退出时 Shutdown。voime-gpu-common USER §3 · CORE §5.5
  • 安装 GPU 模块后默认 Final 仍是 CPU；用户必须用 voime ctl backend 或安装时 --backend 显式选择。
  • 切换后端只影响 Final；Preview 始终由核心 SenseVoice 提供。
