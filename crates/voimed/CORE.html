2. CONVENTIONS

↑

约定内容
事件循环daemon 主线程用 crossbeam_channel::select! 同时等待 IPC 事件与 pipeline 事件；100 ms 超时用于检查关闭。
客户端线程accept 线程接受连接；每个客户端一个 reader 线程与一个 writer 线程；daemon 主线程只处理事件与状态。
客户端队列每个客户端一个有界发送队列；Final / State 满时移除客户端，Partial 满时只丢该条。
角色表clients: HashMap<u64, ClientEntry> 由互斥锁保护；set_role 只允许一个 Fcitx。
状态机State.phase 只由 daemon 主线程修改；pipeline 事件与客户端命令都在同一线程串行处理。
段 IDnext_segment 单调递增，wrapping 后跳过 0；当前段在 Final / 丢弃后清空。
模式生效Idle 时立即 pipeline.set_mode；非 Idle 时暂存到 pending_mode，段结束后应用。
前端断开前端状态置 disconnected；Continuous 退 PTT；结束当前段；广播 Snapshot。
退出顺序广播 Bye → IPC shutdown → pipeline shutdown → audio stop → 删除端点。
过渡实现ipc_server.rs 当前直接使用 Unix socket；P0 后改为 voime-transport，daemon 不再 import std::os::unix。
  • 仓库级进程 / 线程边界见 根 CORE §2；用户可见行为见 USER §2。

4.6 ipc_server.rs 文件树

pub enum ServerEvent {
    Connected { client_id: u64 },
    Message { client_id: u64, message: ClientMessage },
    BadMessage { client_id: u64, message: String },
    Disconnected { client_id: u64, role: Option<Role> },
}

struct ClientEntry {
    sender: Sender<ServerMessage>,
    role: Option<Role>,
}

pub struct IpcServer {
    path: PathBuf,
    events_rx: Receiver<ServerEvent>,
    clients: Arc<Mutex<HashMap<u64, ClientEntry>>,
    shutdown: Arc<AtomicBool>,
    accept_thread: Option<JoinHandle<()>>,
}

impl IpcServer {
    pub fn bind(path: &Path) -> anyhow::Result<Self>;
    pub fn events(&self) -> &Receiver<ServerEvent>;
    pub fn next_event(&self) -> anyhow::Result<ServerEvent>;
    pub fn try_event(&self) -> Option<ServerEvent>;
    pub fn broadcast(&self, message: &ServerMessage);
    pub fn disconnect(&self, client_id: u64);
    pub fn send_to(&self, client_id: u64, message: &ServerMessage);
    pub fn set_role(&self, client_id: u64, role: Role) -> bool;
    pub fn role(&self, client_id: u64) -> Option<Role>;
    pub fn client_count(&self) -> usize;
    pub fn shutdown(&mut self);
}
impl Drop for IpcServer { /* shutdown + remove socket */ }

fn prepare_parent(path: &Path) -> anyhow::Result<()>;
pub fn daemon_running(path: &Path) -> bool;
fn spawn_client(stream: UnixStream, client_id: u64,
                clients: &Arc<Mutex<HashMap<u64, ClientEntry>>>,
                events: &Sender<ServerEvent>) -> anyhow::Result<()>;

5. Call stack tree

↑

5.1 启动

systemd --user
└── voimed::main()
    ├── voimed::cli::parse()
    ├── ipc_server::daemon_running(&socket)
    │   └── 判断已运行 → ExitCode::SUCCESS
    ├── voimed::run(args)
    │   ├── voime_core::config::resolve(args)
    │   ├── voime_core::infer::session::SessionFactory::new(config.threads)
    │   ├── voime_core::pipeline::spawn(&config, factory, audio_rx)
    │   ├── voime_core::audio::capture::start(config.input_device, audio_tx)
    │   ├── ipc_server::IpcServer::bind(&config.socket)
    │   └── daemon::Daemon::new(config, pipeline, audio, ipc).run()
    └── 判断 Err → eprintln! + ExitCode::from(1)

5.2 连接、Hello 与角色

IpcServer accept thread
└── UnixListener::accept()
    └── ipc_server::spawn_client(stream, client_id, clients, events)
        ├── UnixStream::try_clone()
        ├── std::thread::Builder::spawn(writer loop)
        └── std::thread::Builder::spawn(reader loop)
            ├── read_until(b'\n')
            ├── serde_json::from_slice::<ClientMessage>()
            └── events.send(ServerEvent::Message)

Daemon::run()
└── Daemon::on_server_event(Message { client_id, message })
    └── Daemon::on_client(client_id, Hello { role, version, config })
        ├── 判断 version != PROTOCOL_VERSION → send Error(version_mismatch) + disconnect
        ├── IpcServer::set_role(client_id, role)
        ├── 判断 role == Fcitx → state.addon = Connected
        ├── State::apply_mode(config.mode)
        ├── Daemon::apply_pipeline_mode()
        └── IpcServer::broadcast(Snapshot)

5.3 Start 与 SegmentStarted

Daemon::on_client(client_id, Start { segment_id, source })
└── Daemon::request_start(client_id, segment_id, source)
    ├── 判断 state.phase != Idle → send Error(busy)
    ├── Daemon::allocate_segment()
    ├── Pipeline::start_segment()
    ├── IpcServer::broadcast(SegmentStarted { segment_id, source })
    └── Daemon::broadcast_state()

5.4 Stop、Toggle 与连续段

Daemon::on_client(client_id, Stop { segment_id, source })
└── Daemon::request_stop(client_id, segment_id)
    ├── 判断 phase != Recording
    │   └── 判断 mode == Toggle → pending_stop = true
    ├── 判断 segment_id != 0 && segment_id != current
    │   └── 判断 mode != Toggle → send Error(busy)
    └── Pipeline::finish_segment()

Daemon::on_client(client_id, Toggle { segment_id, source })
├── 判断 phase == Idle → Daemon::request_start(...)
├── 判断 phase == Recording → Daemon::request_stop(...)
└── 判断 phase == Finalizing → send Error(busy)

pipeline::PipelineEvent::Recording(true)
├── 判断 current_segment.is_none() → allocate_segment + broadcast SegmentStarted
├── state.phase = Recording
├── broadcast_state()
└── 判断 pending_stop → Pipeline::finish_segment()

5.5 Pipeline 事件

Daemon::run()
└── Daemon::on_pipeline(event)
    ├── Recording(true) → phase=Recording + broadcast_state
    ├── Recording(false) → phase=Finalizing + broadcast_state
    ├── Partial(text) → state.partial=Some + broadcast Partial
    ├── Final(text) → transcript.push + phase=Idle + broadcast Final + broadcast_state
    ├── SegmentDropped(reason) → phase=Idle + current_segment=None + broadcast Error(inference)
    └── Fatal(error) → fatal=Some + shutdown=true

5.6 前端断开与模式回退

ipc_server reader loop 退出
└── events.send(ServerEvent::Disconnected { client_id, role })
    └── Daemon::on_server_event(Disconnected)
        ├── 判断 role == Fcitx → state.addon = Disconnected
        ├── 判断 state.mode == Continuous → Pipeline::set_mode(Ptt)
        ├── 判断 current_segment.is_some() → Pipeline::finish_segment()
        └── Daemon::broadcast_snapshot()

5.7 退出

Daemon::on_client(Quit)（role=Control）
└── shutdown = true
    └── Daemon::run() 跳出循环
        ├── IpcServer::broadcast(Bye)
        ├── IpcServer::shutdown()
        │   ├── shutdown.store(true)
        │   ├── accept_thread.join()
        │   ├── clients.clear()
        │   └── std::fs::remove_file(socket)
        ├── Pipeline::shutdown()
        └── CaptureHandle::stop()
