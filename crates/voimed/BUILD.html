1. 环境

↑

项目要求
Ruststable 工具链（rust-toolchain.toml）。
LinuxALSA 开发头文件；Fcitx5 不是 daemon 的构建依赖。
WindowsRust MSVC 工具链；WASAPI 由 cpal 处理。
模型运行前需要 default/vad + default/sense-voice；GPU 后端还需完整的 firered/；编译不需要权重。
GPU runtime可选；后端设置为 GPU 时需要 voime-gpu 与对应 runtime。缺失或初始化失败时回退 CPU SenseVoice。
服务管理Linux systemd user service；Windows daemon 是托盘子进程，随托盘启动和退出，不使用独立服务或独立退出流程。

2. 构建与安装

↑

cargo build --release -p voimed
scripts/install_voimed.sh

# 自定义前缀 / 不重新构建 / 不安装 systemd
scripts/install_voimed.sh --prefix DIR --bindir DIR --no-build --no-systemd
产物说明
target/release/voimedASR 守护进程；ONNX Runtime 随 ort 构建时链接。
scripts/install_voimed.sh安装到 ~/.local/bin，生成 systemd user unit。
~/.config/systemd/user/voime.service用户服务；ExecStart 替换为实际 $BINDIR/voimed。
  • 根 workspace 的完整构建、源码安装与模型安装见 根 BUILD §2 / §3 / §4。
  • Windows 产物为 voimed.exe；由托盘以子进程托管（Job Object），随托盘启动和退出；登录启动由安装器负责，不使用 Session 0 服务。

3. 运行

↑

# systemd user service
systemctl --user daemon-reload
systemctl --user enable --now voime.service
systemctl --user status voime.service

# 或前台启动
voimed --verbose

# 查看状态；后端由 models/backend 或 --backend 选择
voimed --backend gpu
voime ctl status
voime ctl backend cpu
voime doctor
操作命令 / 契约
停止Linux：voime ctl quit 或 systemctl --user stop voime.service；Windows：退出托盘即停止。
重启进程systemctl --user restart voime.service；安装 / 替换模型后用它重新加载；前端会定时重连。
模型来源启动时读取 models/backend 与 default/，GPU 后端再读取 firered/；没有 models / use / restart-backend 子命令；使用 voime ctl backend。
诊断voime doctor 检查端点、daemon、两个资源包、后端设置、GPU runtime 与前端。
日志给服务环境设 VOIME_LOG=1（或目录路径）后重启，日志写入 {XDG_STATE_HOME}/voime/logs/voimed.log；Windows 为 %LOCALAPPDATA%\voime\logs\voimed.log。
端点默认 $XDG_RUNTIME_DIR/voime/voimed.sock；自定义端点用 --endpoint（--socket 为兼容别名）。
  • voimed 不需要 WAYLAND_DISPLAY / DISPLAY；它只处理音频与 IPC。
  • 如果已有 daemon 在运行，再次启动会打印提示并以 0 退出。

4. 测试

↑

cargo test -p voimed
cargo clippy -p voimed --all-targets
cargo fmt -p voimed --check
测试覆盖
tests/daemon.rs端点存活、断线角色、daemon 生命周期、GPU 初始化 / 运行期回退。
tests/state.rs快照默认值、清空历史、status 字段。
tests/ipc.rs握手、角色、模式、SetBackend、framing、协议 5；不包含模型列表或 package_id。
tests/segmenter.rs分段端点、最大段长与预卷。
worker / GPUspawn / handshake / 超时 / 崩溃重启 / 回退 CPU；只在专用 runner 启用。
模型目录默认 CPU 资源包、GPU 资源包完整性、FireRed / Punc 缺一失败；另测空闲 SetBackend 切换与忙碌拒绝。

5. 升级 / 卸载

↑

操作步骤
升级停止服务；重新运行安装脚本；启动服务；前端自动重连。资源包走 clean install，旧 schema / 旧目录布局直接拒绝。
迁移配置模型根目录与端点路径由默认值 / CLI 决定；不迁移历史（不持久化）。上一版本可手工运行 scripts/migrate-asr-v2.sh，安装器不调用。
卸载systemctl --user disable --now voime.service；删除 ~/.local/bin/voimed 与 ~/.config/systemd/user/voime.service；模型目录与 GPU runtime 按需保留。
Windows退出托盘（同时停止 daemon）；删除 voimed.exe / voime.exe / 可选 voime-gpu.exe；按需删除模型目录、GPU runtime 与登录启动项。
