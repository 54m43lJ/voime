2. CONVENTIONS

↑

约定内容
线程模型TUI 主线程读取终端事件并绘制；Client 启动一个 reader 线程把 ServerMessage 写入有界通道。
事件循环TUI 每 50 ms 轮询终端事件；先消费所有待处理 IPC 事件，再绘制。
终端恢复Tui::init 启用 raw mode / 备用屏幕 / 隐藏光标；Drop 与 panic hook 都恢复终端。
文本清洗Final / Partial 去掉 \r / \n 并 trim；空文本不进入历史 / 不覆盖 partial。
滚动ScrollState 保存 offset 与 follow；上翻停止跟随，End 恢复；绘制时按内容高度夹取 offset。
角色TUI 以 tui 连接；ctl / doctor 以 control 连接；ctl backend 不连接。
doctor 只读不发送 Start / Stop / Quit，不修改配置，不启动 worker；只连接读 Snapshot / Diagnostics、读配置并调用 core 只读 API。
ctl 写配置只有 ctl backend 写 [final].backend；其他 ctl 动作只发送控制消息。
ctl 超时每次 ctl 动作等待响应的超时由 main.rs 拥有；具体值见 §4.1。
端点Client 通过 voime-transport 的 Stream 连接 daemon；ctl backend 不使用端点。
无模型不加载 ONNX / GGUF；doctor 只读模型 manifest、设备列表与 daemon Diagnostics 快照。
Fcitx 系统安装doctor 检查 /usr 系统 addon 路径与 ABI；不设置、不检查 FCITX_ADDON_DIRS，不检查inputmethod 条目。
  • 仓库级线程 / 进程边界见 根 CORE §2；用户可见行为见 USER §2。

impl FinalConfig {
    pub fn path() -> PathBuf;
    pub fn load() -> anyhow::Result<Self>;
}

  • path 为 ~/.config/voime/config.toml（Windows %APPDATA%\voime\config.toml）。

pub fn run(endpoint: &Endpoint) -> bool;

fn check_final_backend() -> CheckResult;
fn check_workers(diagnostics: Option<&WorkerDiagnosticsAnswer>) -> [CheckResult; 3];

                diagnostics: Option<&WorkerDiagnosticsAnswer>) -> CheckResult;

pub type WorkerDiagnosticsAnswer = (String, Option<WorkerDiagnostics>);

pub enum CheckResult {
    Pass,
    Warn(String),
    Fail(String),
}
  • CheckResult 是单项检查结果；Warn / Fail 携带一行原因，Pass 不带内容。
  • check_final_backend 只读 FinalConfig::load，并列出 CPU / Qwen 的安装与选择状态。
  • check_workers 依次检查 CPU / Qwen：worker 可执行文件、模型目录；对已选择后端使用 Client::diagnostics() 返回的内存快照，不读取日志、不启动 worker。
  • check_fcitx 只检查系统 addon 描述 / 库与 ABI；不检查inputmethod 条目或 FCITX_ADDON_DIRS。
  • check_windows 检查命名管道、麦克风隐私、voime-tray.exe 进程与 TSF 注册（若启用）；不加载模型。

5. Call stack tree

↑

5.1 TUI 启动与事件循环

voime::main()
├── voime::cli::parse()
├── 判断无子命令 → voime::run_tui(endpoint)
│   ├── Client::connect(endpoint)
│   ├── Client::snapshot()
│   ├── App::new()
│   ├── App::on_event(Snapshot)
│   └── App::run(client)
│       ├── Tui::init()
│       ├── loop
│       │   ├── Client::try_event() → App::on_event(...)
│       │   ├── Tui::draw(&mut app)
│       │   ├── crossterm::event::poll(50 ms)
│       │   └── crossterm::event::read() → App::on_key(key)
│       └── Tui::restore()
└── 判断 Err → eprintln! + ExitCode::from(1)

5.2 TUI 按键

App::on_key(key)
├── 判断 key.kind != Press → Continue
├── 判断 Ctrl+C → Detach
├── 判断 Ctrl+X → Client::send(ClearHistory)
├── 判断 q（无修饰）→ Detach
├── 判断 Space
│   ├── 判断 mode == Continuous && recording → Client::send(Stop { source: Tui })
│   ├── 判断 mode == Continuous → Client::send(Start { source: Tui })
│   └── 判断 mode == Ptt / Toggle → Client::send(Toggle { source: Tui })
├── 判断 PageUp → ScrollState::page_up(viewport_height - 1)
├── 判断 PageDown → ScrollState::page_down(viewport_height - 1)
├── 判断 Home → ScrollState::home()
└── 判断 End → ScrollState::end()

5.3 TUI 事件与绘制

App::on_event(event)
├── Snapshot → 覆盖 mode / hotkey / transcript / partial / addon / phase
├── SegmentStarted → recording=true + partial.clear() + scroll.end()
├── State → 更新 recording / finalizing；Idle 时清空 partial
├── Partial → App::set_partial(text)
├── Final → App::push_final(text) + partial.clear() + recording=false
├── HistoryCleared → transcript.clear()
├── Status → App::apply_status(status)
├── Error → eprintln!
└── Bye → detached=true

Tui::draw(&mut app)
├── 计算 content_area = area - FOOTER_HEIGHT
├── app.viewport_height = content_area.height
├── build_lines(app, content_area.width)
│   ├── 历史 transcript → push_wrapped(..., marker=false)
│   └── recording / finalizing / partial → 当前行（recording 时带 ●）
├── 夹取 app.scroll.offset
├── Paragraph::new(lines).scroll((offset, 0))
└── footer_text(app) → Paragraph（DIM）

5.4 ctl 命令与 backend 写入

voime::run_ctl(endpoint, action)
├── 判断 action == Backend(id)
│   └── voime::config::write_backend(id)
│       ├── FinalConfig::path()
│       ├── 读取现有 TOML
│       ├── 替换 [final].backend
│       └── 写临时文件 + rename
└── 其他动作为 voime::run_ctl_inner(endpoint, action)
    ├── Client::connect_as(endpoint, Role::Control)
    ├── Client::snapshot()
    ├── 判断 Start / Stop / Toggle → Client::send(...) + Client::wait_for_state(3 s)
    ├── 判断 Status → Client::send(Status) + Client::next_event_timeout(3 s)
    ├── 判断 Clear → Client::send(ClearHistory) + 等待 HistoryCleared
    └── 判断 Quit → Client::send(Quit) + 等待 Bye

5.5 doctor

voime::main()
└── voime::doctor::run(endpoint)
    ├── 判断 cfg(unix) → std::fs::metadata(endpoint.as_unix_path()) → 检查 Unix 0600
    ├── 判断 cfg(windows) → 检查 endpoint 命名管道
    ├── Client::connect_as(endpoint, Role::Control)
    │   ├── Client::snapshot() → daemon 在线
    │   └── Client::diagnostics() → Diagnostics { backend, worker }
    ├── voime::config::FinalConfig::load()
    │   └── doctor::check_final_backend() → cpu / qwen3
    ├── doctor::check_workers(diagnostics) → CPU / Qwen
    │   └── doctor::check_worker(backend, selected, diagnostics)
    │       └── 检查 worker 可执行文件、模型目录与 daemon 内存状态
    ├── voime_core::config::default_model_root()
    │   └── doctor::check_models(root) → 核心模型 manifest / SHA
    ├── voime_core::audio::capture::list_input_devices()
    ├── voime_core::audio::capture::default_input_device_name()
    ├── 判断 cfg(unix) → doctor::check_fcitx()
    │   ├── doctor::fcitx_running() → 遍历 /proc
    │   ├── doctor::addon_path("addon/voime.conf") → /usr/share/fcitx5/addon
    │   ├── doctor::library_path() → /usr/lib/fcitx5/voime.so
    │   ├── doctor::system_addon_abi() → Fcitx5 ABI / 依赖解析
    │   └── doctor::user_config_path() → XDG_CONFIG_HOME / HOME
    └── 判断 cfg(windows) → doctor::check_windows(snapshot)
        ├── doctor::process_running("voime-tray.exe")
        └── doctor::microphone_privacy()
  • doctor 在 Linux 检查 fcitx5 与系统 addon；在 Windows 检查命名管道、麦克风隐私、前端进程与 TSF 注册。
  • doctor 不再检查 /usr/share/fcitx5/inputmethod/voime.conf；Voime 不注册输入法条目。
  • worker 状态通过只读 Diagnostics 消息读取；Status / Snapshot 形状保持不变，日志不参与判定。
  • doctor 不加载模型权重，只校验 manifest 与文件；模型缺失计为 FAIL，GPU 未选择只计为 WARN。

5.6 断线与退出

Client reader thread
└── read_message() 返回 EOF

App::run()

├── 判断 detached → break
└── Tui::restore()
    ├── Show / DisableMouseCapture / LeaveAlternateScreen
    └── disable_raw_mode()
