1. 环境

↑

项目要求
Ruststable 工具链。
终端TUI 需要 TTY；ctl / doctor 不需要。
平台Linux 当前完整支持；Windows 目标复用 crossterm / ratatui，doctor 需平台子模块。
运行依赖daemon 与模型；TUI / ctl 本身不加载模型。

2. 构建与安装

↑

cargo build --release -p voime
scripts/install_voime.sh

# 自定义前缀 / 不重新构建
scripts/install_voime.sh --prefix DIR --bindir DIR --no-build
产物说明
target/release/voimeTUI / ctl / doctor 单一二进制。
~/.local/bin/voime安装脚本的默认目标。
  • 根 workspace 的完整构建见 根 BUILD §2。
  • Windows 产物为 voime.exe；TUI 的终端行为按 Windows Terminal 验证。

3. 使用

↑

voime                 # TUI；q / Ctrl+C 只 detach
voime ctl status
voime ctl start
voime ctl stop
voime ctl clear
voime ctl models
voime ctl use fire-red-aed-gpu
voime ctl restart-backend
voime ctl quit
voime doctor
场景契约
TUI 退出q / Ctrl+C detach；daemon 与前端继续运行。
停止 daemonvoime ctl quit；不要依赖 TUI 退出。
模型选择voime ctl models / use 只读写 Final 选择；restart-backend 在空闲时生效。
诊断voime doctor 只读；失败项以 FAIL 输出；GPU runtime 不可用为 WARN。
端点--endpoint 全局选项；--socket 为兼容别名。

4. 测试

↑

cargo test -p voime

cargo fmt -p voime --check

ctlmodels / use / restart-backend 的输出与 BackendState 处理。
ctlstart / stop / toggle / status / clear / quit 的成功与超时路径。
doctor端点、daemon、模型、音频、前端检查；FAIL 退出码。
