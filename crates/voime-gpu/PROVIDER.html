1. TERMS

↑

术语定义
GPU runtime执行 FireRed / Qwen 的 Vulkan 或 CUDA runtime；只由对应 worker 加载。
runtime 包按模型 + OS + EP 拆分的 worker 二进制与 runtime 库；独立目录、版本、SHA 与签名。
FireRed AEDFireRedASR2-AED 1.1B encoder-decoder 模型；非流式，只用于 Final；OpenASR .oasr FP16。
FireRedPuncFireRed Final 标点模型；OpenASR .oasr FP16；由 FireRed worker 加载。
Qwen3-ASRQwen3-ASR 1.7B 语音识别模型；F16 GGUF + mmproj；只用于 Final；内置标点。
FP16GPU 产品路径唯一精度；int8 只用于 CPU SenseVoice。
deviceruntime 暴露的 GPU 设备名；auto 由 runtime 选择默认设备。

2. CONVENTIONS

↑

约定内容
进程隔离GPU runtime 只进入对应 worker；daemon 只映射 CPU ONNX Runtime，不加载 Vulkan / CUDA / ROCm / MIGraphX / DirectML。
模型专用FireRed worker 只加载 OpenASR / FireRed；Qwen worker 只加载 llama.cpp / Qwen；两者不共享模型或 runtime 目录。
平台顺序Linux AMD Vulkan 为 P0；Windows AMD Vulkan 为 P1；NVIDIA CUDA 为 P1 / P2；不使用 MIGraphX / DirectML。
精度两个模型只接受 FP16；加载失败直接报错，不回退 FP32 / int8。
模型不可变模型包运行期只读；worker 加载时再次校验 SHA-256、张量与 metadata。
运行时隔离runtime 包不进入模型目录；模型包不允许自带可执行文件。
错误边界runtime / 设备 / 模型错误映射为 worker 错误码；不把底层文案写进前端。

3. DIAGRAMS

↑

3.1 GPU runtime 边界

  • Voime 作为单一参与者；GPU runtime 与两个模型包是外部 provider。
  • 仅 Final 路径使用这些 provider；Preview、VAD 不在此边界内。

3.2 模型加载与推理边界

  • 启动时校验 manifest、模型、Punc / mmproj 与 metadata；每个 Final 段只重置解码状态。
  • VAD 不在 worker 内；FireRedPunc 在 FireRed worker 内；Qwen 标点由模型内置。

4.4 错误与失败策略

错误触发条件处理
RuntimeMissingruntime 目录缺失、版本不匹配或动态库加载失败。worker 退出；daemon 标记该 GPU Final 不可用；最终回退 CPU。
DeviceUnavailable无 GPU、驱动不匹配、显存不足。worker 退出；不加载 CPU AED / Qwen；Preview 继续。
LoadFailed模型 / Punc / mmproj / metadata / SHA 校验失败。worker 不进入 Ready；daemon 回滚 active。
InferenceFailed运行期推理失败。当前段丢弃；daemon 重启 worker；连续失败回退 CPU。
Timeouthandshake / transcribe 超预算。daemon 杀 worker；按崩溃路径重建。
ProtocolMismatchworker / daemon 协议版本不一致。拒绝加载；提示升级 runtime 或 daemon。
