  • 每个 bin 只启用自己的 feature；不要在一个二进制里同时链入两个 runtime。

2. CONVENTIONS

↑

约定内容
进程边界只运行在独立 worker 进程；没有库 API 被 daemon 链接。
硬编码映射daemon 按 AsrKind 选择二进制；worker 不接收 runtime 插件路径，不动态加载 EP。
GPU runtimeFireRed 用 OpenASR / ggml；Qwen 用 llama.cpp / ggml；Vulkan / CUDA 只在此进程注册。
FP16两个模型都只接受 FP16；加载失败返回错误，不回退其他精度。
协议权威帧格式、消息与错误码只在 USER §4.2 / §4.3 定义。
无状态每个 Final 段独立解码；不保留跨段 KV cache、音频或文本。
标点FireRed 在 worker 内应用 FireRedPunc；Qwen 使用模型内置标点。
错误映射模型 / runtime / 设备错误映射为 worker 错误码；不把底层文案暴露成前端文案。
资源释放Shutdown / 崩溃都必须释放 GPU 会话与显存；daemon 不持有 GPU 资源。

5. Call stack tree

↑

5.1 FireRed worker 启动

voime-gpu-firered::main()
├── voime_gpu::cli::parse()
├── OpenAsrRuntime::load(device)
├── protocol::read_frame(stdin)
├── 判断 Request::Hello → FireRedWorker::load(manifest, runtime)
│   ├── FireRedPunc::load(...)
│   └── protocol::write_frame(Ready)
└── 判断加载失败 → protocol::write_frame(Error { LoadFailed })

5.2 Qwen worker 启动

voime-gpu-qwen3::main()
├── voime_gpu::cli::parse()
├── LlamaRuntime::load(device)
├── protocol::read_frame(stdin)
├── 判断 Request::Hello → QwenWorker::load(manifest, runtime)
│   └── protocol::write_frame(Ready)
└── 判断加载失败 → protocol::write_frame(Error { LoadFailed })

5.3 推理

protocol::read_frame(stdin)
├── 判断 Request::Transcribe 且 FireRed
│   ├── OpenAsrRuntime::transcribe(aed, audio)
│   ├── FireRedPunc::punctuate(text)
│   └── protocol::write_frame(Result { text })
└── 判断 Request::Transcribe 且 Qwen
    ├── LlamaRuntime::transcribe(model, mmproj, audio)
    ├── qwen::parse::strip_language_tag(text)
    └── protocol::write_frame(Result { text })

5.4 取消与关闭

protocol::read_frame(stdin)
├── 判断 Request::Cancel → 丢弃当前结果 + write Error(Timeout)
└── 判断 Request::Shutdown
    ├── protocol::write_frame(Bye)
    ├── FireRedWorker / QwenWorker::drop() → 释放模型与显存
    └── runtime::drop() → 释放 Vulkan / CUDA
