2. CONVENTIONS

↑

约定内容
进程边界只运行在独立 voime-gpu 进程；没有库 API 被 daemon 链接。
GPU EPDirectML / MIGraphX / CUDA 只在此进程注册；CPU ORT 不在此进程加载。
FP16encoder / decoder 只接受 FP16；加载失败返回错误，不回退其他精度。
模型目录只加载 daemon 传入的 fire-red-aed manifest 与 encoder / decoder / tokens；不读取 VAD、SenseVoice 或 Punc 目录。
协议权威帧格式、消息与错误码只在 USER §4.2 / §4.3 定义。
无状态每个 Final 段独立解码；不保留跨段 KV cache、音频或文本。
错误映射模型 / EP / 设备错误映射为 worker 错误码；不把 GPU 错误暴露成前端文案。
资源释放Shutdown / 崩溃都必须释放 GPU 会话与显存；daemon 不持有 GPU 资源。

4. Internal types & method signatures

↑

4.1 main.rs 文件树

fn main() -> std::process::ExitCode;
fn run(args: Args) -> anyhow::Result<()>;
  • main 只做协议循环与错误退出；模型加载在 server::handshake 内完成。

4.2 cli.rs 文件树

pub struct Args {
    pub manifest: PathBuf,
    pub device: String,
    pub verbose: bool,
}

pub fn parse() -> Args;
  • --manifest 指向 models/fire-red-aed；punc 是 daemon 加载的独立目录，不传给 worker。

4.3 protocol.rs 文件树

pub struct Frame { pub header: Header, pub audio: Vec<f32> }
pub struct Header { /* ... */ }

pub enum Request { Hello { .. }, Transcribe { .. }, Cancel { .. }, Shutdown }
pub enum Response { Ready { .. }, Result { .. }, Error { .. }, Bye }
pub enum ErrorCode { RuntimeMissing, DeviceUnavailable, LoadFailed, InferenceFailed, Timeout, ProtocolMismatch }

pub fn read_frame(reader: &mut impl Read) -> anyhow::Result<Frame>;
pub fn write_frame(writer: &mut impl Write, header: &Header, audio: &[f32]) -> anyhow::Result<()>;

4.4 server.rs 文件树

pub struct Server { /* runtime + aed + stdout protocol */ }

impl Server {
    pub fn run(args: Args) -> anyhow::Result<()>;
    fn handshake(&mut self, hello: Hello) -> anyhow::Result<Ready>;
    fn transcribe(&mut self, request: Transcribe, audio: &[f32]) -> anyhow::Result<Result>;
    fn shutdown(&mut self) -> anyhow::Result<()>;
}

4.5 aed.rs 文件树

pub struct FireRedAed { /* encoder + decoder + tokenizer + metadata */ }

impl FireRedAed {
    pub fn load(manifest: &Path, runtime: &GpuRuntime) -> anyhow::Result<Self>;
    pub fn transcribe(&mut self, samples: &[f32]) -> anyhow::Result<AedOutput>;
}

pub struct AedOutput {
    pub text: String,
    pub latency_ms: u64,
    pub rtf: f32,
}
  • transcribe 内完成 fbank / CMVN、encoder、自回归 decoder、KV cache 与 tokenizer。
  • 停止条件为 eos、max_len 或 max_token_per_second；不做 beam search。

4.6 runtime.rs 文件树

pub struct GpuRuntime { /* EP + device + vram */ }

impl GpuRuntime {
    pub fn load(device: &str) -> anyhow::Result<Self>;
    pub fn create(&self, artifact: &Artifact) -> anyhow::Result<Session>;
    pub fn vram_mb(&self) -> u32;
    pub fn provider(&self) -> &str;
}

5. Call stack tree

↑

5.1 启动与握手

voime-gpu::main()
├── voime_gpu::cli::parse()
├── voime_gpu::server::Server::run(args)
│   ├── GpuRuntime::load(device)
│   ├── protocol::read_frame(stdin)
│   ├── 判断 Request::Hello → Server::handshake(hello)
│   │   ├── FireRedAed::load(manifest, runtime)
│   │   └── protocol::write_frame(Ready)
│   └── 判断加载失败 → protocol::write_frame(Error { LoadFailed })
└── 判断 Err → eprintln! + ExitCode::from(1)

5.2 推理

protocol::read_frame(stdin)
└── 判断 Request::Transcribe → Server::transcribe(request, audio)
    ├── FireRedAed::transcribe(audio)
    │   ├── Fbank / CMVN
    │   ├── Encoder::run(x, x_lens) → cross_k / cross_v
    │   ├── Decoder::run(...) → logits / KV cache
    │   └── AsrTokenizer::decode(ids)
    └── protocol::write_frame(Result { id, text, latency_ms, rtf })

5.3 取消与关闭

protocol::read_frame(stdin)
├── 判断 Request::Cancel → 丢弃当前结果 + write Error(Timeout)
└── 判断 Request::Shutdown
    ├── protocol::write_frame(Bye)
    ├── FireRedAed::drop() → 释放 GPU 会话
    └── GpuRuntime::drop() → 释放 EP / 显存
