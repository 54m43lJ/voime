1. 环境

↑

项目要求
Ruststable 工具链（rust-toolchain.toml）；与 daemon 同 workspace，但两个 worker 作为独立 bin 构建。
Linux AMDVulkan（OpenASR / llama.cpp）；P0 验收平台 RX 9070 XT 16 GB；不需要 ROCm / MIGraphX。
Windows AMDVulkan；P1。
NVIDIACUDA runtime；P1 / P2，独立打包。
FireRed 模型FireRed AED FP16 + FireRedPunc .oasr；编译不需要权重。
Qwen 模型Qwen3-ASR 1.7B F16 GGUF + mmproj；编译不需要权重。
隔离GPU feature 只在对应 bin 启用；daemon 构建不得打开 firered / qwen GPU feature。

2. 构建

↑

# FireRed worker（Linux / Windows AMD）
cargo build --release -p voime-gpu --bin voime-gpu-firered --features firered-vulkan

# Qwen worker（Linux / Windows AMD）
cargo build --release -p voime-gpu --bin voime-gpu-qwen3 --features qwen3-vulkan

# NVIDIA 示例
cargo build --release -p voime-gpu --bin voime-gpu-firered --features firered-cuda
cargo build --release -p voime-gpu --bin voime-gpu-qwen3 --features qwen3-cuda
产物说明
target/release/voime-gpu-fireredFireRed GPU Final worker；OpenASR / FireRed AED + FireRedPunc。
target/release/voime-gpu-qwen3Qwen GPU Final worker；llama.cpp / Qwen3-ASR + mmproj。
voime-gpu-firered.exe / voime-gpu-qwen3.exeWindows 产物；由托盘 / daemon 以子进程托管。
runtime 包voime-gpu-firered-* / voime-gpu-qwen3-*，按 OS + EP 拆分。
  • 基础安装不包含两个 worker；只有 --firered / --qwen3 或显式安装 runtime 才使用。
  • 不要把 GPU runtime 放入模型目录；模型包不允许自带可执行文件。
  • 两个 bin 不要同时启用两个模型 feature；每个 runtime 包只带一个 worker。

3. 运行与安装

↑

# 安装模型
scripts/install_models.sh --firered --activate
scripts/install_models.sh --qwen3 --activate

# Linux AMD runtime
scripts/install_runtime.sh --backend firered
scripts/install_runtime.sh --backend qwen3

# Windows AMD runtime
powershell -ExecutionPolicy Bypass -File scripts\install_models.ps1 -FireRed -Runtime firered-vulkan
powershell -ExecutionPolicy Bypass -File scripts\install_models.ps1 -Qwen3 -Runtime qwen3-vulkan
操作契约
安装runtime 包独立目录、版本、SHA 与签名；按模型安装，显式 opt-in。
启动由 voimed 按 Final kind spawn；用户不直接运行 worker，排障时可手动启动。
停止daemon 发送 Shutdown；5 s 超时后强杀；Windows Job Object / Linux 进程组确保无孤儿。
诊断voime doctor / ctl models 显示两个 backend 的 runtime、driver、VRAM、worker 与 BackendState。
卸载删除对应 worker 与 runtime 目录；模型目录按需保留；不删除另一个 worker。

↑

cargo test -p voime-gpu

cargo fmt -p voime-gpu --check
测试覆盖
协议帧长度、截断、协议版本、Hello / Ready、Transcribe / Result、Cancel、Shutdown。
FireRedFP16 AED / Punc、metadata、SHA；Punc 输出；无 Partial。
QwenF16 GGUF + mmproj；language tag 解析；ctx=4096；空文本；无 Partial。
生命周期两个 worker 的 spawn / handshake / 超时 / 崩溃重启 / 显存不足 / shutdown 无孤儿。
隔离worker 不加载 CPU 模型；daemon 不加载 GPU 库；移除某个 runtime 后 CPU Final 仍可用。
性能两个模型的首次加载、RTF、p95 收尾延迟、峰值 VRAM；目标机器冻结。

5. 升级 / 卸载

↑

操作步骤
升级 worker停止 daemon 或重启后端；替换对应 worker 与 runtime；旧 Final 不可用时回退 CPU SenseVoice。
升级 runtime独立替换 runtime 目录；校验版本 / SHA / 签名；不改变模型目录。
卸载删除对应 worker 与 runtime；不删除 SenseVoice 基础包；active 改回 CPU 或重新安装。
迁移旧 GPU 包 / 旧 schema 直接拒绝；不建立运行期兼容层。
