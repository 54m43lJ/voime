1. 环境

↑

项目要求
Ruststable 工具链（rust-toolchain.toml）；与 daemon 同 workspace，但作为独立二进制构建。
Linux AMDROCm 7.2.1 + MIGraphX；ORT 1.23.2；P0 验收平台 RX 9070 XT 16 GB。
Windows AMDDirectML runtime；P1。
NVIDIACUDA / TensorRT runtime；P1 / P2，独立打包。
模型FireRed AED FP16 encoder / decoder / tokens / punc；编译不需要权重。
隔离GPU feature 只在本二进制启用；daemon 构建不得打开 directml / migraphx / cuda feature。

2. 构建

↑

# 通用 GPU 二进制（runtime 由动态库提供）
cargo build --release -p voime-gpu

# Linux AMD 示例
cargo build --release -p voime-gpu --features migraphx

# Windows AMD 示例
cargo build --release -p voime-gpu --features directml
产物说明
target/release/voime-gpu独立 GPU Final worker；只加载 GPU ORT / EP。
voime-gpu.exeWindows 产物；由托盘 / daemon 以子进程托管。
runtime 包voime-gpu-linux-migraphx / voime-gpu-windows-directml / voime-gpu-linux-cuda / voime-gpu-windows-cuda。
  • 基础安装不包含本二进制或 runtime；只有 firered 档 / 显式 opt-in 才安装。
  • 不要把 GPU runtime 放入模型目录；模型包不允许自带可执行文件。

3. 运行与安装

↑

# 安装模型（含 FireRed AED）
scripts/install_models.sh --profile firered --activate

# Linux AMD runtime
scripts/install_runtime.sh --runtime linux-migraphx

# Windows AMD runtime
powershell -ExecutionPolicy Bypass -File scripts\install_models.ps1 -Runtime windows-directml
操作契约
安装runtime 包独立目录、版本、SHA 与签名；安装需显式 opt-in。
启动由 voimed spawn；用户不直接运行 worker，排障时可手动启动。
停止daemon 发送 Shutdown；5 s 超时后强杀；Windows Job Object / Linux 进程组确保无孤儿。
诊断voime doctor / ctl models 显示 runtime、driver、VRAM、worker 与 BackendState。
卸载删除 runtime 目录与可选 voime-gpu 二进制；模型目录按需保留。

4. 测试

↑

cargo test -p voime-gpu
cargo clippy -p voime-gpu --all-targets
cargo fmt -p voime-gpu --check
测试覆盖
协议帧长度、截断、协议版本、Hello / Ready、Transcribe / Result、Cancel、Shutdown。
模型FP16 encoder / decoder、metadata、KV cache 形状、tokens、SHA；FP16 不可用直接失败。
生命周期spawn / handshake / 超时 / 崩溃重启 / 显存不足 / shutdown 无孤儿。
隔离worker 不加载 CPU 模型；daemon 不加载 GPU 库；移除 runtime 后 CPU Final 仍可用。
性能首次加载、RTF、p95 收尾延迟、峰值 VRAM；目标机器冻结。

5. 升级 / 卸载

↑

操作步骤
升级 worker停止 daemon 或重启后端；替换 voime-gpu 与 runtime；旧 Final 不可用时回退 CPU SenseVoice。
升级 runtime独立替换 runtime 目录；校验版本 / SHA / 签名；不改变模型目录。
卸载删除 worker 二进制与 runtime；不删除 SenseVoice 基础包；active 改回 CPU 或重新安装。
迁移旧 GPU 包 / 旧 schema 直接拒绝；不建立运行期兼容层。
