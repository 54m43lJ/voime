1. 环境

↑

项目要求
平台AMD x86_64 Linux；桌面为 Hyprland / Wayland。X11 与 Windows 本版不实现。
Ruststable 工具链（rust-toolchain.toml）。首次构建需要网络下载 crate、协议 XML 与 ONNX Runtime 预编译库。
Linux 构建依赖ALSA、Wayland、xkbcommon 与 D-Bus 开发头文件。Arch：alsa-lib、wayland、libxkbcommon、dbus；Debian / Ubuntu：libasound2-dev、libwayland-dev、libxkbcommon-dev、libdbus-1-dev。
运行期Hyprland（≥ 0.52.1，支持 input-method-v2）、D-Bus session bus、可用录音设备；无需 Fcitx5 / IBus / xdg-desktop-portal / 网络 / GPU / Python。
输入法冲突运行前必须停用 Fcitx5 / IBus。seat 只能有一个 input-method-v2 对象；voimed 收到 unavailable 会以 1 退出。
TUIvoime 需要 TTY、UTF-8 与 ANSI 转义；voimed 不需要 TTY。
托盘可选；需要 StatusNotifierWatcher / 宿主（Waybar、Vicinae 等）。缺失时只告警。
模型安装期Python 3.10+、网络与磁盘空间；只用于 scripts/install_models.sh 与 tools/，不进入运行时。

2. 构建

↑

cargo build --release
产物说明
target/release/voimed常驻 daemon / 唯一输入法；拥有音频、模型、键盘抓取、上屏、IPC 与托盘。
target/release/voime可选 TUI 与 ctl / doctor 客户端。
模型包由安装脚本写入用户数据目录，不进入版本库；应用只读。
protocols/*.xmlinput-method-unstable-v2 与 virtual-keyboard-unstable-v1，由 voimed/build.rs 经 wayland-scanner 生成绑定。
  • 构建过程通过 ort 的 download-binaries 获取 ONNX Runtime；构建完成后运行期不联网。
  • 发布时只需分发两个可执行文件、protocols/（仅源码构建需要）、scripts/、tools/ 与安装说明；不要分发 target/ 或安装虚拟环境。
  • 若 ONNX 使用 external data，模型目录中的 *.data 或分片文件必须与 .onnx 一起复制。
  • x11rb 是可选 feature，只用于 XWayland 的 XTEST 粘贴兜底；默认构建不启用。

3. 安装模型

↑

scripts/install_models.sh
行为契约
默认目录$XDG_DATA_HOME/voime/models（未设置时 ~/.local/share/voime/models）。
虚拟环境~/.cache/voime/venv；依赖见 tools/requirements-export.txt。只用于 VAD / Punc 导出与校验。
网络下载 FireRedASR2-CTC 官方 .tar.bz2、FireRedVAD / FireRedPunc 官方权重；完成后应用离线运行。
CTC直接解出 model.int8.onnx 与 tokens.txt，不再为 CTC 运行 Python / PyTorch 导出。模型约 740 MiB。
磁盘下载缓存与模型包占用量以安装脚本输出为准；默认 int8 模型包约 1 GB 量级。
安装方式在目标目录同盘创建临时目录，下载 / 导出、校验、写 manifest.json 后原子替换。
# 常用参数
scripts/install_models.sh --model-dir /path/to/models
scripts/install_models.sh --source-dir /path/to/official/weights

# 单独校验已有模型包（会重写 manifest.json）
~/.cache/voime/venv/bin/python tools/verify_models.py --model-dir /path/to/models
  • manifest.json 使用 schema 2，asr.kind 默认为 fire-red-ctc；CTC 的 CMVN 参数存放在 ONNX metadata，不在 manifest 中。
  • 需要从 HuggingFace 下载且未检测到 HF_TOKEN 时，安装脚本会警告并提示输入；输入的 token 只用于当前进程，不写入磁盘。
  • 模型包内容与张量契约见 PROVIDER §4.2；安装脚本不写入用户音频或识别历史。

4. 运行

↑

# 一次性迁移：停用 Fcitx5 / IBus
systemctl --user disable --now fcitx5
# 或删除 Hyprland 配置中的 exec-once = fcitx5

# 启动 daemon（推荐 Hyprland exec-once 或 systemd user service）
voimed

# 可选 TUI
voime

# 控制 / 诊断
voime ctl status
voime ctl quit
voime doctor
操作行为
voime ctl start / stop / toggle手动控制当前语音段；与 PTT 共用状态机。
voime ctl clear清空 daemon 会话历史；剪贴板不变。
voime ctl quit停止 daemon，取消当前段，不产生 Final。
Super+F2按住说话；松开结束。可在 voimed --hold-key 修改。
Super+F3按一下开始 / 再按一下结束。可在 voimed --toggle-key 修改。
托盘右键“退出”与 voime ctl quit 相同。
  • PTT 组合键不得与 Hyprland bind / bindr 冲突；合成器会先消费已绑定的键。
  • 普通按键由 daemon 透明转发；如果打字异常，先运行 voime doctor 检查 grab / keymap / virtual-keyboard。
  • PTT 硬上限 30 s；TUI 状态行显示 ● Remaining: xx s，continuous 不显示。
现象处理
ImUnavailable停用 Fcitx5 / IBus 后重启 voimed；确认同一 seat 没有其他输入法。
GrabFailed / KeyForwardFailed确认 Hyprland ≥ 0.52.1、virtual-keyboard 可用；查看 stderr 与 voime doctor。
PTT 无反应检查组合键是否被 Hyprland 绑定；用 voime ctl toggle 验证录音链路。
模型清单错误 / 缺失 / 校验失败重新运行安装脚本；确认 --model-dir 指向包含 manifest.json 的目录。
没有可用输入设备检查系统录音设备；设备名必须与操作系统暴露的名称完全一致。
XWayland 粘贴失败确认剪贴板可用；启用 x11 feature 使用 XTEST 兜底。
TUI 连不上 daemon先启动 voimed；确认两者 --socket 一致。

5. 测试

↑

cargo test
cargo clippy --all-targets
cargo fmt --all --check
~/.cache/voime/venv/bin/python tools/verify_models.py --model-dir <DIR> --no-write
  • tests/segmenter.rs 覆盖端点、静音自动结束与最大段长；tests/keyboard.rs 覆盖 PTT 匹配、非 PTT 转发、keymap 变化与重复；tests/ipc.rs 覆盖握手、编解码与慢客户端；tests/sink.rs 覆盖 im / clipboard 选择。
  • tests/countdown.rs 覆盖 30 s 计时、自动切段与 continuous 不显示；tests/state.rs 覆盖段所有权与清空。
  • 模型包校验包含 SHA-256、张量名称、类型、形状与真实 ONNX Runtime 推理；CTC 另测 CMVN metadata、token id 与 greedy CTC。

6. 发布检查

↑

cargo build --release
target/release/voimed --help
target/release/voime --help
scripts/install_models.sh
  • 发布包应包含两个可执行文件、scripts/、tools/ 与安装说明；模型权重由安装脚本按需下载。
  • 运行验收：停用 Fcitx5 后 daemon 启动、普通打字透明转发、hold / toggle PTT、原生 Wayland 提交、XWayland 粘贴、30 s 倒计时 / 自动切段、TUI detach、托盘退出。
  • 冲突验收：Fcitx5 运行时 voimed 必须退出并提示 ImUnavailable；不得静默降级为纯粘贴。
  • 剪贴板验收：原生提交不修改剪贴板；XWayland / 终端只写入单条 Final；清空不修改剪贴板。
  • 键盘验收：布局切换、修饰键、死键、组合键、长按重复在转发后与未安装 Voime 时一致；无丢键、无重复。
