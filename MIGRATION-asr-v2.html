一次性迁移 — ASR v2

README USER CORE PROVIDER BUILD ｜ 提案

本文只说明 scripts/migrate-asr-v2.sh 的可选一次性迁移。它不是安装脚本的一部分； 安装器不会检测、调用或提示运行它。默认升级方式仍是 clean install。

1. 范围

↑

项目约定
支持来源只支持上一版本 + 当前开发机环境；不覆盖源码构建、其他发行版或其他机器。
目标schema 3 固定模型目录（vad / sense-voice，可选 fire-red-aed / punc）与 Fcitx 配置备份。
不处理不转换旧 CTC / SenseVoice-punc / AED CPU 包；不建立运行期兼容层；不迁移模型选择指针（新架构没有）；不改音频等无关用户数据。
生命周期临时脚本，只随 ASR v2 首次发布提供；下一个大版本移除。

2. 前置条件

↑

  • 先安装新版本二进制；迁移脚本备份旧模型目录与 Fcitx 配置，然后调用安装器写入新的固定模型目录。
  • 停止 voimed；脚本不会在 daemon 运行时执行。
  • 确认模型根目录可写，且磁盘空间足够保存时间戳备份。
  • 阅读发布说明；确认当前环境属于“上一版本 + 当前开发机”，其他环境直接 clean install。

3. 使用

↑

# 只输出计划，不修改文件
scripts/migrate-asr-v2.sh --dry-run

# 默认安装 VAD + SenseVoice；GPU 目录再加 --gpu
scripts/migrate-asr-v2.sh --apply
scripts/migrate-asr-v2.sh --apply --gpu

# 指定模型根目录
scripts/migrate-asr-v2.sh --dry-run --model-root /path/to/models
选项行为
--dry-run默认模式；列出将备份、安装与写入的项。
--apply执行迁移；执行前要求 daemon 已停止。
--gpu除默认 VAD + SenseVoice 外，额外安装 FireRed AED + Punc；对应安装步骤需要可用的 Punc 源目录。
--force忽略已存在的迁移标记；仅用于明确知道后果的重复运行。
--model-root覆盖模型根目录。

4. 迁移内容

↑

步骤行为
备份把旧模型目录与 ~/.config/fcitx5/conf/voime.conf 复制到带时间戳的备份目录；失败时停止。
安装调用 install_models.sh 写入固定目录：默认 vad + sense-voice；--gpu 追加 fire-red-aed + punc。
配置保留 Fcitx 的 Mode / Hotkey；旧模型选择字段不再读取，未知字段保留在备份中。
收尾写迁移标记 .migrate-asr-v2；输出模型根目录与备份路径。

5. 回滚

↑

  • 失败时脚本自动恢复备份，并保留迁移日志。
  • 手工回滚：停止 daemon，把备份目录中的模型 / 配置复制回原位置，再启动旧版本；新架构没有 active 需要恢复。
  • 迁移不是运行期兼容承诺；回滚后旧版本仍按旧规则运行。

6. 不做什么

↑

  • 不安装或替换二进制；不启动 / 停止 systemd 或托盘。
  • 不下载模型；模型安装仍由安装脚本完成。
  • 不转换旧模型包，不保留旧 schema、active=legacy 或旧目录布局；新 daemon 只读取四个固定目录。
  • 不修改与升级无关的音频、按键或识别历史。
