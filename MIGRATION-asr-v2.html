一次性迁移 — ASR v2

README USER CORE PROVIDER BUILD ｜ 提案

本文只说明 scripts/migrate-asr-v2.sh 的可选一次性迁移。它不是安装脚本的一部分； 安装器不会检测、调用或提示运行它。默认升级方式仍是 clean install。

1. 范围

↑

项目约定
支持来源只支持上一版本 + 当前开发机环境；不覆盖源码构建、其他发行版或其他机器。
目标schema 3 的两个资源包目录：default/（VAD + SenseVoice）与可选 firered/（FireRed AED + Punc）；保留 Fcitx 配置备份。
不处理不转换旧 CTC / SenseVoice-punc / AED CPU 包；不建立运行期兼容层；不迁移后端设置；不改音频等无关用户数据。
生命周期临时脚本，只随 ASR v2 首次发布提供；下一个大版本移除。

2. 前置条件

↑

  • 先安装新版本二进制；迁移脚本备份旧模型目录与 Fcitx 配置，然后调用安装器写入新的资源包目录。
  • 停止 voimed；脚本不会在 daemon 运行时执行。
  • 确认模型根目录可写，且磁盘空间足够保存时间戳备份。
  • 阅读发布说明；确认当前环境属于“上一版本 + 当前开发机”，其他环境直接 clean install。

3. 使用

↑

# 只输出计划，不修改文件
scripts/migrate-asr-v2.sh --dry-run

# 默认安装 default/（VAD + SenseVoice）；需要 firered/ 时再加 --gpu
scripts/migrate-asr-v2.sh --apply
scripts/migrate-asr-v2.sh --apply --gpu --punc-source-dir /path/to/fireredpunc

# 指定模型根目录 / 缓存 / 本地导出的 FireRed 包
scripts/migrate-asr-v2.sh --dry-run --model-root /path/to/models
scripts/migrate-asr-v2.sh --apply --cache-dir /path/to/cache \
    --source-dir /path/to/exported/aed --aed-version v2
选项行为
--dry-run默认模式；列出将备份、安装、清理与写入的项。
--apply执行迁移；执行前要求 daemon 已停止。
--gpu除默认 default/（VAD + SenseVoice）外，额外安装 firered/（FireRed AED + Punc）；对应安装步骤需要可用的 Punc 源目录。
--punc-source-dir传给安装器的 FireRedPunc 源目录；不提供时复用已安装的 firered/punc。
--source-dir传给安装器的本地导出模型目录；可用于 VAD / FireRed AED / Punc。
--cache-dir传给安装器的下载缓存目录。
--aed-versionv1 / v2 / auto；传给 FireRed 安装步骤。
--force忽略已存在的迁移标记；仅用于明确知道后果的重复运行。
--model-root覆盖模型根目录；不能为空或 /。

4. 迁移内容

↑

步骤行为
备份把旧模型目录复制到 <backup>/models/，把 ~/.config/fcitx5/conf/voime.conf 复制到 <backup>/config/voime.conf；失败时停止。
安装调用 install_models.sh 写入资源包：默认 default/（vad + sense-voice）；--gpu 追加 firered/（fire-red-aed + punc）。
清理安装成功后删除模型根目录下旧的 vad / sense-voice / fire-red-aed / punc / fire-red-aed-v1 目录与旧 active 文件；备份仍保留。
配置保留 Fcitx 的 Mode / Hotkey；Backend 缺失时按 cpu 处理。旧模型选择字段不再读取，未知字段保留在备份中。
收尾写迁移标记 .migrate-asr-v2；输出模型根目录与备份路径。

5. 回滚

↑

  • 失败时脚本自动删除未完成的新模型目录并恢复备份；已备份的配置保持不变。
  • 手工回滚：停止 daemon，把 <backup>/models/ 与 <backup>/config/voime.conf 复制回原位置，再启动旧版本；新架构没有 active 需要恢复。
  • 迁移不是运行期兼容承诺；回滚后旧版本仍按旧规则运行。

6. 不做什么

↑

  • 不安装或替换二进制；不启动 / 停止 systemd 或托盘。
  • 不下载模型；模型安装仍由安装脚本完成。
  • 不转换旧模型包，不保留旧 schema、active=legacy 或旧目录布局；安装成功后清理旧根级模型目录，新 daemon 只读取 default/ 与 firered/ 资源包。
  • 不修改与升级无关的音频、按键或识别历史。
