2. CONVENTIONS

↑

约定内容
线程边界 daemon 主线程拥有状态机、会话历史与投递；Wayland 线程独占 input-method-v2、keyboard grab、virtual-keyboard 与 xkb 状态；pipeline 工作线程独占 VAD / ASR / 标点会话；cpal 回调只做格式转换并入队；IPC 读写线程与托盘线程只通过 channel 与主线程通信；TUI 是独立进程。
状态所有权 daemon 拥有 mode、phase、recording、finalizing、partial、transcript、remaining_ms、IM 状态与键盘状态；TUI 只拥有滚动与视口；Wayland 线程只拥有键盘抓取和转发状态。
输入法唯一性 一个 seat 只创建一个 zwp_input_method_v2。启动期收到 unavailable 即失败退出；不重试、不降级为纯剪贴板；Fcitx5 / IBus 必须先停用。
键盘抓取 IM 对象创建后立即 grab_keyboard，整个 daemon 生命周期持有；deactivate 不释放。grab 的 keymap / key / modifiers / repeat_info 全部由 Wayland 线程处理。
透明转发 非 PTT 的 key / modifiers 立即转发到 zwp_virtual_keyboard_v1；不缓存、不延迟、不改变 keycode / state / time。转发失败视为 KeyForwardFailed 并退出，不能持有 grab 却不转发。
XIM 边界 XIM server 只注册、跟踪 focused IC 并发送 XIM_COMMIT；不请求 forward-event，不处理普通按键或 PTT。XIM 不可用只影响 XWayland 上屏，不阻断 daemon；XWayland 延迟启动时由 daemon tick 周期性重试注册。
同连接 input-method-v2、keyboard grab 与 virtual-keyboard 必须创建在同一个 wl_display 上；Hyprland 通过客户端指针识别并忽略 IM 自己注入的按键，避免转发回环。
PTT 匹配 用 grab 的 xkb keymap 把 keycode + modifiers 转成 keysym；只比较 Shift / Ctrl / Alt / Super，忽略 CapsLock / NumLock / group。hold 按下按组合键匹配，松开按记下的 keycode 匹配；重复 press 一律忽略。
合成器优先级 Hyprland 先处理合成器键绑定，再交给 IM grab。PTT 组合键不得与 Hyprland bind / bindr 冲突。
采集常开 音频流在启动后保持运行；PTT 模式通过 StartSegment / FinishSegment 决定是否收集样本，不反复启停设备。
安装期与运行期分离 下载与模型导出只存在于安装脚本；Rust 二进制不依赖 Python，不包含下载器。CTC 直接下载官方包，VAD / Punc 的导出与校验在安装期完成。
模型生命周期 启动时校验并加载 VAD / CTC / Punc，会话对象常驻内存；每个语音段只重置解码与 VAD 状态，不重新加载权重。
单段串行 同一时刻只有一个语音段处于识别或收尾状态。临时识别与最终识别在同一工作线程串行执行，不存在重叠任务；正在执行的临时识别不能被取消。
有界队列 continuous 模式下 VAD 持续运行，完成段进入容量 2 的待识别队列；队列满时丢弃最旧的未处理段。PTT 模式不使用该队列。
音频格式 内部统一为 16 kHz、单声道、f32 样本；设备原生采样率与声道数在 audio::resample 中转换。音频不落盘。
分段上限 PTT 硬上限固定 30_000 ms；continuous 使用 manifest 的 max_segment_ms，同样不超过 30_000 ms。达到上限时当前段进入 Finalizing；若 PTT 仍按住，final 完成后立即开始新段，音频进入有界缓冲。
临时识别 按动态间隔对当前段末尾最多 6 s 音频执行 greedy CTC，不加标点；间隔同时受新增音频量与上次耗时约束，避免慢推理后逐帧重复触发。
最终识别 语音段结束后对完整段执行 CTC 识别，再对整段文本执行 FireRedPunc；空文本不产生结果行，也不投递。
投递链 auto 按 im → xim → clipboard 顺序选择；im 仅在 IM active 时可用；xim 仅在焦点为 XWayland 且 XIM 有 focused IC 时可用；clipboard 写单条 Final 后经 virtual-keyboard 发送粘贴键，XWayland 失败时用 XTest 兜底。显式指定 sink 时失败不自动切换。
清空工作区 ClearHistory 只清空 daemon 的 transcript，并把广播 HistoryCleared；不修改 partial、recording、finalizing、remaining_ms、IM 状态或剪贴板。
IPC 背压 每个 subscriber 一个有界队列；队列满时断开该客户端，不阻塞 daemon。协议版本不匹配返回 Error 后断开。
托盘 托盘线程只发 TrayEvent::Quit，不持有 daemon 状态；没有 StatusNotifierWatcher / 宿主时只记录 warning。
关停顺序 停止采集 → 取消当前段 → 关闭托盘 → 关闭 XIM server → 销毁 keyboard grab → 销毁 virtual-keyboard → 销毁 input-method-v2 → 关闭 IPC socket；所有退出路径复用同一条 shutdown。
错误策略 启动期致命错误写 stderr 并以 1 退出；单段推理失败丢弃该段并继续监听；IM / grab / VK / 音频流持续失败时关闭 daemon；XIM 注册或提交失败只记录并回退剪贴板。运行期错误不进入 TUI 内容区。
无异步运行时 使用标准线程、crossbeam-channel 与 Wayland 事件队列；不引入 tokio / async-std。D-Bus 使用 ksni 的 blocking API。
路径与编码 路径使用 std::path::PathBuf；终端文本统一 UTF-8；不经过 shell，不拼命令行字符串。

4.3 voime-core/src/model.rs 文件树

use std::path::{Path, PathBuf};

pub struct TensorSpec {
    pub name: String,
    pub dtype: String,
    pub shape: Vec<i64>,
}

pub struct Artifact {
    pub model: PathBuf,
    pub sha256: String,
    pub inputs: Vec<TensorSpec>,
    pub outputs: Vec<TensorSpec>,
}

pub enum AsrArtifact {
    FireRedCtc {
        model: Artifact,
        tokens: PathBuf,
    },
    FireRedAed {
        encoder: Artifact,
        decoder: Artifact,
        tokens: PathBuf,
    },
}

pub struct PuncArtifact {
    pub model: Artifact,
    pub vocab: PathBuf,
    pub labels: PathBuf,
    pub max_tokens: usize,
}

pub struct ModelManifest {
    pub schema: u32,
    pub sample_rate: u32,
    pub fbank: FbankManifest,
    pub max_segment_ms: u32,
    pub vad: Artifact,
    pub asr: AsrArtifact,
    pub punc: PuncArtifact,
}

pub struct FbankManifest {
    pub num_bins: usize,
    pub frame_ms: u32,
    pub shift_ms: u32,
}

impl ModelManifest {
    pub fn load(path: &Path) -> anyhow::Result<Self>;
    pub fn verify(&self, dir: &Path) -> anyhow::Result<()>;
    pub fn rebase(&mut self, dir: &Path) -> anyhow::Result<()>;
}
  • schema 固定为 2；CTC 与 AED 用 tagged enum 区分，默认 FireRedCtc。
  • verify 校验主文件存在性与 SHA-256；external data 分片不在哈希范围，必须与主文件一起保留。
  • FbankManifest 缺省为 80 bins / 25 ms 窗 / 10 ms 帧移；max_segment_ms 缺省 30_000，允许范围 1..=30_000。

├── daemon::Daemon::start_segment(source)
│   ├── state::PttTimer::start()
│   ├── pipeline::Pipeline::start_segment()
│   │   └── crossbeam_channel::Sender::send(PipelineCommand::StartSegment)
│   ├── state::Phase::Recording
│   └── ipc_server::IpcServer::broadcast(State)
└── daemon::Daemon::on_hotkey(HoldReleased / TogglePressed)
