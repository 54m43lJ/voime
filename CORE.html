2. CONVENTIONS

↑

约定内容
进程边界 fcitx5 进程加载 addon，拥有 Fcitx 主循环、按键事件、InputPanel 与 IPC 客户端；voimed 是独立进程，拥有音频、模型、pipeline、会话历史与 socket 服务；voime TUI 只连接 socket。
线程边界 addon 的所有 Fcitx 调用在 Fcitx 事件循环线程内完成；voimed 的事件循环处理 socket / 命令 / 状态，pipeline 工作线程串行执行 VAD / CTC / 标点；TUI 使用自己的线程。
Mode / Hotkey 所有权 addon 从 ~/.config/fcitx5/conf/voime.conf 读取 Mode / Hotkey；通过 Hello / Configure 同步给 daemon；daemon 不解析命令行模式。
目标输入框 每个语音段在开始时保存目标 InputContext 的 TrackableObjectReference；最终提交前检查存在且 hasFocus()。
临时窗口 addon 在收到 Partial 时调用 InputPanel::setPreedit 并 updateUserInterface(InputPanel)；Final / 停止 / 空段 / 错误 / 目标丢失 / 断线时清空。
最终提交 addon 先清空临时窗口，再对目标 InputContext 调用 commitString；不重新选择当前窗口。
键盘所有权 Fcitx 持有键盘；Voime 不读取 / 转发 / 注入按键。普通按键完全由 Fcitx 路由。
单段串行 同一时刻只有一个语音段处于识别或收尾状态；Recording / Finalizing 期间新的 Start 被忽略。
有界队列 continuous 的完成段进入容量 2 的待识别队列；队列满时丢弃最旧段，避免阻塞当前语音。
音频格式 内部统一为 16 kHz、单声道、f32；设备原生格式在 audio::resample 转换；音频不落盘。
模型生命周期 启动时校验并加载 VAD / CTC / Punc；会话常驻内存；每个语音段只重置解码状态，不重新加载权重。
CTC 单 ONNX、CMVN 从 metadata 读取、greedy 解码；final 与尾部 partial 共用同一会话；默认分段上限 30_000 ms。
临时识别 按动态间隔对当前段末尾最多 6 s 音频执行 CTC，不加标点；结果只用于 Fcitx 临时窗口与 TUI。
最终识别 段结束后对完整段执行 CTC，再执行 FireRedPunc；空文本不产生 Final。
IPC 背压 每个客户端有有界队列；Final / State 不丢，Partial 可丢；慢 TUI 被断开，不阻塞 daemon。
错误策略 启动错误写 stderr / Fcitx 日志并以非零码退出；运行期单段失败丢弃该段；addon 断线放行热键，不影响普通输入。
无异步运行时 Rust 侧使用标准线程、crossbeam-channel 与事件循环；addon 使用 Fcitx EventLoop::addIOEvent；不引入 tokio / async-std。
无持久化 不写音频、按键或识别历史到磁盘；daemon 退出后会话历史丢失。

5. Call stack tree

↑

5.1 启动

systemd --user
└── voimed::main()
    ├── cli::parse()
    ├── config::Config::resolve(args)
    ├── model::ModelManifest::load / verify
    ├── infer::session::SessionFactory::new(config.threads)
    ├── pipeline::Pipeline::spawn(&config, factory, audio_rx)
    │   ├── vad::firered::FireRedVad::new(...)
    │   ├── asr::firered_ctc::FireRedCtc::new(...)
    │   ├── punc::firered::FireRedPunc::new(...)
    │   └── std::thread::Builder::spawn(Worker::run)
    ├── audio::capture::start(config.input_device, audio_tx)
    ├── ipc_server::IpcServer::bind(config.socket)
    └── daemon::Daemon::run(state, pipeline, audio, ipc)

fcitx5
├── 加载 share/fcitx5/addon/voime.conf
├── 加载 share/fcitx5/inputmethod/voime.conf
└── VoimeAddon::VoimeAddon(instance)
    ├── VoimeConfig::load(~/.config/fcitx5/conf/voime.conf)
    ├── IpcClient::connect(default_socket)
    ├── IpcClient::configure(mode, hotkey)
    └── Instance::watchEvent(InputContextKeyEvent, PreInputMethod)

voime（可选）
└── Client::connect(socket)
    └── Snapshot
  • voimed 与 Fcitx 的启动顺序不敏感；addon 重连失败时按退避间隔重试。
  • 模型校验、会话创建与音频流在 socket 服务前完成；任一步失败不进入运行态。
  • addon 未连接 daemon 时不消费热键；Fcitx 继续正常输入。

5.2 热键与模式

fcitx5::InputContextKeyEvent
└── VoimeAddon::handleKey(event)
    ├── 判断 Mode == Continuous → 直接返回
    ├── KeyEvent::checkKeyList(VoimeConfig::hotkey)
    ├── 判断 Mode == Ptt
    │   ├── 判断 event.isRelease() 且 holdActive_
    │   │   └── IpcClient::stop(segment_id, Hold)
    │   └── 判断 press 且 !recording_ 且 !finalizing_
    │       ├── target_ = event.inputContext()->watch()
    │       └── IpcClient::start(segment_id, Hold)
    └── 判断 Mode == Toggle
        ├── 判断 toggleCode_ 且 release → 消费
        └── 判断 press
            ├── 判断 !recording_
            │   ├── target_ = event.inputContext()->watch()
            │   └── IpcClient::start(segment_id, Toggle)
            └── 判断 recording_
                └── IpcClient::stop(segment_id, Toggle)
  • 命中热键后调用 KeyEvent::filterAndAccept()；未命中立即返回，不影响 Fcitx 的普通路由。
  • hold 的松开按记录的 keycode 匹配，不重新比较完整组合键；auto-repeat 消费后忽略。

5.3 Continuous 监听

pipeline::Worker::run(audio_rx, commands)
└── loop
    ├── crossbeam_channel::select_biased!（命令优先，50 ms 超时）
    │   ├── 判断 PipelineCommand::StartSegment / FinishSegment / Shutdown
    │   │   └── Worker::handle_command(command)
    │   └── 判断 AudioChunk
    │       └── Worker::handle_audio(chunk)
    │           ├── audio::resample::StreamResampler::push(chunk)
    │           └── Worker::process_pending_audio(false)
    │               └── Worker::process_vad_batch(batch, frame_samples)
    │                   └── vad::firered::FireRedVad::push(batch)
    │                       └── Worker::handle_frame(frame, audio)
    │                           └── vad::segmenter::Segmenter::push(frame, samples, mode)
    │                               ├── 判断 SpeechStart → PipelineEvent::Recording(true)
    │                               ├── 判断 partial 门槛 → Worker::emit_partial()
    │                               └── 判断 SpeechEnd → Worker::finalize(segment)
    └── Worker::drain_queue()
  • continuous 由 daemon 的 Mode=continuous 驱动；addon 不参与分段。
  • VAD 与分段器在同一工作线程串行执行，不需要锁。

5.4 临时结果与窗口

pipeline::Worker::emit_partial()
├── 截取 active_samples() 末尾 PARTIAL_MAX_MS
├── asr::features::Fbank::compute(tail)
├── asr::firered_ctc::FireRedCtc::transcribe(features)
└── 判断 text 非空 → PipelineEvent::Partial(text)

daemon::Daemon::on_pipeline(Partial(text))
└── IpcServer::broadcast(ServerMessage::Partial)

VoimeAddon::onIpcMessage(Partial(text))
├── 判断 target_.focused()
└── Preview::show(target_.get(), text)
    ├── InputPanel::setPreedit(Text(text))
    └── InputContext::updateUserInterface(InputPanel)
  • Partial 不进入历史、不提交；为空时保留上一行，避免窗口闪烁。
  • Fcitx UI 是否显示由当前 UI addon 决定；没有 UI 时不显示窗口。

5.5 最终识别与提交

pipeline::Worker::finalize(segment)
├── asr::features::Fbank::compute(segment.samples)
├── asr::firered_ctc::FireRedCtc::transcribe(features)
├── 判断 text 非空
│   └── punc::firered::FireRedPunc::punctuate(text)
└── 判断 final 非空 → PipelineEvent::Final(final)

daemon::Daemon::on_pipeline(Final(text))
├── state.transcript.push(text)
└── IpcServer::broadcast(ServerMessage::Final(segment_id, text))

VoimeAddon::onIpcMessage(Final(segment_id, text))
├── 判断 target_.segment_id == segment_id
├── Preview::clear(target_.get())
├── 判断 target_.focused()
│   └── InputContext::commitString(text)
└── 判断失焦 / 不存在 → 保留历史，不提交
  • 提交前先清空临时窗口；commitString 没有返回值，不能确认应用接受文本。
  • Fcitx commit filter 会作用在最终文本上；Voime 不二次转换。

5.6 TUI、控制与退出

voime::main()

5.7 断线、目标丢失与模式切换

IpcClient::on_readable() 返回 EOF
└── VoimeAddon::onIpcMessage(Disconnected)
    ├── Preview::clear(target_.get())
    ├── holdActive_ = false; toggleCode_ = 0
    └── 热键恢复为普通按键（不消费）

Daemon::apply_mode(mode)
├── Mode=continuous → 允许 VAD 自动分段
└── Mode=ptt / toggle → 等待 addon 的 Start / Stop

TargetRef::focused() == false
├── Preview::clear(ref.get())
└── Final 保留在 daemon 历史 / TUI
  • Fcitx 重启后 addon 重新加载并重连；daemon 不重启。
  • 模式切换在下一个语音段生效；当前段继续到结束。
